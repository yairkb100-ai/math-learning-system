תרגול: תעודת הזהות של הפונקציה הקווית

פרק 14 · שיפוע, חיתוך עם הצירים, עלייה וירידה וסימן — בייצוג אחד

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: קריאה מהמשוואה קל
לכל פונקציה רשמו את השיפוע, את נקודת החיתוך עם ציר ה-y, וציינו אם היא עולה או יורדת:

א. y = 6x - 2
ב. y = -x + 7
ג. y = 4 - 3x
א. שיפוע 6, חיתוך (0, -2), עולה.
ב. שיפוע -1, חיתוך (0, 7), יורדת.
ג. מסדרים ל-y = -3x + 4: שיפוע -3, חיתוך (0, 4), יורדת.
תרגיל 2: מוצאים נקודת אפס קל
מצאו את נקודת האפס של כל פונקציה:

א. y = 5x - 20
ב. y = -2x + 8
ג. y = 12x + 3
א. 0 = 5x - 20, כלומר x = 4. הנקודה (4, 0).
ב. 0 = -2x + 8, כלומר x = 4. הנקודה (4, 0).
ג. 0 = 12x + 3, כלומר 12x = -3 ומכאן x = -6. הנקודה (-6, 0).
תרגיל 3: תעודת זהות מלאה בינוני
מלאו את חמשת פרטי תעודת הזהות של הפונקציה y = -2x + 6: שיפוע, חיתוך עם ציר ה-y, נקודת אפס, עלייה/ירידה, ותחומי חיוביות ושליליות.
שיפוע -2; חיתוך עם ציר ה-y בנקודה (0, 6); נקודת אפס: 0 = -2x + 6 נותן x = 3, כלומר (3, 0); השיפוע שלילי ולכן הפונקציה יורדת; יורדת ואפס ב-x = 3, לכן y > 0 עבור x < 3 ו-y < 0 עבור x > 3.
תרגיל 4: משחזרים משוואה בינוני
פונקציה קווית יורדת חותכת את ציר ה-y בגובה 9, ונקודת האפס שלה היא (3, 0). מצאו את משוואתה ובדקו שהשיפוע מתאים לתיאור.
מהחיתוך: b = 9, ולכן y = mx + 9. מציבים (3, 0): 0 = 3m + 9, כלומר m = -3. המשוואה היא y = -3x + 9. השיפוע -3 שלילי — מתאים ל"יורדת" ✓
תרגיל 5: אתגר: תעודה משתי תכונות מאתגר
פונקציה קווית עוברת בנקודה (0, 4) והיא חיובית עבור x < 2 ושלילית עבור x > 2. מצאו את משוואתה.
מהנקודה (0, 4): b = 4. המעבר מחיובי לשלילי מתרחש בנקודת האפס, ולכן נקודת האפס היא (2, 0). הפונקציה חיובית משמאל לאפס ושלילית מימין — כלומר היא יורדת. מציבים (2, 0) ב-y = mx + 4: 0 = 2m + 4, כלומר m = -2. המשוואה היא y = -2x + 4.
תרגיל 6: קריאה מהמשוואה קל
רשמו את השיפוע ואת נקודת החיתוך עם ציר ה-y של y = -3x + 12, וציינו אם הפונקציה עולה או יורדת.
השיפוע הוא -3 (המקדם של x), ונקודת החיתוך עם ציר ה-y היא (0, 12) (המספר החופשי).

השיפוע שלילי, ולכן הפונקציה יורדת.
תרגיל 7: נקודת אפס קל
מצאו את נקודת האפס של y = 4x - 20.
מציבים y = 0: 0 = 4x - 20, כלומר 4x = 20 ומכאן x = 5.

נקודת האפס היא (5, 0).

בדיקה: 4 · 5 - 20 = 0 ✓
תרגיל 8: תעודת זהות מלאה בינוני
מלאו את חמשת פרטי תעודת הזהות של y = -2x + 8.
שיפוע: -2.

חיתוך עם ציר ה-y: (0, 8).

נקודת אפס: 0 = -2x + 8, כלומר x = 4; הנקודה (4, 0).

עלייה/ירידה: m < 0, ולכן יורדת.

חיוביות/שליליות: יורדת ואפס ב-x = 4, ולכן y > 0 עבור x < 4 ו-y < 0 עבור x > 4.
תרגיל 9: משחזרים משוואה בינוני
פונקציה קווית חותכת את ציר ה-y בנקודה (0, -3) ואת ציר ה-x בנקודה (6, 0). מצאו את השיפוע ואת משוואת הישר.
מהחיתוך עם ציר ה-y: b = -3, ולכן y = mx - 3.

מציבים את נקודת האפס (6, 0): 0 = 6m - 3, כלומר 6m = 3 ומכאן m = 12.

המשוואה היא y = 12x - 3.

בדיקה: עבור x = 6 מתקבל 12 · 6 - 3 = 0 ✓
תרגיל 10: השוואה בין תעודות בינוני
נתונות f(x) = -5x + 3 ו-g(x) = 3x + 3. עבור כל שאלה ענו לפי תעודות הזהות, בלי שרטוט: (א) מי תלולה יותר? (ב) מי עולה ומי יורדת? (ג) האם יש להן נקודה משותפת על ציר ה-y?
(א) משווים ערך מוחלט של שיפועים: |-5| = 5 לעומת |3| = 3. הפונקציה f תלולה יותר.

(ב) f בעלת שיפוע שלילי — יורדת; g בעלת שיפוע חיובי — עולה.

(ג) לשתיהן b = 3, ולכן שתיהן עוברות בנקודה (0, 3) — זו הנקודה המשותפת.
תרגיל 11: אתגר: מהסימן אל המשוואה מאתגר
פונקציה קווית עוברת בנקודה (0, 8), היא חיובית עבור x < 4 ושלילית עבור x > 4. מצאו את משוואתה.
מהנקודה (0, 8): b = 8, ולכן y = mx + 8.

המעבר מחיובי לשלילי מתרחש בנקודת האפס, ולכן נקודת האפס היא (4, 0).

הפונקציה חיובית משמאל לאפס ושלילית מימין — כלומר היא יורדת.

מציבים (4, 0): 0 = 4m + 8, כלומר m = -2.

המשוואה היא y = -2x + 8. השיפוע שלילי — מתאים לכך שהפונקציה יורדת ✓
תרגיל 12: חיזוק נוסף: בודקים ומנמקים קל
בדקו האם הנקודה (4, 5) נמצאת על הישר y = 2x - 3. הסבירו את הבדיקה.
מציבים x = 4: מתקבל y = 2 · 4 - 3 = 5. מכיוון שהתקבל שיעור ה-y של הנקודה, היא נמצאת על הישר.
