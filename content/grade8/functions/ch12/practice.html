תרגול: מציאת משוואת הישר

פרק 12 · לפי שיפוע ונקודה ולפי שתי נקודות

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: שיפוע ונקודה קל
מצאו את משוואת הישר בכל סעיף.

א. השיפוע 2 והישר עובר בנקודה (1, 7).
ב. השיפוע (-1) והישר עובר בנקודה (4, 1).
א. השלד: y = 2x + b. מציבים: 7 = 2 · 1 + b, כלומר 7 = 2 + b ומכאן b = 5.
התשובה: y = 2x + 5. בדיקה: 2 + 5 = 7 ✓

ב. השלד: y = -x + b. מציבים: 1 = -4 + b ומכאן b = 5.
התשובה: y = -x + 5. בדיקה: -4 + 5 = 1 ✓
תרגיל 2: משתי נקודות בינוני
מצאו את משוואת הישר העובר בנקודות (1, 5) ו-(4, 14), ובדקו את התשובה בשתי הנקודות.
השיפוע: m = 14 - 54 - 1 = 93 = 3.

השלד: y = 3x + b. מציבים את (1, 5): 5 = 3 + b ומכאן b = 2.

התשובה: y = 3x + 2.

בדיקה: עבור x = 1 מתקבל 3 + 2 = 5 ✓, ועבור x = 4 מתקבל 12 + 2 = 14 ✓
תרגיל 3: שתי נקודות עם שיעורים שליליים בינוני
מצאו את משוואת הישר העובר בנקודות (-3, 8) ו-(1, -4).
נסמן (x1, y1) = (-3, 8) ו-(x2, y2) = (1, -4) ונשמור על הסדר:

m = -4 - 81 - (-3) = -124 = -3

מציבים את (1, -4) ב-y = -3x + b: -4 = -3 + b ומכאן b = -1.

התשובה: y = -3x - 1.

בדיקה: עבור x = -3 מתקבל 9 - 1 = 8 ✓, ועבור x = 1 מתקבל -3 - 1 = -4 ✓
תרגיל 4: מקרים מיוחדים בינוני
מצאו את משוואת הישר בכל סעיף, והסבירו במה הוא מיוחד.

א. הישר עובר ב-(2, -5) וב-(6, -5).
ב. הישר עובר ב-(-4, 1) וב-(-4, 7).
א. לשתי הנקודות אותו שיעור שני, ולכן m = -5 - (-5)6 - 2 = 04 = 0. השיפוע אפס, הישר אופקי, ומשוואתו y = -5.

ב. לשתי הנקודות אותו שיעור ראשון, ולכן המכנה הוא -4 - (-4) = 0. חילוק באפס אינו מוגדר, ולכן לישר אין שיפוע ואין לו צורת y = mx + b. זהו ישר אנכי שמשוואתו x = -4 (וכזכור, ישר אנכי אינו פונקציה).
תרגיל 5: אתגר: חבילת הגלישה מאתגר
בחבילת גלישה משלמים תשלום קבוע לחודש ועוד מחיר קבוע לכל ג'יגה. חודש שבו נצרכו 3 ג'יגה עלה 62 ש"ח, וחודש שבו נצרכו 7 ג'יגה עלה 86 ש"ח.

א. מצאו את המשוואה הקושרת בין מספר הג'יגה למחיר.
ב. מה משמעות השיפוע ומה משמעות ה-b בסיפור?
ג. כמה יעלה חודש שבו נצרכו 10 ג'יגה?
א. הנתונים הם הנקודות (3, 62) ו-(7, 86).

m = 86 - 627 - 3 = 244 = 6

מציבים את (3, 62) ב-y = 6x + b: 62 = 18 + b ומכאן b = 44.

התשובה: y = 6x + 44. בדיקה: עבור x = 7 מתקבל 42 + 44 = 86 ✓

ב. השיפוע 6 הוא המחיר לכל ג'יגה — 6 ש"ח. הערך b = 44 הוא התשלום הקבוע לחודש, גם אם לא נצרכה אף ג'יגה.

ג. מציבים x = 10: 6 · 10 + 44 = 104 ש"ח.
תרגיל 6: שיפוע ונקודה קל
מצאו את משוואת הישר שהשיפוע שלו 3 והוא עובר בנקודה (2, 4).
השלד: y = 3x + b. מציבים x = 2 ו-y = 4: 4 = 6 + b, ומכאן b = -2.

התשובה: y = 3x - 2. בדיקה: 3 · 2 - 2 = 4 ✓
תרגיל 7: שתי נקודות פשוטות קל
מצאו את משוואת הישר העובר בנקודות (1, 2) ו-(3, 6).
m = 6 - 23 - 1 = 42 = 2.

מציבים (1, 2) ב-y = 2x + b: 2 = 2 + b, ומכאן b = 0.

התשובה: y = 2x — ישר העובר בראשית הצירים. בדיקה: 2 · 3 = 6 ✓
תרגיל 8: שתי נקודות ושיפוע שלילי בינוני
מצאו את משוואת הישר העובר בנקודות (-2, 3) ו-(2, -5), ובדקו בשתי הנקודות.
נסמן (x1, y1) = (-2, 3) ו-(x2, y2) = (2, -5):

m = -5 - 32 - (-2) = -84 = -2

מציבים (2, -5): -5 = -4 + b, ומכאן b = -1.

התשובה: y = -2x - 1.

בדיקה: עבור x = 2 מתקבל -4 - 1 = -5 ✓, ועבור x = -2 מתקבל 4 - 1 = 3 ✓
תרגיל 9: אופקי או אנכי בינוני
מצאו את משוואת הישר בכל סעיף:

א. הישר עובר ב-(-1, 6) וב-(4, 6).
ב. הישר עובר ב-(7, 0) וב-(7, -5).
א. שיעורי ה-y שווים, ולכן m = 6 - 64 - (-1) = 0 והישר אופקי: y = 6.

ב. שיעורי ה-x שווים, ולכן המכנה הוא 7 - 7 = 0 והשיפוע אינו מוגדר. זהו ישר אנכי ומשוואתו x = 7 — אין לו כלל צורת y = mx + b.
תרגיל 10: אתגר: הנר הנשרף מאתגר
נר נשרף בקצב קבוע. אחרי 2 שעות גובהו היה 19 ס"מ, ואחרי 6 שעות גובהו היה 11 ס"מ.

א. מצאו את המשוואה הקושרת בין הזמן לגובה הנר.
ב. מה היה גובהו ההתחלתי?
ג. אחרי כמה שעות ייגמר הנר?
א. הנתונים הם הנקודות (2, 19) ו-(6, 11).

m = 11 - 196 - 2 = -84 = -2

מציבים (2, 19) ב-y = -2x + b: 19 = -4 + b, ומכאן b = 23.

המשוואה: y = -2x + 23. בדיקה: -12 + 23 = 11 ✓

ב. הגובה ההתחלתי הוא הערך עבור x = 0, כלומר 23 ס"מ.

ג. הנר נגמר כאשר y = 0: פותרים -2x + 23 = 0 ומקבלים x = 11.5 שעות.
תרגיל 11: אתגר: טעות הסימן מאתגר
תלמיד חישב את השיפוע של הישר העובר ב-(1, 9) וב-(4, 3) וכתב: m = 9 - 34 - 1 = 2. הסבירו מה שגוי, מצאו את המשוואה הנכונה, וודאו אותה בשתי הנקודות.
הטעות: במונה נלקח ההפרש מהנקודה השנייה אל הראשונה, ובמכנה מהראשונה אל השנייה — כלומר הסדר לא היה עקבי, ולכן הסימן התהפך.

חישוב נכון, עם (x1, y1) = (1, 9) ו-(x2, y2) = (4, 3):

m = 3 - 94 - 1 = -63 = -2

מציבים (1, 9) ב-y = -2x + b: 9 = -2 + b, ומכאן b = 11.

התשובה: y = -2x + 11.

בדיקה: עבור x = 1 מתקבל -2 + 11 = 9 ✓, ועבור x = 4 מתקבל -8 + 11 = 3 ✓
