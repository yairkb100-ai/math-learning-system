תרגול: אי-שוויונות וישרים

פרק 13 · מתי פונקציה אחת גדולה מהשנייה — גרפית ואלגברית

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: מעל הציר ומתחתיו קל
נתונה הפונקציה f(x) = 5x - 10.

א. עבור אילו ערכי x הגרף נמצא מעל ציר ה-x?
ב. עבור אילו ערכי x הגרף נמצא מתחת לציר ה-x?
א. פותרים 5x - 10 > 0, כלומר 5x > 10 ומכאן x > 2.

ב. פותרים 5x - 10 < 0, כלומר 5x < 10 ומכאן x < 2.

בשני הסעיפים חילקנו ב-5, שהוא חיובי, ולכן הסימן לא התהפך. אפס הפונקציה הוא x = 2, והוא הגבול בין שני התחומים.
תרגיל 2: קוראים את התשובה מהגרף קל
שני ישרים, f ו-g, נחתכים בנקודה (4, 5). השיפוע של f הוא 3 והשיפוע של g הוא 1.

א. עבור אילו ערכי x מתקיים f(x) > g(x)?
ב. עבור אילו ערכי x מתקיים f(x) < g(x)?
הישר f תלול יותר (שיפוע 3 לעומת 1), ולכן מימין לנקודת המפגש הוא העליון ומשמאלה הוא התחתון.

א. f(x) > g(x) כאשר x > 4.

ב. f(x) < g(x) כאשר x < 4.

ב-x = 4 עצמו שתי הפונקציות שוות, ולכן הוא אינו שייך לאף אחד משני התחומים.
תרגיל 3: השוואה בין שתי פונקציות בינוני
נתונות f(x) = 3x + 2 ו-g(x) = x + 8. עבור אילו ערכי x מתקיים f(x) > g(x)? מצאו גם את נקודת המפגש וסמנו את הפתרון על ציר המספרים.
3x + 2 > x + 8 ⇒ 2x > 6 ⇒ x > 3

נקודת המפגש: מ-3x + 2 = x + 8 מקבלים x = 3 ואז y = 11, כלומר (3, 11).

הסימון על הציר: עיגול ריק ב-3 (הסימן הוא >) וחץ הפונה ימינה.

בדיקה: עבור x = 5 מתקבל f = 17 ו-g = 13 ✓
תרגיל 4: זהירות מהמספר השלילי בינוני
פתרו את האי-שוויון -2x + 5 ≤ 1, ובדקו את התשובה בהצבה של שני ערכים.
מעבירים את 5: -2x ≤ -4.

מחלקים ב-(-2), שהוא שלילי, ולכן הופכים את הסימן: x ≥ 2.

בדיקה: עבור x = 2 מתקבל -4 + 5 = 1, ואכן 1 ≤ 1 ✓. עבור x = 3 מתקבל -6 + 5 = -1 ≤ 1 ✓. עבור x = 0 מתקבל 5, שאינו קטן או שווה ל-1 ✗

הסימון: עיגול מלא ב-2 וחץ ימינה.
תרגיל 5: אתגר: שני מכוני כושר מאתגר
מכון א' גובה דמי הרשמה של 100 ש"ח ועוד 10 ש"ח לכל ביקור. מכון ב' גובה דמי הרשמה של 40 ש"ח ועוד 20 ש"ח לכל ביקור.

א. כתבו פונקציה לעלות הכוללת בכל מכון לפי מספר הביקורים x.
ב. מצאו מתי שני המכונים עולים אותו דבר.
ג. עבור אילו מספרי ביקורים מכון א' זול יותר? הסבירו את התשובה במילים.
א. מכון א': f(x) = 10x + 100. מכון ב': g(x) = 20x + 40.

ב. פותרים 10x + 100 = 20x + 40, כלומר 60 = 10x ומכאן x = 6. בשישה ביקורים שני המכונים עולים 160 ש"ח.

ג. פותרים 10x + 100 < 20x + 40, כלומר 60 < 10x ומכאן x > 6. מכון א' זול יותר החל משבעה ביקורים ומעלה.

במילים: דמי ההרשמה של מכון א' יקרים יותר, אבל כל ביקור בו זול יותר. מי שמתאמן מעט משלם בעיקר על ההרשמה ולכן ב' עדיף לו; מי שמתאמן הרבה מרוויח מהמחיר הנמוך לביקור, והחיסכון מכסה את ההרשמה היקרה.
תרגיל 6: אי-שוויון בסיסי קל
פתרו את האי-שוויון 6x - 12 > 0 וכתבו את התשובה כתחום.
מעבירים: 6x > 12. מחלקים ב-6, שהוא חיובי, ולכן הסימן נשאר: x > 2.

בדיקה: עבור x = 3 מתקבל 6, שאכן גדול מ-0 ✓
תרגיל 7: חילוק במספר שלילי קל
פתרו את האי-שוויון -4x ≥ 12.
מחלקים את שני האגפים ב-(-4), שהוא מספר שלילי, ולכן הופכים את סימן האי-שוויון: x ≤ -3.

בדיקה: עבור x = -3 מתקבל 12 ≥ 12 ✓; עבור x = 0 מתקבל 0, שאינו גדול או שווה ל-12 ✗
תרגיל 8: השוואה בין שני ביטויים בינוני
עבור אילו ערכי x מתקיים 5x - 3 < 2x + 9?
מעבירים את ה-x לאגף אחד ואת המספרים לשני: 3x < 12, ומכאן x < 4.

לא היה כאן שום היפוך — חילקנו ב-3, שהוא חיובי.

בדיקה: עבור x = 0 מתקבל -3 < 9 ✓; עבור x = 5 מתקבל 22 < 19 ✗
תרגיל 9: גרפית ואלגברית בינוני
נתונות f(x) = 3x - 1 ו-g(x) = x + 5. מצאו את נקודת המפגש של הגרפים, פתרו את f(x) > g(x), והסבירו כיצד רואים את התשובה בגרף.
נקודת המפגש: 3x - 1 = x + 5, כלומר 2x = 6 ומכאן x = 3, ואז y = 3 + 5 = 8. הנקודה היא (3, 8).

אלגברית: 3x - 1 > x + 5, כלומר 2x > 6 ומכאן x > 3.

בגרף: השיפוע של f הוא 3 ושל g הוא 1, ולכן f תלולה יותר ומימין לנקודת המפגש היא העליונה. שתי הדרכים נותנות x > 3 ✓
תרגיל 10: איזה מכון משתלם בינוני
מכון א' גובה 120 ש"ח הרשמה ועוד 8 ש"ח לביקור, ומכון ב' גובה 60 ש"ח הרשמה ועוד 12 ש"ח לביקור. עבור אילו מספרי ביקורים מכון א' זול יותר?
העלויות הן f(x) = 8x + 120 ו-g(x) = 12x + 60.

פותרים 8x + 120 < 12x + 60, כלומר 60 < 4x ומכאן x > 15.

התשובה: מ-16 ביקורים ומעלה מכון א' זול יותר. ב-15 ביקורים בדיוק שניהם עולים 240 ש"ח, ומתחת לכך מכון ב' זול יותר.
תרגיל 11: אתגר: סוגריים והיפוך מאתגר
פתרו את האי-שוויון 2(x - 3) ≥ 5x + 6 וסמנו את הפתרון על ציר המספרים.
פותחים סוגריים: 2x - 6 ≥ 5x + 6.

מעבירים: 2x - 5x ≥ 6 + 6, כלומר -3x ≥ 12.

מחלקים ב-(-3), שהוא שלילי, ולכן הופכים את הסימן: x ≤ -4.

הסימון: עיגול מלא ב-(-4) וחץ הפונה שמאלה.

בדיקה: עבור x = -4 מתקבל 2 · (-7) = -14 בצד אחד ו--20 + 6 = -14 בצד השני, ואכן -14 ≥ -14 ✓; עבור x = 0 מתקבל -6 ≥ 6 ✗
תרגיל 12: חיזוק נוסף: בודקים ומנמקים קל
בדקו האם הנקודה (3,7) נמצאת על הישר y=2x+1. הסבירו את הבדיקה.
מציבים x=3: מתקבל y=2cdot3+1=7. מכיוון שהתקבל שיעור ה־y של הנקודה, היא נמצאת על הישר.
