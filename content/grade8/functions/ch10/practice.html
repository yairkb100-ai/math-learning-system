תרגול: חיוביות, שליליות ואפסי הפונקציה

פרק 10 · מתי הגרף מעל הציר, מתי מתחתיו ואיפה הוא חוצה אותו

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: שלוש שאלות על גרף קל
לפניכם גרף הפונקציה y = x - 2:



א. מהו אפס הפונקציה?
ב. מתי הפונקציה חיובית?
ג. מתי הפונקציה שלילית?
א. הגרף חותך את ציר ה-x בנקודה (2, 0), ולכן האפס הוא x = 2.
ב. מימין לנקודת החיתוך הגרף מעל הציר: חיובית כאשר x > 2.
ג. משמאל לה הגרף מתחת לציר: שלילית כאשר x < 2.
תרגיל 2: בדרך אלגברית בינוני
נתונה הפונקציה y = 5x - 10. מצאו בלי לשרטט את אפס הפונקציה ואת תחומי החיוביות והשליליות.
מציבים y = 0: 5x - 10 = 0, ולכן x = 2 — זהו האפס.

השיפוע m = 5 חיובי (ישר עולה), ולכן שלילית לפני האפס וחיובית אחריו: שלילית כאשר x < 2, חיובית כאשר x > 2.

בדיקה: ב-x = 3 מקבלים y = 5 · 3 - 10 = 5 > 0 ✓
תרגיל 3: ישר יורד בינוני
נתונה הפונקציה y = -2x + 6.

א. מצאו את אפס הפונקציה ואת תחומי החיוביות והשליליות.
ב. הראו שקיים תחום שבו הפונקציה חיובית ויורדת בו-זמנית.
א. -2x + 6 = 0, ולכן x = 3. השיפוע שלילי — הישר יורד — ולכן חיובית לפני האפס: חיובית כאשר x < 3, שלילית כאשר x > 3.
ב. הישר יורד בכל מקום, ובתחום x < 3 הוא גם מעל הציר — שם הפונקציה חיובית ויורדת בו-זמנית. למשל ב-x = 0: y = 6 > 0, ובכל זאת הגרף בירידה.
תרגיל 4: אתגר: שתי פונקציות, שני סיפורים מאתגר
א. עבור y = 4x + 8 מצאו את האפס ואת תחומי החיוביות והשליליות.
ב. עבור הקו האופקי y = -2 קבעו: האם יש לו אפס? מהם תחומי החיוביות והשליליות שלו?
א. 4x + 8 = 0, ולכן x = -2. השיפוע חיובי, ולכן שלילית כאשר x < -2 וחיובית כאשר x > -2. בדיקה: ב-x = 0 מקבלים y = 8 > 0, ואכן 0 > -2 ✓
ב. הקו y = -2 אופקי ונמצא כולו מתחת לציר ה-x: הוא אינו חותך אותו לעולם, ולכן אין לו אפס. הפונקציה שלילית לכל x, ואין לה תחום חיוביות כלל.
תרגיל 5: אפס הפונקציה קל
מצאו את אפס הפונקציה y = 6x - 18 וכתבו את נקודת החיתוך עם ציר ה-x.
מציבים y = 0: 6x - 18 = 0, ולכן 6x = 18 ומכאן x = 3. נקודת החיתוך היא (3, 0).
תרגיל 6: תחומים בישר עולה בינוני
כתבו את תחומי החיוביות והשליליות של y = 3x - 12, ונמקו בעזרת סימן השיפוע.
האפס: 3x - 12 = 0 נותן x = 4. השיפוע 3 חיובי, ולכן הישר עולה: שלילי לפני האפס וחיובי אחריו.

חיובית כאשר x > 4, שלילית כאשר x < 4. בדיקה: עבור x = 5 מתקבל y = 3 — חיובי, כמצופה.
תרגיל 7: תחומים בישר יורד בינוני
כתבו את תחומי החיוביות והשליליות של y = -4x + 8, ונמקו.
האפס: -4x + 8 = 0 נותן x = 2. השיפוע (-4) שלילי, ולכן הישר יורד: חיובי לפני האפס ושלילי אחריו.

חיובית כאשר x < 2, שלילית כאשר x > 2. בדיקה: עבור x = 0 מתקבל y = 8 — חיובי, ואכן 0 < 2.
תרגיל 8: אתגר: יורדת וחיובית מאתגר
נתונה הפונקציה y = -2x + 10. הראו שהיא יורדת, ובכל זאת מצאו תחום שלם שבו היא חיובית. הסבירו מדוע אין בכך סתירה.
השיפוע הוא (-2), שלילי — ולכן הפונקציה יורדת בכל תחום ההגדרה.

האפס: -2x + 10 = 0 נותן x = 5. מכיוון שהישר יורד, הוא חיובי לפני האפס: הפונקציה חיובית בכל התחום x < 5. למשל עבור x = 1 מתקבל y = 8.

אין סתירה, כי מדובר בשתי שאלות שונות: עלייה וירידה מתארות לאן הגרף הולך, ואילו חיוביות ושליליות מתארות איפה הגרף נמצא ביחס לציר ה-x. הגרף יכול לגלוש כלפי מטה ועדיין להישאר מעל הציר, עד לרגע שבו הוא חוצה אותו.
