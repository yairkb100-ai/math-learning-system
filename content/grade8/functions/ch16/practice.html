תרגול: משוואות ואי-שוויונות עם ערך מוחלט

פרק 16 · שאלה על מרחק — ולכן בדרך כלל שני פתרונות

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: הצורה הפשוטה קל
פתרו:

א. |x| = 12
ב. |x| = 1
ג. |x| = -7
א. x = 12 או x = -12.
ב. x = 1 או x = -1.
ג. אין פתרון — ערך מוחלט אינו שלילי.
תרגיל 2: נקודה בפנים קל
פתרו ובדקו את שני הפתרונות:

א. |x - 7| = 4
ב. |x + 3| = 5
א. x - 7 = 4 נותן x = 11; x - 7 = -4 נותן x = 3. בדיקה: |11 - 7| = 4 ✓, |3 - 7| = 4 ✓.
ב. x + 3 = 5 נותן x = 2; x + 3 = -5 נותן x = -8. בדיקה: |2 + 3| = 5 ✓, |-8 + 3| = 5 ✓.
תרגיל 3: ביטוי בתוך הקווים בינוני
פתרו את |2x - 1| = 9.
2x - 1 = 9 נותן 2x = 10 ומכאן x = 5.
2x - 1 = -9 נותן 2x = -8 ומכאן x = -4.
בדיקה: |2 · 5 - 1| = |9| = 9 ✓ ו-|2 · (-4) - 1| = |-9| = 9 ✓
תרגיל 4: שני סוגי אי-שוויון בינוני
פתרו:

א. |x - 1| < 4
ב. |x - 1| ≥ 4
א. "קרוב": -4 < x - 1 < 4, ומכאן -3 < x < 5.
ב. "רחוק": x - 1 ≥ 4 או x - 1 ≤ -4, כלומר x ≥ 5 או x ≤ -3.
תרגיל 5: אתגר: בקרת איכות מאתגר
בקבוק תקין אם נפחו רחוק מ-1500 מ"ל בלא יותר מ-20 מ"ל. כתבו את התנאי כאי-שוויון עם ערך מוחלט, פתרו אותו, וכתבו את הנפח הקטן ביותר והגדול ביותר של בקבוק תקין.
מסמנים ב-v את הנפח. התנאי הוא |v - 1500| ≤ 20.

פותרים: -20 ≤ v - 1500 ≤ 20, ומוסיפים 1500 לכל חלק: 1480 ≤ v ≤ 1520.

הנפח הקטן ביותר של בקבוק תקין הוא 1480 מ"ל, והגדול ביותר 1520 מ"ל.
תרגיל 6: הצורה הפשוטה קל
פתרו: |x| = 11, |x| = 0, ו-|x| = -4.
|x| = 11: שני פתרונות, x = 11 או x = -11.

|x| = 0: פתרון יחיד, x = 0.

|x| = -4: אין פתרון — ערך מוחלט אינו שלילי.
תרגיל 7: משוואה עם נקודה בפנים קל
פתרו את |x - 8| = 5 ובדקו את שני הפתרונות.
x - 8 = 5 נותן x = 13; x - 8 = -5 נותן x = 3.

בדיקה: |13 - 8| = 5 ✓ ו-|3 - 8| = |-5| = 5 ✓
תרגיל 8: ביטוי בתוך הקווים בינוני
פתרו את |2x + 3| = 9.
2x + 3 = 9 נותן 2x = 6 ומכאן x = 3.

2x + 3 = -9 נותן 2x = -12 ומכאן x = -6.

בדיקה: |2 · 3 + 3| = |9| = 9 ✓ ו-|2 · (-6) + 3| = |-9| = 9 ✓
תרגיל 9: אי-שוויון "קרוב" בינוני
פתרו את |x - 5| ≤ 3 וכתבו את הפתרון כתחום.
"קרוב" — קטע אחד: -3 ≤ x - 5 ≤ 3.

מוסיפים 5 לכל חלק: 2 ≤ x ≤ 8.
תרגיל 10: אי-שוויון "רחוק" בינוני
פתרו את |x + 2| > 6 וכתבו את הפתרון כשני תחומים.
"רחוק" — שני תחומים: x + 2 > 6 או x + 2 < -6.

מכאן x > 4 או x < -8.
תרגיל 11: אתגר: מהפתרון אל המשוואה מאתגר
כתבו אי-שוויון עם ערך מוחלט שפתרונו הוא בדיוק הקטע 1 ≤ x ≤ 9.
מרכז הקטע הוא 1 + 92 = 5, והמרחק מהמרכז לכל קצה הוא 4.

לכן התנאי הוא "המרחק בין x ל-5 קטן או שווה ל-4": |x - 5| ≤ 4.

בדיקה: -4 ≤ x - 5 ≤ 4 נותן 1 ≤ x ≤ 9 ✓
תרגיל 12: חיזוק נוסף: בודקים כל פתרון קל
פתרו את |x - 3| = 7 והציבו את שני הפתרונות בחזרה במשוואה.
x - 3 = 7 נותן x = 10; x - 3 = -7 נותן x = -4.

בדיקה: |10 - 3| = |7| = 7 ✓ ו-|-4 - 3| = |-7| = 7 ✓
