תרגול: ריבוע של סכום

פרק 2 · הנוסחה (a+b)² = a² + 2ab + b² — פיתוח, מודל שטח וחישוב בעל פה

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: ישר מהנוסחה קל
פתחו לפי הנוסחה:

א. (x+1)2
ב. (x+6)2
א. x2 + 2 · x · 1 + 1 = x2 + 2x + 1.
ב. x2 + 2 · x · 6 + 36 = x2 + 12x + 36.
תרגיל 2: גם משתנים, גם מספרים בינוני
א. פתחו: (x+9)2
ב. חשבו בעל פה בעזרת הנוסחה: 212
א. x2 + 2 · x · 9 + 81 = x2 + 18x + 81.
ב. 212 = (20+1)2 = 400 + 2 · 20 · 1 + 1 = 400 + 40 + 1 = 441.
תרגיל 3: מקדם בריבוע בינוני
פתחו לפי הנוסחה: (5x+2)2.
כאן a=5x ו-b=2, ולכן a2 = (5x)2 = 25x2. מקבלים: 25x2 + 2 · 5x · 2 + 4 = 25x2 + 20x + 4.
תרגיל 4: אתגר: להשלים לריבוע מאתגר
א. פתחו: (2x+3y)2
ב. איזה מספר צריך לעמוד במקום הריק כדי שהביטוי x2 + 14x + □ יהיה ריבוע של סכום?
א. a=2x, b=3y: מקבלים (2x)2 + 2 · 2x · 3y + (3y)2 = 4x2 + 12xy + 9y2.
ב. האיבר האמצעי 14x הוא פעמיים מכפלת השורשים: 14x = 2 · x · 7, כלומר b = 7. לכן המספר החסר הוא 72 = 49, והביטוי הוא (x+7)2.
תרגיל 5: ריבוע פשוט נוסף קל
פתחו לפי הנוסחה: (x+8)2.
כאן a=x ו-b=8. (x+8)2 = x2 + 2 · x · 8 + 64 = x2 + 16x + 64.
תרגיל 6: ריבוע פשוט קל
פתחו לפי הנוסחה: (x+8)2.
x2 + 2 · x · 8 + 64 = x2 + 16x + 64.
תרגיל 7: בעל פה בינוני
חשבו בעזרת הנוסחה, בלי מחשבון: 332.
332 = (30+3)2 = 900 + 2 · 30 · 3 + 9 = 900 + 180 + 9 = 1089.
תרגיל 8: מקדם בריבוע בינוני
פתחו לפי הנוסחה: (6x+1)2.
a=6x, b=1: מקבלים (6x)2 + 2 · 6x · 1 + 1 = 36x2 + 12x + 1.
תרגיל 9: אתגר: שני משתנים מאתגר
פתחו לפי הנוסחה: (3a+2b)2.
a בנוסחה הוא 3a ו-b בנוסחה הוא 2b: מקבלים (3a)2 + 2 · 3a · 2b + (2b)2 = 9a2 + 12ab + 4b2.
תרגיל 10: אתגר: אימות בדרך הארוכה מאתגר
פתחו את (x+3)2 בשתי דרכים: א. בכתיבה (x+3)(x+3) וכפל כל איבר בכל איבר. ב. ישירות לפי הנוסחה. ודאו ששתי הדרכים נותנות אותה תוצאה.
א. (x+3)(x+3) = x2 + 3x + 3x + 9 = x2 + 6x + 9.
ב. לפי הנוסחה: a=x, b=3: x2 + 2 · x · 3 + 9 = x2 + 6x + 9. אותה תוצאה בדיוק — הנוסחה היא רק קיצור של הכפל המלא.
