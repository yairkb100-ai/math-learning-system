תרגול: פירוק בנוסחאות

פרק 5 · קריאת הנוסחאות בכיוון ההפוך — מהביטוי אל המכפלה

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: הפרש ריבועים בסיסי קל
פרקו לגורמים:

א. x2 - 16
ב. x2 - 100
א. 16 = 42, ולכן x2 - 16 = (x-4)(x+4).
ב. 100 = 102, ולכן x2 - 100 = (x-10)(x+10).
תרגיל 2: עם מקדמים בינוני
פרקו לגורמים:

א. 25x2 - 1
ב. 4x2 - 49
א. 25x2 = (5x)2 ו-1 = 12: הפירוק (5x-1)(5x+1).
ב. 4x2 = (2x)2 ו-49 = 72: הפירוק (2x-7)(2x+7).
תרגיל 3: ריבוע מושלם בינוני
פרקו לגורמים:

א. x2 + 8x + 16
ב. x2 - 14x + 49
א. הקצוות ריבועים: x2 ו-16 = 42. בדיקת האמצעי: 2 × x × 4 = 8x — מתאים. הפירוק: (x+4)2.
ב. הקצוות: x2 ו-49 = 72. בדיקת האמצעי: 2 × x × 7 = 14x — מתאים, והסימן שלילי. הפירוק: (x-7)2.
תרגיל 4: אתגר: לפרק עד הסוף מאתגר
פרקו לגורמים עד הסוף:

א. 5x2 - 45
ב. x4 - 81
א. קודם גורם משותף: 5x2 - 45 = 5(x2 - 9). בפנים הפרש ריבועים: 5(x-3)(x+3).
ב. x4 = (x2)2 ו-81 = 92: קודם (x2-9)(x2+9). הגורם x2 - 9 מתפרק שוב: (x-3)(x+3). הפירוק המלא: (x-3)(x+3)(x2+9). הגורם x2 + 9 הוא סכום ריבועים ואינו מתפרק.
תרגיל 5: עוד הפרש ריבועים קל
פרקו לגורמים: x2 - 36.
36 = 62, ולכן x2 - 36 = (x-6)(x+6).
תרגיל 6: הפרש ריבועים גדול קל
פרקו לגורמים: x2 - 169.
169 = 132, ולכן x2 - 169 = (x-13)(x+13).
תרגיל 7: ריבוע של הפרש בינוני
פרקו לגורמים: x2 - 16x + 64.
הקצוות ריבועים: x2 ו-64 = 82. בדיקת האמצעי: 2 × x × 8 = 16x — מתאים, בסימן שלילי. הפירוק: (x-8)2.
תרגיל 8: גורם משותף ואז נוסחה בינוני
פרקו לגורמים עד הסוף: 6x2 - 54.
גורם משותף 6: 6(x2 - 9). בפנים הפרש ריבועים: 6(x-3)(x+3).
תרגיל 9: אתגר: שני שלבים לריבוע מאתגר
פרקו לגורמים עד הסוף: 2x2 + 12x + 18.
גורם משותף 2: 2(x2 + 6x + 9). בפנים ריבוע מושלם — 2 × x × 3 = 6x מתאים: 2(x+3)2.
תרגיל 10: אתגר: לבדוק ולתקן מאתגר
תלמיד פירק: x2 + 20x + 100 = (x+10)(x-10). האם הפירוק נכון? אם לא, מצאו את הפירוק הנכון והסבירו את הטעות.
לא נכון. (x+10)(x-10) הוא הפרש ריבועים ומתפרק ל-x2-100, לא לביטוי המקורי (שיש בו שלושה איברים!). הביטוי x2+20x+100 הוא ריבוע מושלם: הקצוות x2 ו-100=102, והאמצעי 2 · x · 10 = 20x מתאים. הפירוק הנכון: x2+20x+100 = (x+10)2. הטעות: בלבול בין תבנית הפרש ריבועים (שני איברים, בלי אמצעי) לתבנית ריבוע מושלם (שלושה איברים).
תרגיל 11: משוואה עם גורם משותף — בסיסי קל
פתרו את המשוואה: x2 - 5x = 0.
מוציאים x כגורם משותף: x2-5x = x(x-5). המשוואה: x(x-5)=0, ולכן x=0 או x-5=0, כלומר x=0 או x=5.
תרגיל 12: משוואה עם מקדם שלילי בינוני
פתרו את המשוואה: 4x2 - 8x = 0.
גורם משותף 4x: 4x2-8x = 4x(x-2). המשוואה: 4x(x-2)=0, ולכן 4x=0 או x-2=0, כלומר x=0 או x=2.
תרגיל 13: צמצום שבר בסיסי קל
צמצמו את השבר: x2-25x+5, וציינו את תנאי ההגדרה.
המונה הפרש ריבועים: x2-25=(x-5)(x+5). לכן x2-25x+5 = (x-5)(x+5)x+5 = x-5, בתנאי x ≠ -5.
תרגיל 14: קודם גורם משותף, אז צמצום בינוני
צמצמו את השבר: 3x2-27x+3, וציינו את תנאי ההגדרה.
קודם מוציאים גורם משותף מהמונה: 3x2-27 = 3(x2-9) = 3(x-3)(x+3). עכשיו מצמצמים: 3(x-3)(x+3)x+3 = 3(x-3) = 3x-9, בתנאי x ≠ -3.
תרגיל 15: חיזוק נוסף: בודקים ומנמקים בינוני
פתחו את (x+3)2 בעזרת הנוסחה, ואז הציבו x=2 כדי לבדוק.
(x+3)2=x2+6x+9. עבור x=2 מתקבלים בשני הצדדים 25: משמאל (2+3)2, ומימין 4+12+9.
