דף עבודה — פרק 5: פירוק בנוסחאות

קריאת הנוסחאות בכיוון ההפוך — מהביטוי אל המכפלה
שם: כיתה: תאריך:
פירוק לגורמים = כתיבת ביטוי כמכפלה. תבנית הפרש ריבועים: a² − b² = (a − b)(a + b). תבנית ריבוע מושלם: שני הקצוות ריבועים, והאמצעי הוא פעמיים מכפלת השורשים — אז הביטוי שווה לריבוע של סוגריים. סדר העבודה: תמיד קודם מוציאים גורם משותף, ורק אחר כך בודקים נוסחה — וממשיכים לפרק עד שאף גורם לא מתפרק עוד. בדיקה: פתחו חזרה וודאו שקיבלתם את הביטוי המקורי. שני שימושים לפירוק: פתרון משוואה מהצורה ax² + bx = 0 על ידי הוצאת x כגורם משותף ועיקרון מכפלת האפס, וצמצום שברים אלגבריים על ידי פירוק המונה או המכנה — תמיד עם ציון תנאי ההגדרה.

שאלה 17 — צמצום שבר עם גורם משותף בינוני

צמצמו את השבר עד הסוף וציינו תנאי הגדרה: (2x² − 18)/(x + 3)

שאלה 18 — אתגר: משוואה ושבר יחד מאתגר

א. פתרו את המשוואה x² − 9x = 0. ב. צמצמו את השבר (x² − 9)/(x + 3) וציינו תנאי הגדרה.

שאלה 5. רק x² − 4 מתפרק: (x − 2)(x + 2). סכום ריבועים x² + 4 אינו מתפרק.
שאלה 6. א. (2x − 3)(2x + 3)   ב. (5x − 4)(5x + 4)
שאלה 7. א. (x − 9)²   ב. (x + 10)²
שאלה 8. 3(x² − 4) = 3(x − 2)(x + 2)
שאלה 9. 2(x² + 8x + 16) = 2(x + 4)²
שאלה 10. א. ריבוע מושלם: 2 × x × 6 = 12x מתאים, ולכן (x + 6)². ב. לא ריבוע מושלם — האמצעי היה צריך להיות 12x ולא 10x.
שאלה 11. (x² − 4)(x² + 4) = (x − 2)(x + 2)(x² + 4)
שאלה 12. 5(x² − 16) = 5(x − 4)(x + 4)
שאלה 13. 2(x⁴ − 16) = 2(x² − 4)(x² + 4) = 2(x − 2)(x + 2)(x² + 4)
שאלה 14. x(x − 7) = 0 ⟵ x = 0 או x = 7
שאלה 15. 6x(x + 3) = 0 ⟵ x = 0 או x = −3
שאלה 16. (x − 7)(x + 7)/(x + 7) = x − 7, בתנאי x ≠ −7
שאלה 17. 2(x² − 9) = 2(x − 3)(x + 3) ⟵ 2(x − 3) = 2x − 6, בתנאי x ≠ −3
שאלה 18. א. x(x − 9) = 0 ⟵ x = 0 או x = 9. ב. (x − 3)(x + 3)/(x + 3) = x − 3, בתנאי x ≠ −3
