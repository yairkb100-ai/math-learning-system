תרגול: הצורה הכללית והקודקוד

פרק 4 · y = ax² + bx + c - מציאת הקודקוד וציר הסימטריה

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: זיהוי המקדמים קל
רשמו לכל פונקציה את a, את b ואת c:

א. y = x2 + 5x - 2
ב. y = -3x2 + x
ג. y = 4x2 - 9
ד. y = x2
א. a = 1, b = 5, c = -2.
ב. a = -3, b = 1, c = 0 (אין איבר חופשי).
ג. a = 4, b = 0, c = -9 (אין איבר עם x).
ד. a = 1, b = 0, c = 0.
תרגיל 2: קודקוד וציר סימטריה קל
נתונה הפונקציה y = x2 - 8x + 12.

א. מצאו את שיעורי הקודקוד.
ב. כתבו את משוואת ציר הסימטריה.
ג. האם הקודקוד הוא מינימום או מקסימום?
א. a = 1, b = -8, ולכן x = --82 = 4. מציבים: y = 16 - 32 + 12 = -4. הקודקוד (4, -4).
ב. ציר הסימטריה: x = 4.
ג. a = 1 > 0, ולכן הפרבולה נפתחת כלפי מעלה והקודקוד הוא נקודת מינימום.
תרגיל 3: הערך המקסימלי בינוני
מהו הערך הגדול ביותר שמקבלת הפונקציה y = -x2 + 4x + 5, ועבור איזה x הוא מתקבל?
a = -1 < 0, ולכן קיים ערך מקסימלי בקודקוד. x = -42 · (-1) = 2. מציבים: y = -4 + 8 + 5 = 9.

הערך המקסימלי הוא 9, והוא מתקבל עבור x = 2.
תרגיל 4: בת הזוג הסימטרית בינוני
הנקודה (1, -6) נמצאת על הפרבולה y = x2 - 10x + 3.

א. ודאו זאת בהצבה.
ב. מצאו את הנקודה הסימטרית לה ביחס לציר הסימטריה.
א. מציבים x = 1: y = 1 - 10 + 3 = -6 — הנקודה אכן על הפרבולה.
ב. ציר הסימטריה: x = --102 = 5. הנקודה (1, -6) נמצאת 4 יחידות משמאל לציר, ולכן בת זוגה נמצאת 4 יחידות מימין לו, ב-x = 9. בדיקה: 81 - 90 + 3 = -6. הנקודה הסימטרית היא (9, -6).
תרגיל 5: אתגר - שחזור מקדם מהקודקוד מאתגר
קודקוד הפרבולה y = ax2 - 8x + 3 נמצא ב-x = 1.

א. מצאו את a.
ב. מצאו את שיעור ה-y של הקודקוד וקבעו אם זהו מינימום או מקסימום.
א. לפי הנוסחה --82a = 1, כלומר 82a = 1, ומכאן 2a = 8 ו-a = 4.
ב. הפונקציה היא y = 4x2 - 8x + 3. מציבים x = 1: y = 4 - 8 + 3 = -1. הקודקוד הוא (1, -1), ומכיוון ש-a = 4 > 0 זו נקודת מינימום.
תרגיל 6: זיהוי מהיר של המקדמים קל
רשמו את a, את b ואת c של הפונקציה y = x2 - 7x + 2.
a = 1, b = -7, c = 2. שימו לב שהסימן המינוס שייך למקדם b.
תרגיל 7: ציר סימטריה קל
מהי משוואת ציר הסימטריה של הפרבולה y = x2 + 8x - 1?
a = 1, b = 8, ולכן x = -82 · 1 = -4. ציר הסימטריה הוא הישר x = -4.
תרגיל 8: קודקוד וערך מקסימלי בינוני
מצאו את קודקוד הפרבולה y = -2x2 + 12x - 7 ואת הערך המקסימלי של הפונקציה.
a = -2, b = 12, ולכן x = -122 · (-2) = -12-4 = 3. מציבים: y = -2 · 9 + 36 - 7 = -18 + 36 - 7 = 11.

הקודקוד הוא (3, 11), ומכיוון ש-a < 0 הערך המקסימלי של הפונקציה הוא 11.
תרגיל 9: אתגר - שחזור הפונקציה מהקודקוד מאתגר
קודקוד הפרבולה y = x2 + bx + c הוא (3, -4). מצאו את b ואת c.
לפי הנוסחה -b2 · 1 = 3, ולכן b = -6.

מציבים את הקודקוד בפונקציה y = x2 - 6x + c: -4 = 9 - 18 + c, כלומר -4 = -9 + c ומכאן c = 5.

הפונקציה היא y = x2 - 6x + 5. בדיקה: עבור x = 3 מתקבל 9 - 18 + 5 = -4.
תרגיל 10: חיזוק נוסף: בודקים ומנמקים קל
בפונקציה y=x2 מצאו את ערך הפונקציה עבור x=-3 והסבירו מדוע הוא חיובי.
(-3)2=9. החזקה השנייה מכפילה שני מספרים שליליים, ולכן התוצאה חיובית.
