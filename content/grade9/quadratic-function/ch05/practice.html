תרגול: חיתוך עם הצירים וחקר הפרבולה

פרק 5 · אפסי הפונקציה, הדיסקרימיננט, עלייה וירידה, חיוביות ושליליות

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: חיתוך עם ציר ה-y קל
רשמו לכל פונקציה את נקודת החיתוך עם ציר ה-y:

א. y = x2 + 5x - 3
ב. y = 2x2 - 7
ג. y = -x2 + 4x
מציבים בכל סעיף x = 0, ומקבלים את האיבר החופשי:

א. (0, -3).
ב. (0, -7).
ג. (0, 0) — הפרבולה עוברת בראשית הצירים.
תרגיל 2: חיתוך עם ציר ה-x קל
מצאו את נקודות החיתוך עם ציר ה-x:

א. y = x2 - 16
ב. y = x2 - 5x
א. פותרים x2 - 16 = 0, כלומר x2 = 16, ומכאן x = 4 או x = -4. הנקודות: (4, 0) ו-(-4, 0).
ב. פותרים x2 - 5x = 0; מוציאים גורם משותף: x(x-5) = 0, ומכאן x = 0 או x = 5. הנקודות: (0, 0) ו-(5, 0).
תרגיל 3: ספירת נקודות חיתוך בינוני
בלי לפתור משוואות, קבעו כמה נקודות חיתוך יש לכל פרבולה עם ציר ה-x:

א. y = x2 - 6x + 5
ב. y = x2 + 4x + 4
ג. y = x2 + x + 5
א. Δ = 36 - 20 = 16 > 0 — שתי נקודות חיתוך.
ב. Δ = 16 - 16 = 0 — נקודה אחת; הפרבולה משיקה לציר בקודקוד (-2, 0).
ג. Δ = 1 - 20 = -19 < 0 — אין נקודות חיתוך.
תרגיל 4: עלייה, ירידה וסימן בינוני
נתונה הפונקציה y = x2 - 4x + 3.

א. מצאו את הקודקוד ואת נקודות החיתוך עם ציר ה-x.
ב. רשמו את תחומי העלייה והירידה.
ג. רשמו את תחומי החיוביות והשליליות.
א. הקודקוד: x = 42 = 2 ו-y = 4 - 8 + 3 = -1, כלומר (2, -1). חיתוך עם ציר ה-x: (x-1)(x-3) = 0, ומכאן (1, 0) ו-(3, 0).
ב. a = 1 > 0, ולכן הפונקציה יורדת בתחום x < 2 ועולה בתחום x > 2.
ג. שלילית בין השורשים: 1 < x < 3; חיובית בתחומים x < 1 ו-x > 3.
תרגיל 5: אתגר - חקר מלא ושרטוט מאתגר
חקרו את הפונקציה y = -x2 - 2x + 3 חקר מלא — כיוון פתיחה, קודקוד, חיתוך עם שני הצירים, ערך קיצון, תחומי עלייה וירידה ותחומי חיוביות ושליליות — ושרטטו את הגרף.
כיוון: a = -1 < 0 — פתיחה כלפי מטה.

קודקוד: x = --22 · (-1) = 2-2 = -1, ומציבים: y = -1 + 2 + 3 = 4. הקודקוד (-1, 4), וזהו הערך המקסימלי של הפונקציה.

חיתוך עם ציר ה-y: (0, 3).

חיתוך עם ציר ה-x: -x2 - 2x + 3 = 0; כופלים ב-(-1): x2 + 2x - 3 = 0, כלומר (x+3)(x-1) = 0, ומכאן (-3, 0) ו-(1, 0).

עלייה וירידה: עולה עבור x < -1, יורדת עבור x > -1.

חיוביות ושליליות: חיובית בין השורשים, -3 < x < 1; שלילית בתחומים x < -3 ו-x > 1.

לשרטוט: מסמנים את הקודקוד ואת שלוש נקודות החיתוך, מוסיפים את הנקודה הסימטרית ל-(0, 3) שהיא (-2, 3), ומעבירים עקומה חלקה.
תרגיל 6: חיתוך עם שני הצירים קל
מצאו את נקודות החיתוך של הפרבולה y = x2 - 4 עם הצירים.
עם ציר ה-y: מציבים x = 0 ומקבלים (0, -4).

עם ציר ה-x: פותרים x2 - 4 = 0, כלומר x2 = 4, ומכאן x = 2 או x = -2. הנקודות: (2, 0) ו-(-2, 0).
תרגיל 7: ספירה בעזרת הדיסקרימיננט קל
כמה נקודות חיתוך עם ציר ה-x יש לפרבולה y = x2 + x + 4?
Δ = 12 - 4 · 1 · 4 = 1 - 16 = -15 < 0, ולכן אין אף נקודת חיתוך. מכיוון ש-a > 0, הפרבולה כולה מעל ציר ה-x.
תרגיל 8: חקר בסיסי בינוני
נתונה הפונקציה y = x2 - 2x - 3. מצאו את הקודקוד, את נקודות החיתוך עם הצירים ואת הערך המינימלי.
קודקוד: x = 22 = 1 ו-y = 1 - 2 - 3 = -4, כלומר (1, -4).

חיתוך עם ציר ה-y: (0, -3).

חיתוך עם ציר ה-x: (x-3)(x+1) = 0, ומכאן (3, 0) ו-(-1, 0).

המקדם a = 1 > 0, ולכן הערך המינימלי של הפונקציה הוא (-4) והוא מתקבל עבור x = 1.
תרגיל 9: אתגר - חקר פרבולה יורדת מאתגר
חקרו את הפונקציה y = -x2 + 6x - 8: קודקוד, נקודות חיתוך עם הצירים, ערך קיצון ותחום חיוביות.
a = -1 < 0 — פתיחה כלפי מטה.

קודקוד: x = -62 · (-1) = 3, ומציבים: y = -9 + 18 - 8 = 1. הקודקוד (3, 1), והערך המקסימלי הוא 1.

חיתוך עם ציר ה-y: (0, -8).

חיתוך עם ציר ה-x: כופלים ב-(-1) ופותרים x2 - 6x + 8 = 0, כלומר (x-2)(x-4) = 0, ומכאן (2, 0) ו-(4, 0).

הפתיחה כלפי מטה, ולכן הפונקציה חיובית בין השורשים: 2 < x < 4.
תרגיל 10: חיזוק נוסף: בודקים ומנמקים קל
בפונקציה y=x2 מצאו את ערך הפונקציה עבור x=-3 והסבירו מדוע הוא חיובי.
(-3)2=9. החזקה השנייה מכפילה שני מספרים שליליים, ולכן התוצאה חיובית.
