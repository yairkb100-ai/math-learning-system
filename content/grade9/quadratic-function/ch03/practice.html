תרגול: הזזות של הפרבולה

פרק 3 · הזזה אנכית, הזזה אופקית וצורת הקודקוד

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: קודקוד וציר סימטריה קל
מצאו את הקודקוד ואת ציר הסימטריה של כל פרבולה:

א. y = x2 + 7
ב. y = x2 - 1
ג. y = (x-6)2
ד. y = (x+2)2
א. הזזה אנכית למעלה: הקודקוד (0, 7), ציר הסימטריה x = 0.
ב. הזזה אנכית למטה: הקודקוד (0, -1), ציר הסימטריה x = 0.
ג. הסוגר מתאפס ב-x = 6: הקודקוד (6, 0), ציר הסימטריה x = 6.
ד. הסוגר מתאפס ב-x = -2: הקודקוד (-2, 0), ציר הסימטריה x = -2.
תרגיל 2: טבלה לפרבולה מוזזת קל
נתונה הפונקציה y = x2 - 4.

א. חשבו את ערכיה עבור x = -3, -2, -1, 0, 1, 2, 3.
ב. מהו הקודקוד?
ג. באילו נקודות הפרבולה חותכת את ציר ה-x?
א. הערכים לפי הסדר: 5, 0, -3, -4, -3, 0, 5. למשל עבור x = -3 מתקבל 9 - 4 = 5, ועבור x = 1 מתקבל 1 - 4 = -3.
ב. הקודקוד (0, -4) — הפרבולה הבסיסית הוזזה 4 יחידות למטה.
ג. שני ערכי y בטבלה שווים 0: הנקודות (-2, 0) ו-(2, 0).
תרגיל 3: צורת הקודקוד המלאה בינוני
לכל פונקציה מצאו את הקודקוד, את כיוון הפתיחה ואת הערך המינימלי או המקסימלי:

א. y = 2(x-1)2 + 5
ב. y = -3(x+4)2 - 2
א. הסוגר מתאפס ב-x = 1, ואז y = 5. הקודקוד (1, 5). מכיוון ש-a = 2 > 0 הפרבולה פתוחה כלפי מעלה, ולכן 5 הוא הערך המינימלי.
ב. הסוגר מתאפס ב-x = -4, ואז y = -2. הקודקוד (-4, -2). מכיוון ש-a = -3 < 0 הפרבולה פתוחה כלפי מטה, ולכן -2 הוא הערך המקסימלי — כל שאר ערכי הפונקציה קטנים ממנו.
תרגיל 4: כתיבת המשוואה מהקודקוד בינוני
כתבו את משוואת הפרבולה בכל סעיף:

א. קודקוד (4, -3) ומקדם a = 1.
ב. קודקוד (-1, 5) ומקדם a = -2.
א. מציבים בצורת הקודקוד: y = (x-4)2 - 3. בדיקה: עבור x = 4 מתקבל 0 - 3 = -3.
ב. כאן p = -1, ולכן בסוגר נכתב x + 1: y = -2(x+1)2 + 5. בדיקה: עבור x = -1 מתקבל 0 + 5 = 5, ועבור x = 0 מתקבל -2 · 1 + 5 = 3 — ערך נמוך יותר, כמצופה מפרבולה הפתוחה כלפי מטה.
תרגיל 5: אתגר: חקירה קצרה מאתגר
נתונה הפונקציה y = (x-3)2 - 4.

א. מצאו את הקודקוד ואת ציר הסימטריה.
ב. מצאו את נקודת החיתוך עם ציר ה-y.
ג. מצאו את נקודות החיתוך עם ציר ה-x.
ד. מהו הערך המינימלי של הפונקציה?
א. הסוגר מתאפס ב-x = 3, ואז y = -4. הקודקוד (3, -4) וציר הסימטריה x = 3.
ב. מציבים x = 0: y = (0-3)2 - 4 = 9 - 4 = 5. הנקודה (0, 5).
ג. מציבים y = 0: (x-3)2 - 4 = 0, כלומר (x-3)2 = 4. מכאן x - 3 = 2 או x - 3 = -2, ולכן x = 5 או x = 1. הנקודות (5, 0) ו-(1, 0).

בדיקה יפה: שתי נקודות החיתוך סימטריות ביחס לישר x = 3 — המרחק מ-1 ומ-5 אל 3 הוא 2 בשני המקרים.
ד. הפרבולה פתוחה כלפי מעלה (a = 1 > 0), ולכן הערך המינימלי הוא ערך ה-y של הקודקוד: -4.
תרגיל 6: זיהוי קודקוד קל
מהו הקודקוד ומהו ציר הסימטריה של הפרבולה y = (x-8)2 + 4?
הסוגר מתאפס כאשר x = 8, ואז y = 0 + 4 = 4. הקודקוד הוא (8, 4) וציר הסימטריה הוא הישר x = 8. מכיוון ש-a = 1 > 0 הפרבולה פתוחה כלפי מעלה ו-4 הוא הערך המינימלי שלה.
תרגיל 7: הזזה אנכית קל
הפרבולה y = x2 הוזזה 7 יחידות למטה. כתבו את הפונקציה שהתקבלה ואת הקודקוד שלה.
הזזה למטה פירושה חיסור מערכי הפונקציה: y = x2 - 7. הקודקוד ירד יחד עם כל הגרף ועבר מ-(0,0) אל (0, -7). ציר הסימטריה לא השתנה ונשאר x = 0.
תרגיל 8: מלכודת הסימן בינוני
לאיזה כיוון ובכמה יחידות הוזזה הפרבולה y = (x+6)2 ביחס ל-y = x2? נמקו בעזרת הצבה.
הקודקוד יושב במקום שבו הסוגר מתאפס: x + 6 = 0, כלומר x = -6. לכן הקודקוד הוא (-6, 0) והפרבולה הוזזה 6 יחידות שמאלה, למרות סימן הפלוס.

הצבה מאששת: עבור x = -6 מתקבל y = 0 — הערך הקטן ביותר האפשרי; ואילו עבור x = 6 מתקבל y = 122 = 144 — ערך גדול מאוד, ובוודאי לא קודקוד.
תרגיל 9: אתגר: מקודקוד ונקודה אל המשוואה מאתגר
פרבולה שקודקודה (-1, 3) עוברת גם בנקודה (1, 11). מצאו את משוואתה בצורת הקודקוד.
מתחילים מצורת הקודקוד עם p = -1 ו-k = 3: y = a(x+1)2 + 3.

מציבים את הנקודה (1, 11): 11 = a(1+1)2 + 3 = 4a + 3, ולכן 4a = 8 ו-a = 2.

המשוואה: y = 2(x+1)2 + 3.

בדיקה: עבור x = 1 מתקבל 2 · 4 + 3 = 11, ועבור x = -1 מתקבל 0 + 3 = 3 — שני הנתונים מתקיימים.
