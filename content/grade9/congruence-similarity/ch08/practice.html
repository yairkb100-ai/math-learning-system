תרגול: זווית חיצונית למשולש ולמצולע

פרק 8 · הארכת צלע חושפת קיצור דרך לזוויות

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: זווית חיצונית ישירות קל
לכל משולש מצאו את הזווית החיצונית בקדקוד השלישי:

א. זוויות פנימיות 30° ו-80°.
ב. זוויות פנימיות 45° ו-45°.
ג. זוויות פנימיות 20° ו-120°.
א. 30° + 80° = 110°.
ב. 45° + 45° = 90°.
ג. 20° + 120° = 140°.
תרגיל 2: מזווית חיצונית לפנימית קל
זווית חיצונית של משולש היא 125°. מהי הזווית הפנימית הצמודה לה?
זווית חיצונית וזווית פנימית צמודה משלימות ל-180°: 180° - 125° = 55°.
תרגיל 3: זווית פנימית רחוקה חסרה בינוני
זווית חיצונית של משולש היא 140°, ואחת הזוויות הרחוקות היא 65°. מצאו את הזווית הרחוקה השנייה ואת שלוש הזוויות הפנימיות.
הזווית הרחוקה השנייה: 140° - 65° = 75°.

הזווית הפנימית הצמודה: 180° - 140° = 40°.

שלוש הזוויות הפנימיות: 65°, 75°, 40° — וסכומן 180° ✓
תרגיל 4: מצולע משוכלל בינוני
מצאו את הזווית החיצונית ואת הזווית הפנימית של: (א) מתומן משוכלל (n = 8); (ב) מצולע משוכלל בעל 12 צלעות.
א. חיצונית 360°8 = 45°; פנימית 180° - 45° = 135°.

ב. חיצונית 360°12 = 30°; פנימית 180° - 30° = 150°.
תרגיל 5: אתגר: כמה צלעות מאתגר
במצולע משוכלל כל זווית חיצונית היא 24°. כמה צלעות למצולע? ומהי כל זווית פנימית?
סכום הזוויות החיצוניות הוא 360°, וכולן שוות ל-24°, ולכן מספר הקדקודים הוא 360°24° = 15.

למצולע 15 צלעות. כל זווית פנימית: 180° - 24° = 156°.
תרגיל 6: זווית חיצונית ישירות קל
במשולש ABC נתון \angle A = 55° ו-\angle B = 65°. מהי הזווית החיצונית בקדקוד C?
לפי משפט הזווית החיצונית: 55° + 65° = 120°.

בדיקה: \angle C = 180° - 120° = 60°, וגם 180° - 55° - 65° = 60° ✓
תרגיל 7: זווית רחוקה חסרה קל
זווית חיצונית של משולש היא 135°, ואחת הזוויות הרחוקות היא 85°. מהי הזווית הרחוקה השנייה?
135° - 85° = 50°.
תרגיל 8: שלוש הזוויות בינוני
זווית חיצונית של משולש היא 150°, ואחת הזוויות הרחוקות היא 95°. מצאו את שלוש הזוויות הפנימיות.
הרחוקה השנייה: 150° - 95° = 55°.

הצמודה: 180° - 150° = 30°.

שלוש הזוויות: 95°, 55°, 30° — סכומן 180° ✓
תרגיל 9: מצולע משוכלל בינוני
מצאו את הזווית הפנימית של מצולע משוכלל בעל 15 צלעות, דרך הזווית החיצונית.
זווית חיצונית: 360°15 = 24°.

זווית פנימית: 180° - 24° = 156°.
תרגיל 10: אתגר: כמה צלעות מאתגר
הזווית הפנימית של מצולע משוכלל היא 162°. כמה צלעות למצולע?
הזווית החיצונית היא 180° - 162° = 18°.

מספר הצלעות: 360°18° = 20.
