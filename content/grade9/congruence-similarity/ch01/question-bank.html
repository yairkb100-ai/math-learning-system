חלק א' - התאמת קודקודים 🔺 (שאלות 1–4)

  1. משולש ABC חופף למשולש DEF. לאיזו צלע במשולש DEF שווה הצלע AB?
  2. משולש ABC חופף למשולש DEF. לאיזו זווית במשולש DEF שווה הזווית B?
  3. משולש PQR חופף למשולש XYZ. לאיזו צלע שווה QR?
  4. משולש KLM חופף למשולש RST. לאיזו זווית שווה הזווית M?

חלק ב' - צלעות מתאימות 📏 (שאלות 5–8)

  1. משולש ABC חופף למשולש DEF ונתון AB = 11. מהי DE?
  2. משולש ABC חופף למשולש DEF ונתון EF = 7. מהי BC?
  3. משולש ABC חופף למשולש DEF ונתון AB = 5, BC = 6, CA = 9. מהו היקף המשולש DEF?
    משולש ABC: BC = 6, CA = 9, AB = 5
  4. משולש ABC חופף למשולש DEF, היקף ABC הוא 18, וכן DE = 4 ו-EF = 6. מהי FD?

חלק ג' - זוויות מתאימות 📐 (שאלות 9–12)

  1. משולש ABC חופף למשולש DEF ונתון ∠A = 62°. מהי ∠D?
  2. משולש ABC חופף למשולש DEF ונתון ∠A = 90° ו-∠B = 40°. מהי ∠F?
    הזווית A — זווית ישרה
    הזווית B
  3. משולש ABC חופף למשולש DEF ונתון ∠D = 100° ו-∠E = 25°. מהי ∠C?
  4. מהו סכום שלוש הזוויות בכל אחד משני משולשים חופפים?

חלק ד' - חופף או לא חופף ✅ (שאלות 13–16)

  1. האם שני עיגולים שרדיוסם 4 ס"מ חופפים?
  2. ריבוע שצלעו 6 ומלבן שצלעותיו 4 ו-9 — האם שטחיהם שווים? האם הם חופפים?
    הריבוע שצלעו 6
    המלבן שצלעותיו 9 ו-4
  3. האם שני משולשים שווי-צלעות שאורך צלעם 5 ס"מ חופפים?
  4. האם שני משולשים ששטח כל אחד מהם 20 סמ"ר בהכרח חופפים?

חלק ה' - כתיבת ההתאמה ✍️ (שאלות 17–20)

  1. נתון ∠A = ∠R, ∠B = ∠S, ∠C = ∠T והצלעות המתאימות שוות. כתבו את החפיפה.
  2. נתון ∠A = ∠F, ∠B = ∠D, ∠C = ∠E והצלעות המתאימות שוות. כתבו את החפיפה.
  3. במשולש ABC: AB = 9, BC = 5, CA = 7. במשולש DEF: DE = 7, EF = 9, FD = 5. כתבו את החפיפה.
    משולש ABC: BC = 5, CA = 7, AB = 9
  4. במלבן ABCD מעבירים את האלכסון BD. אילו שני משולשים נוצרים ומהי ההתאמה ביניהם?
    המלבן ABCD — צלעות נגדיות שוות וארבע זוויות ישרות. האלכסון BD אינו מסומן בשרטוט

חלק ו' - תנועות, היקף ושטח 🔄 (שאלות 21–24)

  1. אילו שלוש תנועות מותרות כשבודקים חפיפה, ומה משותף לשלושתן?
  2. מלבן שצלעותיו 6 ו-2 ומלבן שצלעותיו 5 ו-3 — האם ההיקפים שווים? האם הם חופפים?
  3. משולש ABC חופף למשולש DEF ונתון AB = 3, BC = 4, CA = 5. מהו שטח המשולש DEF?
    משולש ABC: BC = 4, CA = 5, AB = 3
  4. מעוין שאינו ריבוע, שצלעו 5 ס"מ, וריבוע שצלעו 5 ס"מ — האם הם חופפים? נמקו.
    מעוין ABCD — ארבע צלעות שוות, ללא זוויות ישרות
    ריבוע ABCD — ארבע צלעות שוות וארבע זוויות ישרות

23. המשולש ישר-זווית (3² + 4² = 5²), ולכן שטחו (3 · 4) / 2 = 6. לפי החפיפה גם שטח DEF הוא 6
24. לא. ההיקפים שווים (20 ס"מ) אך הזוויות שונות — בריבוע כל זווית 90° ובמעוין שאינו ריבוע לא
