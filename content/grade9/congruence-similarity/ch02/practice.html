תרגול: משפטי החפיפה צ.ז.צ ו-ז.צ.ז

פרק 2 · שתי צלעות והזווית שביניהן, שתי זוויות והצלע שביניהן

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: איזה משפט מתאים קל
לכל קבוצת נתונים על המשולשים ABC ו-DEF קבעו אם היא מספיקה לחפיפה, ואם כן — לפי איזה משפט.

א. AB = DE, \angle B = \angle E, BC = EF
ב. \angle A = \angle D, AB = DE, \angle B = \angle E
ג. AB = DE, BC = EF, \angle A = \angle D
א. מספיק — הזווית \angle B נמצאת בין הצלעות AB ו-BC, ולכן זהו צ.ז.צ.
ב. מספיק — הצלע AB נמצאת בין הזוויות \angle A ו-\angle B, ולכן זהו ז.צ.ז.
ג. אינו מספיק — הצלעות הנתונות הן AB ו-BC, והזווית שביניהן היא \angle B ולא \angle A. זהו הצירוף צ.צ.ז, שאינו משפט חפיפה.
תרגיל 2: השלמת הנתון החסר בינוני
במשולשים ABC ו-KLM נתון AB = KL = 9 ו-\angle A = \angle K = 55°. איזה נתון אחד נוסף ישלים את הנתונים למשפט צ.ז.צ, ואיזה נתון אחד נוסף ישלים אותם למשפט ז.צ.ז?
לצ.ז.צ: הזווית \angle A נמצאת בין AB ל-AC, ולכן צריך את הצלע השנייה היוצאת מ-A — כלומר את הנתון AC = KM.

לז.צ.ז: הצלע AB צריכה להיות בין שתי הזוויות הנתונות, ולכן צריך את הזווית שבקצה השני שלה — כלומר את הנתון \angle B = \angle L.
תרגיל 3: קטעים שנחתכים בינוני
הקטעים PR ו-QS נחתכים בנקודה O, ונתון PO = OR = 4 ו-QO = OS = 6. כתבו את שלושת הנתונים המובילים לחפיפה, ציינו את שם המשפט, והסיקו מסקנה אחת על הצלעות.
בוחנים את המשולשים POQ ו-ROS.

PO = OR — נתון.

QO = OS — נתון.

\angle POQ = \angle ROS — זוויות קודקודיות.

הזווית שב-O היא הזווית שבין שתי הצלעות הנתונות בכל משולש, ולכן \triangle POQ \cong \triangle ROS לפי צ.ז.צ.

מסקנה: PQ = RS (צלעות מתאימות במשולשים חופפים).
תרגיל 4: אתגר: חוצה זווית במשולש שווה-שוקיים מאתגר
במשולש ABC מתקיים AB = AC, והקטע AD הוא חוצה הזווית \angle A (כלומר \angle BAD = \angle CAD), כאשר D על הצלע BC. הוכיחו ש-\triangle ABD \cong \triangle ACD, והסיקו ש-BD = DC.
נבחן את המשולשים ABD ו-ACD:

AB = AC — נתון.

\angle BAD = \angle CAD — נתון, AD חוצה זווית.

AD = AD — צלע משותפת לשני המשולשים.

הזווית \angle BAD נמצאת בין הצלעות AB ו-AD, והזווית \angle CAD נמצאת בין AC ו-AD — כלומר בין שתי הצלעות הנתונות בכל משולש. לכן

\triangle ABD \cong \triangle ACD (צ.ז.צ)

מהחפיפה נובע ששאר הצלעות המתאימות שוות, ובפרט BD = DC. כלומר, חוצה זווית הראש במשולש שווה-שוקיים הוא גם התיכון לבסיס — תוצאה שנחזור אליה בהמשך היחידה.
תרגיל 5: נימוק מדויק בינוני
במשולש שבו שתי צלעות שוות, מה אפשר לומר על הזוויות שמולן? כתבו גם את שם המשפט.
הזוויות שמול הצלעות השוות שוות זו לזו, לפי משפט המשולש שווה־השוקיים. יש לציין את ההתאמה בין הצלעות לזוויות.
תרגיל 6: בחירת המשפט המתאים קל
במשולשים ABC ו-DEF נתון \angle A = \angle D, AC = DF ו-\angle C = \angle F. לפי איזה משפט חפיפה נובעת החפיפה, ומהי ההתאמה בין הקודקודים?
הצלע AC נמצאת בין הזוויות \angle A ו-\angle C, והצלע DF נמצאת בין \angle D ו-\angle F. זהו בדיוק המבנה של ז.צ.ז, ולכן \triangle ABC \cong \triangle DEF. ההתאמה: A rightarrow D, B rightarrow E, C rightarrow F.
תרגיל 7: השלמת נתון וחישוב זווית קל
במשולשים ABC ו-KLM נתון \angle B = \angle L = 65° ו-BC = LM = 12. איזה נתון אחד ישלים את הנתונים לז.צ.ז? ואם נוסף הנתון \angle C = \angle M = 40° — מהי \angle K?
הצלע BC נמצאת בין \angle B ל-\angle C, ולכן הנתון החסר הוא \angle C = \angle M. עם הנתון הנוסף מתקבל

\angle A = 180° - 65° - 40° = 75°

ולפי החפיפה \angle K = \angle A = 75°.
תרגיל 8: אלכסון בדלתון בינוני
במרובע ABCD נתון AB = AD ו-CB = CD. מעבירים את האלכסון AC. הוכיחו ש-\angle B = \angle D בעזרת אחד ממשפטי החפיפה שנלמדו, או הסבירו מדוע הם אינם מספיקים כאן.
בוחנים את \triangle ABC ואת \triangle ADC. נתון AB = AD, נתון CB = CD, והצלע AC משותפת ולכן AC = AC. אלה שלושה שוויונות בין צלעות בלבד, ולכן צ.ז.צ ו-ז.צ.ז אינם חלים כאן — אין בנתונים אף זווית. הצירוף הזה הוא צ.צ.צ, והוא אכן משפט חפיפה שיוצג בפרק הבא. לפיו \triangle ABC \cong \triangle ADC ומכאן \angle B = \angle D.
תרגיל 9: אתגר: שני משולשים סביב נקודת חיתוך מאתגר
הקטעים AC ו-BD נחתכים בנקודה O, ונתון AO = OC וכן AB \parallel CD. הוכיחו ש-\triangle AOB \cong \triangle COD, והסיקו ש-O היא אמצע הקטע BD.
נבחן את \triangle AOB ואת \triangle COD:

\angle OAB = \angle OCD — זוויות מתחלפות בין הישרים המקבילים AB ו-CD, שאותם חותך הישר AC.

AO = OC — נתון.

\angle AOB = \angle COD — זוויות קודקודיות.

הצלע AO נמצאת בין הזוויות \angle OAB ו-\angle AOB, והצלע OC נמצאת בין \angle OCD ו-\angle COD, ולכן

\triangle AOB \cong \triangle COD (ז.צ.ז)

מהחפיפה נובע OB = OD, כלומר O מחלקת את הקטע BD לשני חלקים שווים והיא אמצעו.
תרגיל 10: אתגר: מדידת חיזוק משולש בינוני
מיכל בונה שני חיזוקים משולשים זהים: בכל אחד מוט אופקי באורך 45 ס"מ ומוט אנכי באורך 60 ס"מ המחוברים בזווית ישרה, ומוט אלכסוני שסוגר את המשולש. הוכיחו שהחיזוקים חופפים, חשבו את אורך המוט האלכסוני ואת היקף כל חיזוק.
בשני החיזוקים המוט האופקי שווה (45 ס"מ), המוט האנכי שווה (60 ס"מ), והזווית שביניהם היא 90° בשניהם. הזווית יושבת בדיוק בין שני המוטות שנמדדו, ולכן המשולשים חופפים לפי צ.ז.צ.

אורך המוט האלכסוני הוא היתר:

c2 = 452 + 602 = 2025 + 3600 = 5625

c = √5625 = 75 ס"מ

ההיקף של כל חיזוק: 45 + 60 + 75 = 180 ס"מ. מיכל אינה חייבת למדוד את המוט האלכסוני — הוא נקבע מאליו מרגע ששני המוטות והזווית ביניהם נקבעו.
תרגיל 11: חיזוק נוסף: בודקים ומנמקים בינוני

הזוויות שמול הצלעות השוות שוות זו לזו, לפי משפט המשולש שווה־השוקיים. יש לציין את ההתאמה בין הצלעות לזוויות.
