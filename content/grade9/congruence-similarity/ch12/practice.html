תרגול: הוכחה בדרך השלילה

פרק 12 · מניחים שהטענה שגויה — ומגיעים לאבסורד

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: ההנחה השלילית קל
כתבו את ההנחה השלילית לכל טענה:

א. "הישרים מקבילים."
ב. "קיימת נקודת חיתוך."
ג. "כל הצלעות שוות."
א. נניח בשלילה שהישרים נחתכים.
ב. נניח בשלילה שאין אף נקודת חיתוך.
ג. נניח בשלילה שלא כל הצלעות שוות — כלומר יש לפחות שתי צלעות שאורכן שונה.
תרגיל 2: משולש בלי זווית ישרה וקהה יחד בינוני
הוכיחו בדרך השלילה: במשולש אין גם זווית ישרה וגם זווית קהה.
הנחה שלילית: נניח שקיים משולש שבו \angle A = 90° ו-\angle B > 90°.

פיתוח: אז \angle A + \angle B > 90° + 90° = 180°.

הסתירה: נוספת עוד זווית חיובית \angle C, ולכן סכום הזוויות גדול מ-180° — בסתירה למשפט סכום זוויות המשולש.

מסקנה: ההנחה שגויה, ולכן במשולש אין גם זווית ישרה וגם קהה.
תרגיל 3: זיהוי הסתירה בינוני
בהוכחה בדרך השלילה הגיע תלמיד לטענה "סכום זוויות המשולש הוא 200°". עם איזו עובדה ידועה הטענה סותרת, ומה המסקנה?
הטענה סותרת את המשפט שסכום זוויות המשולש הוא 180°. מכיוון שההנחה השלילית הובילה לטענה בלתי אפשרית, ההנחה שגויה — והטענה המקורית שרצו להוכיח נכונה.
תרגיל 4: שני ישרים ומקבילות מאתגר
הוכיחו בדרך השלילה: אם ישר c חותך את הישר a, ו-a מקביל ל-b, אז c חותך גם את b.
הנחה שלילית: נניח ש-c אינו חותך את b — כלומר c מקביל ל-b.

פיתוח: נתון ש-a מקביל ל-b. אם גם c מקביל ל-b, אז a ו-c שניהם מקבילים לאותו ישר b, ולכן a מקביל ל-c.

הסתירה: נתון ש-c חותך את a, בסתירה לכך ש-c מקביל ל-a.

מסקנה: ההנחה ש-c אינו חותך את b מובילה לסתירה, ולכן c חותך את b.
תרגיל 5: אתגר: שלילה מדויקת של אי-שוויון מאתגר
רוצים להוכיח בדרך השלילה את הטענה "x ≥ 5". תלמיד כתב את ההנחה השלילית "נניח x < 5". תלמידה כתבה "נניח x ≤ 5". מי צודק, ומדוע?
התלמיד צודק. השלילה המדויקת של "x ≥ 5" היא "x < 5" — כל מה שאינו "גדול או שווה ל-5".

ההנחה "x ≤ 5" של התלמידה כוללת גם את x = 5, אבל x = 5 מקיים את הטענה המקורית x ≥ 5 — כך שהיא לא שוללת אותה באמת. שלילה נכונה חייבת לכלול את כל המקרים שבהם הטענה נכשלת, ורק אותם.
תרגיל 6: ההנחה השלילית קל
כתבו את ההנחה השלילית לכל טענה: (א) "הישרים מקבילים"; (ב) "קיימת נקודת חיתוך"; (ג) "כל הצלעות שוות".
(א) נניח בשלילה שהישרים נחתכים.

(ב) נניח בשלילה שאין אף נקודת חיתוך.

(ג) נניח בשלילה שלא כל הצלעות שוות — כלומר יש לפחות שתי צלעות שאורכן שונה.

הסתירה: נתון ש-c חותך את a, בסתירה לכך ש-c מקביל ל-a.

מסקנה: ההנחה מובילה לסתירה, ולכן c חותך את b.
תרגיל 10: אתגר: שלילה מדויקת מאתגר
