תרגול: מרחק בין שתי נקודות

פרק 1 · משפט פיתגורס במערכת הצירים - מההפרשים אל המרחק

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: אופקי ואנכי קל
חשבו את המרחק בין הנקודות:

א. A(1,4) ו-B(9,4)
ב. C(3,-2) ו-D(3,7)
א. אותו שיעור y, ולכן הקטע אופקי: AB = 9-1 = 8.
ב. אותו שיעור x, ולכן הקטע אנכי: CD = 7-(-2) = 9.
תרגיל 2: הנוסחה בפעולה קל
חשבו את המרחק בין A(2,3) ל-B(6,6).
ההפרש האופקי 6-2 = 4, ההפרש האנכי 6-3 = 3.

d = √42+32 = √16+9 = √25 = 5
תרגיל 3: שיעורים שליליים בינוני
חשבו את המרחק בין A(-1,-2) ל-B(5,6).
ההפרש האופקי: 5-(-1) = 6. ההפרש האנכי: 6-(-2) = 8.

d = √62+82 = √36+64 = √100 = 10
תרגיל 4: תוצאה מדויקת בשורש בינוני
חשבו את המרחק בין A(2,1) ל-B(5,7) והשאירו תשובה מדויקת.
ההפרשים: 5-2 = 3 ו-7-1 = 6.

d = √32+62 = √9+36 = √45

אפשר לפשט: √45 = √9 · 5 = 3√5 (בערך 6.71).
תרגיל 5: אתגר: מציאת שיעור חסר מאתגר
הנקודה A(1,2) והנקודה B(x,2) מרוחקות זו מזו 7 יחידות. מצאו את כל הערכים האפשריים של x.
לשתי הנקודות אותו שיעור y, ולכן הקטע אופקי והמרחק הוא ההפרש בשיעורי ה-x:

|x - 1| = 7

יש שתי אפשרויות: x-1 = 7 ולכן x = 8 (הנקודה מימין ל-A), או x-1 = -7 ולכן x = -6 (הנקודה משמאל ל-A).

בדיקה: 8-1 = 7, וגם 1-(-6) = 7. שתי התשובות תקפות.
תרגיל 6: מרחק מהראשית קל
מהו המרחק בין ראשית הצירים לנקודה (5,12)?
d = √52 + 122 = √25+144 = √169 = 13.
תרגיל 7: קטע אנכי קל
מהו המרחק בין A(2,7) ל-B(2,-1)?
לשתי הנקודות אותו שיעור x, ולכן הקטע אנכי והמרחק הוא ההפרש בשיעורי ה-y: 7-(-1) = 8.
תרגיל 8: שיעורים שליליים בינוני
חשבו את המרחק בין A(-4,1) ל-B(2,9).
ההפרש האופקי 2-(-4) = 6, ההפרש האנכי 9-1 = 8. לכן d = √36+64 = √100 = 10.
תרגיל 9: אתגר: זיהוי משולש והיקפו מאתגר
נתון משולש שקודקודיו A(0,2), B(4,5) ו-C(8,2). חשבו את אורכי הצלעות, קבעו איזה סוג משולש זה וחשבו את היקפו.
AB = √(4-0)2+(5-2)2 = √16+9 = 5.

BC = √(8-4)2+(2-5)2 = √16+9 = 5.

הצלע AC אופקית (שתי הנקודות בגובה 2): AC = 8-0 = 8.

מתקיים AB = BC = 5, ולכן המשולש שווה-שוקיים עם בסיס AC. ההיקף: 5+5+8 = 18.
