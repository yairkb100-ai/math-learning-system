דף עבודה — פרק 5: משוואה ריבועית בפירוק

כלל המכפלה השווה לאפס וארבעת שלבי הפתרון
שם: כיתה: תאריך:
כלל המכפלה השווה לאפס: אם מכפלה שווה 0, אז לפחות אחד הגורמים שווה 0. הכלל תקף מול אפס בלבד — לא מול שום מספר אחר. סדר העבודה: (1) מעבירים הכול לאגף אחד כך שבאגף השני נשאר 0, (2) מפרקים לגורמים, (3) משווים כל גורם לאפס, (4) בודקים כל פתרון בהצבה במשוואה המקורית. שימו לב: אין לחלק את שני האגפים ב-x — כך מאבדים את הפתרון x = 0.

שאלה 1 — משוואה מפורקת - סדרה א קל

פתרו לפי כלל המכפלה השווה לאפס:

  1. (x − 3)(x + 1) = 0 ⟵
  2. (x + 6)(x − 2) = 0 ⟵

שאלה 2 — משוואה מפורקת - סדרה ב קל

פתרו לפי כלל המכפלה השווה לאפס:

  1. x(x − 7) = 0 ⟵
  2. (2x − 1)(x + 4) = 0 ⟵

שאלה 1. א. x = 3 או x = −1   ב. x = −6 או x = 2
שאלה 2. א. x = 0 או x = 7   ב. x = 0.5 או x = −4
שאלה 3. (x − 2)(x − 5) = 0 ולכן x = 2 או x = 5
שאלה 4. (x + 2)(x + 3) = 0 ולכן x = −2 או x = −3
שאלה 5. x(x − 6) = 0 ולכן x = 0 או x = 6
שאלה 6. (x − 6)(x + 2) = 0 ולכן x = 6 או x = −2
שאלה 7. x² + 3x − 18 = 0, (x + 6)(x − 3) = 0, ולכן x = −6 או x = 3
שאלה 8. 2(x − 2)(x + 2) = 0 ולכן x = 2 או x = −2
שאלה 9. 3x(x − 5) = 0 ולכן x = 0 או x = 5
שאלה 10. x² − 4x = 0, x(x − 4) = 0, ולכן x = 0 או x = 4 — שני פתרונות. חלוקה ב-x מוחקת את הפתרון x = 0, כי אסור לחלק בביטוי שעשוי להיות אפס
שאלה 11. (x − 5)² = 0 ולכן x = 5 בלבד — פתרון יחיד
שאלה 12. (x + 1)(2x + 3) = 0 ולכן x = −1 או x = −1.5
שאלה 13. x² − x − 2 = 4, x² − x − 6 = 0, (x − 3)(x + 2) = 0, ולכן x = 3 או x = −2
שאלה 14. x(x − 3)(x + 3) = 0 ולכן x = 0 או x = 3 או x = −3
שאלה 15. המשוואה x(x + 3) = 28, כלומר x² + 3x − 28 = 0 ו-(x + 7)(x − 4) = 0. הפתרון x = −7 נפסל (אורך אינו שלילי), ולכן הרוחב 4 והאורך 7
