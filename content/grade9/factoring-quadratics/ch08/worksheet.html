דף עבודה — פרק 8: אי-שוויונות ריבועיים

מתי הביטוי חיובי — קוראים מהפרבולה
שם: כיתה: תאריך:
אי-שוויון ריבועי נפתר בשלושה צעדים: מוצאים את נקודות האפס (ax2+bx+c = 0), משרטטים סקיצה של הפרבולה (פתוחה כלפי מעלה אם a>0, כלפי מטה אם a<0), וקוראים ממנה את התחום — מעל הציר y>0, מתחת לציר y<0. עם a>0 ושתי נקודות אפס: "גדול מ-0" נותן שני תחומים חיצוניים, "קטן מ-0" נותן תחום אחד בין הנקודות. נקודת אפס אחת: "גדול מ-0" נכון לכל x פרט לנקודה, "קטן מ-0" אין פתרון. אין נקודות אפס: "גדול מ-0" נכון לכל x. עם מקדם מוביל שלילי כופלים ב-−1 והופכים את סימן האי-שוויון. תמיד בודקים בהצבת ערך מכל תחום.

שאלה 1 — מהפירוק לפתרון — סדרה א קל

נקודות האפס של (x−1)(x−4) הן 1 ו-4, פרבולה מחייכת. פתרו:

  1. (x−1)(x−4) > 0 ⟵
  2. (x−1)(x−4) < 0 ⟵

שאלה 2 — מהפירוק לפתרון — סדרה ב קל

פתרו את (x+2)(x−5) ≤ 0. רשמו קודם את נקודות האפס.

שאלה 3 — מפרקים ואז פותרים קל

פתרו את x2 − 6x + 8 > 0. פרקו לגורמים, מצאו נקודות אפס, ושרטטו סקיצה.

שאלה 4 — הפרש ריבועים קל

פתרו:

  1. x2 − 25 < 0 ⟵
  2. x2 − 25 ≥ 0 ⟵

שאלה 5 — סקיצה וקריאה בינוני

לפניכם סקיצה של פרבולה.

  1. עבור אילו ערכי x מתקיים y > 0?
  2. עבור אילו ערכי x מתקיים y < 0?

שאלה 6 — מקדם מוביל שלילי — סדרה א בינוני

פתרו את −x2 + 4x − 3 > 0. כפלו ב-−1 והפכו את הסימן, ואז המשיכו כרגיל.

שאלה 7 — מקדם מוביל שלילי — סדרה ב בינוני

פתרו את −x2 + x + 6 ≥ 0.

שאלה 8 — נקודת אפס אחת בינוני

נתון הביטוי (x−2)2. פתרו לכל אחד מהאי-שוויונות: (x−2)2 > 0, (x−2)2 ≥ 0, (x−2)2 < 0, (x−2)2 ≤ 0.

שאלה 9 — אין נקודות אפס בינוני

לביטוי x2 + x + 3 דיסקרימיננט שלילי. פתרו את x2 + x + 3 > 0 ואת x2 + x + 3 < 0, והסבירו בעזרת הסקיצה.

שאלה 10 — בהצבה בודקים בינוני

פתרו את x2 − 2x − 8 ≤ 0, ואז בדקו את התשובה בהצבת ערך אחד מתוך התחום וערך אחד מחוצה לו.

שאלה 11 — מהגרף אל האי-שוויון מאתגר

פרבולה חותכת את ציר ה-x ב-x = 1 וב-x = 6, ופתוחה כלפי מטה. כתבו את התחום שבו הפונקציה חיובית ואת התחום שבו היא שלילית.

שאלה 12 — מצאו את הטעות מאתגר

תלמיד פתר x2 − 9 > 0 וכתב −3 < x < 3. הסבירו מה שגוי וכתבו את התשובה הנכונה בעזרת סקיצה.

שאלה 13 — אתגר: מאיזו כמות רווחי מאתגר

הרווח של מיזם (באלפי שקלים) לפי מספר יחידות x הוא y = x2 − 12x + 20. עבור אילו כמויות המיזם מרוויח (y > 0)? ומהו טווח הכמויות שבו הוא בהפסד?
