תרגול: אי-שוויונות ריבועיים

פרק 8 · מתי הביטוי חיובי — קוראים מהפרבולה

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: גדול או קטן מאפס קל
פתרו:

א. x2 - 7x + 10 > 0
ב. x2 - 7x + 10 < 0
נקודות אפס: (x - 2)(x - 5) = 0, כלומר x = 2 ו-x = 5. פרבולה מחייכת.

א. y > 0 — בחוץ: x < 2 או x > 5.
ב. y < 0 — בפנים: 2 < x < 5.
תרגיל 2: עם שוויון קל
פתרו את x2 - 16 ≥ 0.
נקודות אפס: (x - 4)(x + 4) = 0, כלומר x = 4 ו-x = -4. פרבולה מחייכת.

y ≥ 0 — בחוץ כולל הקצוות: x ≤ -4 או x ≥ 4.
תרגיל 3: מקדם מוביל שלילי בינוני
פתרו את -x2 + 6x - 5 > 0.
כופלים ב-(-1) והופכים: x2 - 6x + 5 < 0.

נקודות אפס: (x - 1)(x - 5) = 0, כלומר x = 1 ו-x = 5.

< 0 — בפנים: 1 < x < 5.

בדיקה במקור: x = 3 נותן -9 + 18 - 5 = 4 > 0 ✓
תרגיל 4: מקרים מיוחדים בינוני
פתרו:

א. (x - 4)2 > 0
ב. x2 + 9 < 0
ג. x2 + 1 ≥ 0
א. נקודת אפס יחידה x = 4; פרבולה מחייכת שנוגעת בציר. > 0 לכל x פרט ל-4.
ב. דיסקרימיננט שלילי, פרבולה כולה מעל הציר. אין פתרון.
ג. x2 + 1 תמיד חיובי, ולכן ≥ 0 נכון לכל x.
תרגיל 5: אתגר: מאיזו כמות רווחי מאתגר
הרווח של דוכן (בשקלים) לפי מספר הכוסות x הוא y = -x2 + 14x - 40. עבור אילו כמויות הדוכן ברווח (כלומר y > 0)? ומהי הכמות שנותנת את הרווח המרבי?
רווחי: כופלים ב-(-1) והופכים: x2 - 14x + 40 < 0. נקודות אפס: (x - 4)(x - 10) = 0, כלומר x = 4 ו-x = 10. הפתרון: 4 < x < 10 — בין 5 ל-9 כוסות (כמות שלמה) הדוכן ברווח.

רווח מרבי: קודקוד הפרבולה y = -x2 + 14x - 40 נמצא ב-x = -142 · (-1) = 7. ב-7 כוסות הרווח הוא -49 + 98 - 40 = 9 שקלים — המרבי.
תרגיל 6: מהפירוק לפתרון קל
פתרו את (x - 3)(x + 2) > 0 (הפרבולה מחייכת).
נקודות אפס: x = 3 ו-x = -2.

פרבולה מחייכת, רוצים y > 0 — החלק החיצוני:

x < -2 או x > 3
תרגיל 7: מפרקים ואז פותרים קל
פתרו את x2 - 4x - 5 ≤ 0.
x2 - 4x - 5 = (x - 5)(x + 1) = 0, ולכן נקודות האפס x = 5 ו-x = -1.

פרבולה מחייכת, ≤ 0 — החלק הפנימי כולל הקצוות: -1 ≤ x ≤ 5.
תרגיל 8: מקדם מוביל שלילי בינוני
פתרו את -x2 + 8x - 12 ≥ 0.
כופלים ב-(-1) והופכים: x2 - 8x + 12 ≤ 0.

(x - 2)(x - 6) = 0, ולכן נקודות האפס x = 2 ו-x = 6.

≤ 0 — פנימי כולל קצוות: 2 ≤ x ≤ 6.

בדיקה במקור: x = 4 נותן -16 + 32 - 12 = 4 ≥ 0 ✓
תרגיל 9: מקרה מיוחד בינוני
פתרו את x2 + 6x + 9 > 0.
x2 + 6x + 9 = (x + 3)2, ולכן נקודת האפס היחידה היא x = -3.

פרבולה מחייכת שנוגעת בציר בנקודה אחת, ומעליו בכל שאר הערכים.

(x + 3)2 > 0 נכון לכל x פרט ל--3.
תרגיל 10: אתגר: מתי הגובה חיובי מאתגר
גובה של רקטת צעצוע (במטרים) לפי הזמן t (בשניות) הוא h = -t2 + 10t. עבור אילו זמנים הרקטה מעל הקרקע (h > 0)? ומתי היא בגובהה המרבי?
מעל הקרקע: -t2 + 10t > 0. כופלים ב-(-1) והופכים: t2 - 10t < 0, כלומר t(t - 10) < 0. נקודות אפס 0 ו-10, פרבולה מחייכת, < 0 בפנים: 0 < t < 10 שניות.

גובה מרבי: קודקוד הפרבולה h = -t2 + 10t ב-t = -102 · (-1) = 5. הגובה שם: -25 + 50 = 25 מטר.
תרגיל 11: חיזוק נוסף: בודקים כל אזור קל
פתרו את x2 - x - 6 > 0 ובדקו בהצבת ערך מכל אזור.
(x - 3)(x + 2) = 0, נקודות אפס x = 3 ו-x = -2. פרבולה מחייכת, > 0 בחוץ: x < -2 או x > 3.

בדיקה: x = -3: 9 + 3 - 6 = 6 > 0 ✓; x = 0: -6, לא ✓ (אזור אמצעי נכשל כצפוי); x = 4: 16 - 4 - 6 = 6 > 0 ✓
