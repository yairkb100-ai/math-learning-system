תרגול: פירוק לפי נוסחאות

פרק 2 · הפרש ריבועים וריבוע שלם - פירוק בזיהוי מבנה

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: הפרש ריבועים בסיסי קל
פרקו לגורמים:

א. x2 - 25
ב. x2 - 1
א. 25 = 52, ולכן x2 - 25 = (x - 5)(x + 5).
ב. 1 = 12, ולכן x2 - 1 = (x - 1)(x + 1).
תרגיל 2: ריבוע שלם בינוני
פרקו לגורמים: x2 + 8x + 16.
הקצוות ריבועים: x2 ו-16 = 42, והשורשים הם x ו-4. מבחן האיבר האמצעי: 2 · x · 4 = 8x — מתאים.

x2 + 8x + 16 = (x + 4)2

בדיקה: (x+4)2 = x2 + 4x + 4x + 16 = x2 + 8x + 16.
תרגיל 3: הפרש ריבועים עם מקדם בינוני
פרקו לגורמים: 16x2 - 81.
16x2 = (4x)2 ו-81 = 92, ולכן a = 4x ו-b = 9.

16x2 - 81 = (4x - 9)(4x + 9)

בדיקה: (4x-9)(4x+9) = 16x2 + 36x - 36x - 81 = 16x2 - 81.
תרגיל 4: אתגר: ריבוע שלם וטריק מספרי מאתגר
א. פרקו לגורמים: 25x2 - 30x + 9.
ב. חשבו בלי מחשבון: 882 - 122.
א. הקצוות: 25x2 = (5x)2 ו-9 = 32. מבחן האיבר האמצעי: 2 · 5x · 3 = 30x — מתאים, והסימן שלילי.

25x2 - 30x + 9 = (5x - 3)2

בדיקה: (5x-3)2 = 25x2 - 15x - 15x + 9 = 25x2 - 30x + 9.

ב. לפי הפרש ריבועים: 882 - 122 = (88 - 12)(88 + 12) = 76 · 100 = 7600.
תרגיל 5: הפרש ריבועים קל
פרקו לגורמים: x2 - 64.
64 = 82, ולכן x2 - 64 = (x - 8)(x + 8). בדיקה: x2 + 8x - 8x - 64 = x2 - 64.
תרגיל 6: ריבוע שלם בינוני
פרקו לגורמים: x2 - 16x + 64.
השורשים הם x ו-8, ומבחן האיבר האמצעי נותן 2 · x · 8 = 16x — מתאים, עם סימן מינוס. לכן x2 - 16x + 64 = (x - 8)2.
תרגיל 7: מקדם בשני הצדדים בינוני
פרקו לגורמים: 36x2 - 25.
36x2 = (6x)2 ו-25 = 52, ולכן 36x2 - 25 = (6x - 5)(6x + 5). בדיקה: 36x2 + 30x - 30x - 25 = 36x2 - 25.
תרגיל 8: אתגר: גורם משותף ואז נוסחה מאתגר
פרקו עד הסוף: 5x3 - 20x.
קודם גורם משותף: 5x3 - 20x = 5x(x2 - 4). הביטוי שבסוגריים הוא הפרש ריבועים, ולכן ממשיכים:

5x3 - 20x = 5x(x - 2)(x + 2)

בדיקה: 5x(x2 - 4) = 5x3 - 20x.
