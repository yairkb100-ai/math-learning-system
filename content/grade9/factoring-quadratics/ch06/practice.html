תרגול: נוסחת השורשים

פרק 6 · נוסחת השורשים והדיסקרימיננט - כמה פתרונות יש ואיך מוצאים אותם

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: מקדמים ודיסקרימיננט קל
לכל משוואה רשמו את a, b ו-c, חשבו את Δ וקבעו כמה פתרונות יש:

א. x2+7x+10=0
ב. 2x2-4x+2=0
ג. x2+x+3=0
א. a=1, b=7, c=10; Δ = 49-40 = 9 > 0 — שני פתרונות.
ב. a=2, b=-4, c=2; Δ = 16-16 = 0 — פתרון יחיד.
ג. a=1, b=1, c=3; Δ = 1-12 = -11 < 0 — אין פתרון ממשי.
תרגיל 2: פתרון בעזרת הנוסחה קל
פתרו בעזרת נוסחת השורשים ובדקו בהצבה: x2-8x+15=0.
a=1, b=-8, c=15, ולכן Δ = 64-60 = 4.

x = 8 ± 22

מכאן x1 = 5 ו-x2 = 3.

בדיקה: עבור x=5 מתקבל 25-40+15 = 0; עבור x=3 מתקבל 9-24+15 = 0. שניהם תקינים.
תרגיל 3: מקדם מוביל שונה מאחד בינוני
פתרו ובדקו בהצבה: 2x2+5x-3=0.
a=2, b=5, c=-3, ולכן Δ = 25 - 4 · 2 · (-3) = 25+24 = 49.

x = -5 ± 74

מכאן x1 = 24 = 0.5 ו-x2 = -124 = -3.

בדיקה: עבור x=0.5 מתקבל 0.5+2.5-3 = 0; עבור x=-3 מתקבל 18-15-3 = 0. שניהם תקינים.
תרגיל 4: מסדרים ואז פותרים בינוני
פתרו: x2 = 4x + 5.
מסדרים: x2-4x-5=0, ולכן a=1, b=-4, c=-5 ו-Δ = 16+20 = 36.

x = 4 ± 62

מכאן x1 = 5 ו-x2 = -1.

בדיקה במשוואה המקורית: עבור x=5 מתקבל 25 מול 20+5 = 25; עבור x=-1 מתקבל 1 מול -4+5 = 1. שניהם תקינים.
תרגיל 5: אתגר: פרמטר ופתרון יחיד מאתגר
עבור אילו ערכים של k למשוואה x2+6x+k=0 יש פתרון יחיד? מהו הפתרון במקרה זה?
פתרון יחיד מתקבל כאשר Δ = 0:

Δ = 62 - 4 · 1 · k = 36 - 4k = 0

מכאן 4k = 36 ולכן k = 9.

עבור k=9 המשוואה היא x2+6x+9=0, והפתרון היחיד הוא x = -62 = -3.

בדיקה: 9-18+9 = 0. מתאים.
תרגיל 6: דיסקרימיננט ומספר פתרונות קל
חשבו את Δ וקבעו כמה פתרונות יש למשוואה x2-10x+25=0.
a=1, b=-10, c=25, ולכן Δ = 100-100 = 0 — פתרון יחיד. הפתרון הוא x = 102 = 5, ובבדיקה: 25-50+25 = 0.
תרגיל 7: פתרון בנוסחה בינוני
פתרו בעזרת נוסחת השורשים: 2x2-9x+4=0.
Δ = 81 - 32 = 49, ולכן x = 9 ± 74: מכאן x1 = 4 ו-x2 = 0.5.

בדיקה: עבור x=4 מתקבל 32-36+4 = 0; עבור x=0.5 מתקבל 0.5-4.5+4 = 0.
תרגיל 8: משוואה שצריך לסדר בינוני
פתרו: (x+2)(x-1) = 4.
פותחים סוגריים: x2+x-2 = 4, ומסדרים: x2+x-6 = 0. מתקיים Δ = 1+24 = 25, ולכן x = -1 ± 52: מכאן x1 = 2 ו-x2 = -3.

בדיקה במשוואה המקורית: עבור x=2 מתקבל 4 · 1 = 4; עבור x=-3 מתקבל (-1) · (-4) = 4.
תרגיל 9: אתגר: תנאי לשני פתרונות מאתגר
עבור אילו ערכים של c למשוואה x2-8x+c=0 יש שני פתרונות שונים?
דרושים שני פתרונות, ולכן Δ > 0:

Δ = 64 - 4c > 0

מכאן 4c < 64 ולכן c < 16.

בדיקה על דוגמה: עבור c=15 מתקבל Δ = 4 ושני הפתרונות הם x=5 ו-x=3; עבור c=16 מתקבל Δ = 0 ופתרון יחיד x=4 — בדיוק הגבול.
