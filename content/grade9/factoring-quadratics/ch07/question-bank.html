חלק א' - מלבנים ושטחים 📐 (שאלות 1–4)

  1. אורכו של מלבן גדול מרוחבו ב-6 ושטחו 27. מצאו את מידותיו.
  2. אורכו של מלבן גדול מרוחבו ב-1 ושטחו 56. מצאו את מידותיו.
  3. אורכו של מלבן גדול פי 2 מרוחבו ושטחו 72. מצאו את מידותיו.
  4. שטחו של ריבוע הוא 121. מהי צלעו, ואיזה פתרון נפסל?

חלק ב' - בעיות מספרים 🔢 (שאלות 5–8)

  1. מכפלת שני מספרים טבעיים עוקבים היא 72. מצאו אותם.
  2. מכפלת שני מספרים זוגיים טבעיים עוקבים היא 80. מצאו אותם.
  3. סכום הריבועים של שני מספרים טבעיים עוקבים הוא 113. מצאו אותם.
  4. ריבועו של מספר טבעי גדול מהמספר עצמו ב-42. מהו המספר?

חלק ג' - הגדלה והקטנה של צורה 🔍 (שאלות 9–12)

  1. הגדילו את צלע הריבוע ב-1 והשטח החדש 64. מהי הצלע המקורית?
  2. הגדילו את צלע הריבוע ב-5 והשטח החדש 144. מהי הצלע המקורית?
  3. הגדילו את צלע הריבוע ב-2 והשטח גדל פי 9. מהי הצלע המקורית?
  4. רוחב מלבן x ואורכו x + 3. הוסיפו לכל מידה 1 והתקבל שטח 40. מהן המידות המקוריות?

חלק ד' - מסגרות ושבילים 🖼️ (שאלות 13–16)

  1. תמונה 10 × 14 מוקפת מסגרת ברוחב אחיד ושטחה הכולל 192. מהו רוחב המסגרת?
  2. תמונה 6 × 10 מוקפת מסגרת ברוחב אחיד ושטחה הכולל 96. מהו רוחב המסגרת?
  3. בריכה 8 × 12 מוקפת שביל ברוחב אחיד והשטח הכולל 192. מהו רוחב השביל?
  4. גינה 5 × 9 מוקפת שביל ברוחב אחיד והשטח הכולל 77. מהו רוחב השביל?

חלק ה' - אתגרים 🏆 (שאלות 17–20)

  1. במשולש ישר-זווית ניצב אחד גדול מהשני ב-2 והיתר 10. מצאו את הניצבים.
  2. גובה משולש גדול מבסיסו ב-7 ושטחו 30. מצאו את הבסיס ואת הגובה.
  3. באולם מספר השורות גדול ב-4 ממספר הכיסאות בשורה, ובסך הכול 96 כיסאות. כמה שורות יש?
  4. מכפלת גילה של נועה היום בגילה בעוד 6 שנים היא 91. בת כמה נועה היום?

1. x² + 6x − 27 = 0; x = 3 או x = −9 — השלילי נפסל. המידות 3 × 9
2. x² + x − 56 = 0; x = 7 או x = −8 — השלילי נפסל. המידות 7 × 8
3. 2x² = 72; x = 6 או x = −6 — השלילי נפסל. המידות 6 × 12
4. a = 11 או a = −11 — הפתרון a = −11 נפסל כי צלע אינה שלילית
5. n² + n − 72 = 0; n = 8 או n = −9 — השלילי נפסל. המספרים 8 ו-9
6. n² + 2n − 80 = 0; n = 8 או n = −10 — השלילי נפסל. המספרים 8 ו-10
7. n² + n − 56 = 0; n = 7 או n = −8 — השלילי נפסל. המספרים 7 ו-8, ובבדיקה 49 + 64 = 113
8. x² − x − 42 = 0; x = 7 או x = −6 — השלילי נפסל. המספר 7, ובבדיקה 49 = 7 + 42
9. (a + 1)² = 64; a = 7 או a = −9 — השלילי נפסל. הצלע 7
10. (a + 5)² = 144; a = 7 או a = −17 — השלילי נפסל. הצלע 7
11. (a + 2)² = 9a² ולכן 2a² − a − 1 = 0; a = 1 או a = −0.5 — השלילי נפסל. הצלע 1
12. (x + 1)(x + 4) = 40 ולכן x² + 5x − 36 = 0; x = 4 או x = −9 — השלילי נפסל. המידות המקוריות 4 × 7
13. (10 + 2x)(14 + 2x) = 192 ולכן x² + 12x − 13 = 0; x = 1 או x = −13 — השלילי נפסל. הרוחב 1
14. (6 + 2x)(10 + 2x) = 96 ולכן x² + 8x − 9 = 0; x = 1 או x = −9 — השלילי נפסל. הרוחב 1
15. (8 + 2x)(12 + 2x) = 192 ולכן x² + 10x − 24 = 0; x = 2 או x = −12 — השלילי נפסל. הרוחב 2
16. (5 + 2x)(9 + 2x) = 77 ולכן x² + 7x − 8 = 0; x = 1 או x = −8 — השלילי נפסל. הרוחב 1
17. x² + (x + 2)² = 100 ולכן x² + 2x − 48 = 0; x = 6 או x = −8 — השלילי נפסל. הניצבים 6 ו-8
18. b(b + 7) / 2 = 30 ולכן b² + 7b − 60 = 0; b = 5 או b = −12 — השלילי נפסל. הבסיס 5 והגובה 12
19. c² + 4c − 96 = 0; c = 8 או c = −12 — השלילי נפסל. 8 כיסאות בשורה ו-12 שורות
20. x² + 6x − 91 = 0; x = 7 או x = −13 — השלילי נפסל. נועה בת 7, ובבדיקה 7 · 13 = 91
21. x(x + 5) = 84, ולכן x² + 5x − 84 = 0, ולכן x = 7. המידות: 7 ו-12 (הפתרון x = −12 נפסל)
22. x(x + 2) = 143, ולכן x² + 2x − 143 = 0, ולכן x = 11. המספרים: 11 ו-13
23. x + x² = 56, ולכן x² + x − 56 = 0, ולכן x = 7 (הפתרון x = −8 אינו טבעי)
