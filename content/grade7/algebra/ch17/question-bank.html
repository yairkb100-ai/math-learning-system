חלק א' — קריאת התוצאה הסופית 🔎 (שאלות 1–5)

  1. בפתרון התקבל 5 = 5. מהי המסקנה?
  2. בפתרון התקבל 2 = 9. מהי המסקנה?
  3. בפתרון התקבל x = −3. מהי המסקנה?
  4. בפתרון התקבל 0 = 0. מהי המסקנה?
  5. בפתרון התקבל x = 0. מהי המסקנה?

חלק ב' — פתרו וקבעו ✏️ (שאלות 6–10)

  1. פתרו וקבעו: x + 7 = x + 2
  2. פתרו וקבעו: 8x − 3 = 8x − 3
  3. פתרו וקבעו: 5x + 1 = 2x + 13
  4. פתרו וקבעו: 9x + 4 = 9x + 10
  5. פתרו וקבעו: 4x − 3 = 4x + 3

חלק ג' — עם סוגריים 📦 (שאלות 11–15)

  1. פתרו וקבעו: 3(x + 4) = 3x + 12
  2. פתרו וקבעו: 3(x + 4) = 3x + 7
  3. פתרו וקבעו: 2(x − 5) = 2x − 10
  4. פתרו וקבעו: 5(x + 1) = 3x + 13
  5. פתרו וקבעו: −2(x − 3) = −2x + 6

חלק ד' — התמונה הגרפית 📈 (שאלות 16–20)

  1. שני קווים בעלי אותו שיפוע וגבהי חיתוך שונים. איזה סוג פתרון?
  2. שני קווים בעלי שיפועים שונים. איזה סוג פתרון?
  3. שני קווים שמתלכדים לחלוטין. איזה סוג פתרון?
  4. המשוואה 4x + 1 = 4x + 6 — תארו איך ייראו שני הקווים.
  5. המשוואה 3x + 2 = x + 2 — תארו איך ייראו שני הקווים.

חלק ה' — אפס או אין פתרון? ⚠️ (שאלות 21–25)

  1. פתרו וקבעו: 7x = 0
  2. פתרו וקבעו: 7x + 5 = 5
  3. נכון או לא נכון: אם התקבל 0 = 0 אז x = 0. נמקו.
  4. נכון או לא נכון: אם אין פתרון אז x = 0. נמקו.
  5. נכון או לא נכון: המשוואה 5x = 0 היא בלי פתרון. נמקו.

חלק ו' — אתגרים 🏆 (שאלות 26–30)

  1. במשוואה 2x + k = 2x + 5 — עבור איזה k יהיו אינסוף פתרונות?
  2. במשוואה mx + 3 = 7x + 3 — עבור איזה m יהיו אינסוף פתרונות?
  3. כתבו משוואה משלכם שאין לה פתרון, והסבירו איך בניתם אותה.
  4. כתבו זהות משלכם שיש לה אינסוף פתרונות, והסבירו איך בניתם אותה.
  5. במשוואה x/3 + k = x/3 + 8 — עבור איזה k אין פתרון?
