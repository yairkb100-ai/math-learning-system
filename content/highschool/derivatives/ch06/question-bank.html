  2. מצאו את הנגזרת השנייה של f(x) = x5 + 2x2.
  3. מצאו את הנגזרת השנייה של f(x) = 3x4 - x3 + 6.
  4. מצאו את הנגזרת השנייה של f(x) = x2 - 7x + 2.

חלק ב' — תחומי קמירות 🙂 (שאלות 5–8)

  1. באילו תחומים f(x) = x2 + 4x קמורה כלפי מעלה?
  2. באילו תחומים f(x) = -2x2 + 3x קמורה כלפי מטה?
  3. קבעו את תחומי הקמירות של f(x) = x3.
  4. קבעו את תחומי הקמירות של f(x) = x3 - 6x2.

חלק ג' — נקודות פיתול 🔄 (שאלות 9–12)

  1. מצאו את נקודת הפיתול של f(x) = x3 - 3x2 + 1.
  2. מצאו את נקודת הפיתול של f(x) = x3 + 6x2.
  3. מצאו את כל נקודות הפיתול של f(x) = x4 - 6x2 + 5.
  4. האם ל-f(x) = x4 יש נקודת פיתול? נמקו.

חלק ד' — מבחן הנגזרת השנייה ⚖️ (שאלות 13–16)

  1. מצאו וסווגו את נקודות הקיצון של f(x) = x2 - 8x.
  2. מצאו וסווגו את נקודות הקיצון של f(x) = -x2 + 6x.
  3. מצאו וסווגו את נקודות הקיצון של f(x) = x3 - 12x.
  4. מצאו וסווגו את נקודות הקיצון של f(x) = x3 + 3x2 - 24x.

חלק ה' — משמעות ושפה 💬 (שאלות 17–20)

  1. מכונית נוסעת קדימה ובולמת. מה סימן המהירות ומה סימן התאוצה?
  2. מספר המנויים באתר עולה, אך התוספת החודשית הולכת ומצטמצמת. מה אפשר לומר על f' ועל f''?
  3. אם f''(x) < 0 בכל נקודות קטע, האם בהכרח הפונקציה יורדת בו? נמקו.
  4. מה חובה לבדוק אחרי שפותרים f''(x) = 0, ולמה?

חלק ו' — אתגרים 🏆 (שאלות 21–24)

  1. מצאו את כל נקודות הפיתול של f(x) = x4 - 4x3 + 10.
  2. נתון f(x) = x3 + ax2 + 3x. נקודת הפיתול היא ב-x = 1. מצאו את a.
  3. ידוע ש-f''(x) = 6x - 12 ושהסימן מתחלף. מהו שיעור ה-x של נקודת הפיתול?
  4. הסבירו מדוע מבחן הנגזרת השנייה אינו מכריע כאשר f''(x0) = 0, והביאו שתי דוגמאות נגדיות.

1. f'(x) = 3x2 - 8x ולכן f''(x) = 6x - 8
2. f'(x) = 5x4 + 4x ולכן f''(x) = 20x3 + 4
3. f'(x) = 12x3 - 3x2 ולכן f''(x) = 36x2 - 6x
4. f'(x) = 2x - 7 ולכן f''(x) = 2
5. f''(x) = 2 — חיובי תמיד, ולכן הפונקציה קמורה כלפי מעלה בכל תחומה
6. f''(x) = -4 — שלילי תמיד, ולכן הפונקציה קמורה כלפי מטה בכל תחומה
7. f''(x) = 6x: קמורה כלפי מעלה בתחום x > 0 וקמורה כלפי מטה בתחום x < 0 (ב-x = 0 נקודת פיתול)
8. f'(x) = 3x2 - 12x ולכן f''(x) = 6x - 12: קמורה כלפי מעלה בתחום x > 2 וקמורה כלפי מטה בתחום x < 2
9. f''(x) = 6x - 6 = 0 נותן x = 1; הסימן מתחלף, ו-f(1) = 1 - 3 + 1 = -1, ולכן (1, -1)
10. f''(x) = 6x + 12 = 0 נותן x = -2; הסימן מתחלף, ו-f(-2) = -8 + 24 = 16, ולכן (-2, 16)
11. f'(x) = 4x3 - 12x ולכן f''(x) = 12x2 - 12 = 12(x - 1)(x + 1), המתאפסת ב-x = 1 וב-x = -1. בשתיהן יש החלפת סימן, ו-f(1) = f(-1) = 0, ולכן נקודות הפיתול הן (1, 0) ו-(-1, 0)
12. לא — f''(x) = 12x2 אמנם מתאפסת ב-x = 0, אך היא חיובית משני הצדדים ואינה מחליפה סימן; הקמירות אינה מתחלפת, ולכן אין נקודת פיתול (שם דווקא נקודת מינימום)
13. f'(x) = 2x - 8 = 0 נותן x = 4; f''(x) = 2 חיובי, ולכן מינימום, f(4) = 16 - 32 = -16, כלומר (4, -16)
14. f'(x) = -2x + 6 = 0 נותן x = 3; f''(x) = -2 שלילי, ולכן מקסימום, f(3) = -9 + 18 = 9, כלומר (3, 9)
15. f'(x) = 3x2 - 12 = 0 נותן x = 2 או x = -2; f''(x) = 6x. מתקיים f''(2) = 12 — מינימום (2, -16); ומתקיים f''(-2) = -12 — מקסימום (-2, 16)
16. f'(x) = 3x2 + 6x - 24 = 3(x + 4)(x - 2) = 0 נותן x = -4 או x = 2; f''(x) = 6x + 6. מתקיים f''(-4) = -18 — מקסימום, f(-4) = -64 + 48 + 96 = 80, כלומר (-4, 80); ומתקיים f''(2) = 18 — מינימום, f(2) = 8 + 12 - 48 = -28, כלומר (2, -28)
17. המהירות עדיין חיובית (המכונית מתקדמת), אך התאוצה שלילית — כלומר s'(t) > 0 ו-s''(t) < 0
18. f' חיובית (הפונקציה עולה) ו-f'' שלילית (העלייה נבלמת, קמירות כלפי מטה)
19. לא — סימן f'' קובע קמירות בלבד ולא עלייה או ירידה. פונקציה יכולה לעלות ולהיות קמורה כלפי מטה באותו קטע; מי שקובע עלייה או ירידה הוא סימן f'
20. חובה לבדוק שהסימן של f'' אכן מתחלף משני צידי הנקודה. איפוס הנגזרת השנייה הוא תנאי הכרחי בלבד ולא מספיק — ראו את f(x) = x4 בנקודה x = 0
21. f'(x) = 4x3 - 12x2 ולכן f''(x) = 12x2 - 24x = 12x(x - 2), המתאפסת ב-x = 0 וב-x = 2. סימנים: f''(-1) = 36, f''(1) = -12, f''(3) = 36 — בשתיהן החלפת סימן. הערכים: f(0) = 10 ו-f(2) = 16 - 32 + 10 = -6, ולכן (0, 10) ו-(2, -6)
22. f''(x) = 6x + 2a, ומהתנאי f''(1) = 6 + 2a = 0 מתקבל a = -3
23. 6x - 12 = 0 נותן x = 2
24. כי f''(x0) = 0 אינו מבחין בין המצבים האפשריים. עבור f(x) = x4 מתקיים f''(0) = 0 ויש מינימום, ואילו עבור f(x) = x3 מתקיים f''(0) = 0 ואין קיצון כלל. במצב כזה חוזרים לטבלת הסימנים של f'
