דף עבודה — פרק 6: הנגזרת השנייה, קמירות ונקודות פיתול

חשבון דיפרנציאלי · פרק 6 — סימן הנגזרת השנייה, תחומי קמירות ומבחן הקיצון
שם: כיתה: תאריך:
הנגזרת השנייה f''(x) מתקבלת מגזירת f'(x) פעם נוספת, והיא מודדת את קצב השינוי של השיפוע. סימנה קובע קמירות: f''(x) > 0 — קמירות כלפי מעלה; f''(x) < 0 — קמירות כלפי מטה. נקודת פיתול נמצאת מ-f''(x) = 0 ובתוספת בדיקת החלפת סימן משני הצדדים; שיעור ה-y מחושב תמיד בהצבה בפונקציה המקורית. בנקודה קריטית: f''(x) < 0 מעיד על מקסימום, f''(x) > 0 על מינימום, וכאשר f''(x) = 0 המבחן אינו מכריע וחוזרים לטבלת הסימנים של f'.

שאלה 1 — חישוב נגזרת שנייה — סדרה א קל

מצאו את הנגזרת הראשונה ואת הנגזרת השנייה:

  1. f(x) = x5 - 2x3 + 7x ⟵
  2. f(x) = 4x3 + x2 - 9 ⟵

שאלה 2 — חישוב נגזרת שנייה — סדרה ב קל

מצאו את הנגזרת השנייה:

  1. f(x) = x6 - 3x4 ⟵
  2. f(x) = 2x4 - 5x2 + x ⟵

שאלה 3 — קמירות של פרבולה קל

לכל פונקציה חשבו את הנגזרת השנייה וקבעו את כיוון הקמירות בכל תחומה:

  1. f(x) = x2 - 6x + 1 ⟵
  2. g(x) = -3x2 + x ⟵

שאלה 4 — נקודת פיתול של פונקציה מעוקבת קל

מצאו את נקודת הפיתול של f(x) = x3 - 9x2 + 15x. אל תשכחו לבדוק החלפת סימן.

שאלה 5 — הצבה בנגזרת השנייה קל

נתונה f(x) = x4 - 4x3 + 2x. חשבו:

  1. f''(1) ⟵
  2. f''(3) ⟵

שאלה 6 — תחומי קמירות ושתי נקודות פיתול בינוני

מצאו את תחומי הקמירות ואת כל נקודות הפיתול של f(x) = x4 - 2x3. בנו טבלת סימנים ל-f''.

שאלה 7 — פיתול וסימון על מערכת צירים בינוני

מצאו את נקודת הפיתול של f(x) = x3 - 6x2 + 9x + 1, וקבעו באילו תחומים הפונקציה קמורה כלפי מעלה ובאילו כלפי מטה.

הנקודה המסומנת היא נקודת הפיתול שאתם אמורים לקבל

שאלה 8 — סיווג קיצון במבחן הנגזרת השנייה — סדרה א בינוני

מצאו את נקודות הקיצון של f(x) = x3 - 3x2 - 9x וסווגו אותן בעזרת f''.

שאלה 9 — סיווג קיצון במבחן הנגזרת השנייה — סדרה ב בינוני

מצאו את נקודות הקיצון של f(x) = 2x3 - 9x2 + 12x וסווגו אותן בעזרת f''.

שאלה 10 — לקרוא את שני הסימנים יחד בינוני

תארו במילים את התנהגות הגרף בכל מצב:

  1. בקטע מתקיים f'(x) > 0 וגם f''(x) < 0 ⟵
  2. בקטע מתקיים f'(x) < 0 וגם f''(x) > 0 ⟵
  3. בנקודה מתקיים f'(x) = 0 וגם f''(x) > 0 ⟵

שאלה 11 — אתגר: פיתול, קיצון ומשיק אופקי מאתגר

נתונה f(x) = x4 + 4x3.

  1. מצאו את כל נקודות הפיתול.
  2. מצאו את הנקודות הקריטיות, וסווגו כל אחת מהן.
  3. הסבירו מה מיוחד בנקודה שבה x = 0.

שאלה 12 — מצאו את הטעות מאתגר

תלמיד כתב: "עבור f(x) = x4 + 5 מתקיים f''(0) = 0, ולכן x = 0 היא נקודת פיתול". הפריכו את הטענה, והסבירו מהי באמת הנקודה הזאת.

שאלה 13 — אתגר: מציאת שני פרמטרים מאתגר

נתונה f(x) = x3 + ax2 + bx. ידוע שנקודת הפיתול של הגרף היא בנקודה שבה x = 2, ושיש לפונקציה נקודה קריטית בנקודה שבה x = 1. מצאו את a ואת b, וכתבו את הפונקציה.

שאלה 3. א. f''(x) = 2 — חיובי תמיד, ולכן הפונקציה קמורה כלפי מעלה בכל תחומה   ב. g''(x) = -6 — שלילי תמיד, ולכן הפונקציה קמורה כלפי מטה בכל תחומה
שאלה 4. f'(x) = 3x2 - 18x + 15 ולכן f''(x) = 6x - 18. פותרים 6x - 18 = 0 ומקבלים x = 3. בדיקת סימן: f''(0) = -18 (קמור כלפי מטה) ו-f''(4) = 6 (קמור כלפי מעלה) — הסימן התחלף ✓ הערך: f(3) = 27 - 81 + 45 = -9, ונקודת הפיתול היא (3, -9)
שאלה 5. f'(x) = 4x3 - 12x2 + 2 ולכן f''(x) = 12x2 - 24x. א. f''(1) = 12 - 24 = -12   ב. f''(3) = 108 - 72 = 36
שאלה 6. f'(x) = 4x3 - 6x2 ולכן f''(x) = 12x2 - 12x = 12x(x - 1), המתאפסת ב-x = 0 וב-x = 1. טבלת סימנים: f''(-1) = 24 (חיובי), f''(0.5) = -3 (שלילי), f''(2) = 24 (חיובי). קמורה כלפי מעלה בתחומים x < 0 וגם x > 1, וקמורה כלפי מטה בתחום 0 < x < 1. בשתי הנקודות יש החלפת סימן, ולכן שתיהן נקודות פיתול: f(0) = 0 ו-f(1) = 1 - 2 = -1, כלומר (0, 0) ו-(1, -1)
שאלה 7. f'(x) = 3x2 - 12x + 9 ולכן f''(x) = 6x - 12, המתאפסת ב-x = 2. בדיקת סימן: f''(0) = -12 ו-f''(3) = 6 — הסימן התחלף ✓ קמורה כלפי מטה בתחום x < 2 וקמורה כלפי מעלה בתחום x > 2. הערך: f(2) = 8 - 24 + 18 + 1 = 3, ונקודת הפיתול היא (2, 3)
שאלה 8. f'(x) = 3x2 - 6x - 9 = 3(x - 3)(x + 1) = 0 נותן x = 3 או x = -1. הנגזרת השנייה f''(x) = 6x - 6. מתקיים f''(3) = 12 — חיובי, ולכן מינימום, וערכו f(3) = 27 - 27 - 27 = -27, כלומר (3, -27). ומתקיים f''(-1) = -12 — שלילי, ולכן מקסימום, וערכו f(-1) = -1 - 3 + 9 = 5, כלומר (-1, 5)
שאלה 9. f'(x) = 6x2 - 18x + 12 = 6(x - 1)(x - 2) = 0 נותן x = 1 או x = 2. הנגזרת השנייה f''(x) = 12x - 18. מתקיים f''(1) = -6 — שלילי, ולכן מקסימום, וערכו f(1) = 2 - 9 + 12 = 5, כלומר (1, 5). ומתקיים f''(2) = 6 — חיובי, ולכן מינימום, וערכו f(2) = 16 - 36 + 24 = 4, כלומר (2, 4)
שאלה 10. א. הפונקציה עולה, אך קמורה כלפי מטה — כלומר עולה בקצב הולך ופוחת (העלייה נבלמת). ב. הפונקציה יורדת, אך קמורה כלפי מעלה — כלומר הירידה הולכת ומתמתנת. ג. זו נקודה קריטית שבה העקומה קמורה כלפי מעלה, ולכן לפי מבחן הנגזרת השנייה יש שם מינימום מקומי
שאלה 11. f'(x) = 4x3 + 12x2 = 4x2(x + 3) ולכן f''(x) = 12x2 + 24x = 12x(x + 2). א. פותרים f''(x) = 0 ומקבלים x = 0 ו-x = -2. בדיקת סימן: f''(-3) = 36 (חיובי), f''(-1) = -12 (שלילי), f''(1) = 36 (חיובי) — בשתי הנקודות יש החלפת סימן, ולכן שתיהן נקודות פיתול: f(-2) = 16 - 32 = -16 ו-f(0) = 0, כלומר (-2, -16) ו-(0, 0). ב. הנקודות הקריטיות הן x = 0 ו-x = -3; מתקיים f''(-3) = 36 — חיובי, ולכן מינימום, וערכו f(-3) = 81 - 108 = -27, כלומר (-3, -27). ג. ב-x = 0 מתקיים f''(0) = 0 והמבחן אינו מכריע; מטבלת הסימנים של f'(x) = 4x2(x + 3) רואים שהנגזרת חיובית משני צידי האפס, ולכן אין שם קיצון — זו נקודת פיתול שהמשיק בה אופקי
שאלה 12. f'(x) = 4x3 ולכן f''(x) = 12x2. אמנם f''(0) = 0, אבל 12x2 חיובית משני צידי האפס ואינה מחליפה סימן — ולכן x = 0 אינה נקודת פיתול. איפוס הנגזרת השנייה הוא תנאי הכרחי בלבד. למעשה f'(x) = 4x3 מחליפה סימן משלילי לחיובי ב-x = 0, ולכן זו נקודת מינימום, (0, 5)
שאלה 13. f'(x) = 3x2 + 2ax + b ולכן f''(x) = 6x + 2a. מנקודת הפיתול: f''(2) = 12 + 2a = 0, ולכן a = -6. מהנקודה הקריטית: f'(1) = 3 - 12 + b = 0, ולכן b = 9. הפונקציה היא f(x) = x3 - 6x2 + 9x. בדיקה: f'(x) = 3x2 - 12x + 9 = 3(x - 1)(x - 3) — אכן נקודה קריטית ב-x = 1, ו-f''(x) = 6x - 12 מתאפסת ב-x = 2 ✓
