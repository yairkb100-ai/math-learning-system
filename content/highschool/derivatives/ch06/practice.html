✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: נגזרת שנייה קל
מצאו את הנגזרת השנייה של f(x) = 3x4 - 2x3 + x - 8.
f'(x) = 12x3 - 6x2 + 1

f''(x) = 36x2 - 12x
תרגיל 2: נקודת פיתול של פונקציה מעוקבת קל
מצאו את נקודת הפיתול של f(x) = x3 - 3x2 + 4.
f'(x) = 3x2 - 6x, ולכן f''(x) = 6x - 6.

6x - 6 = 0 ⇒ x = 1.

בדיקת סימן: f''(0) = -6 (קמור כלפי מטה), f''(2) = 6 (קמור כלפי מעלה) — הסימן התחלף ✓

f(1) = 1 - 3 + 4 = 2, ולכן נקודת הפיתול היא (1, 2).
תרגיל 3: תחומי קמירות בינוני
מצאו את תחומי הקמירות ואת נקודות הפיתול של f(x) = x4 - 6x2.
f'(x) = 4x3 - 12x, ולכן f''(x) = 12x2 - 12 = 12(x - 1)(x + 1).

f''(x) = 0 ⇒ x = 1 או x = (-1).

טבלת סימנים: עבור x = (-2) מתקבל f'' = 36 (חיובי), עבור x = 0 מתקבל f'' = -12 (שלילי), ועבור x = 2 מתקבל f'' = 36 (חיובי).

קמורה כלפי מעלה בתחומים x < -1 וגם x > 1; קמורה כלפי מטה בתחום -1 < x < 1.

בשתי הנקודות יש החלפת סימן. הערכים: f(1) = 1 - 6 = -5 ו-f(-1) = 1 - 6 = -5, ולכן נקודות הפיתול הן (1, -5) ו-(-1, -5).
תרגיל 4: סיווג קיצון במבחן הנגזרת השנייה בינוני
מצאו את נקודות הקיצון של f(x) = 2x3 + 3x2 - 12x וסווגו אותן בעזרת הנגזרת השנייה.
f'(x) = 6x2 + 6x - 12 = 6(x + 2)(x - 1) = 0 ⇒ x = -2 או x = 1.

f''(x) = 12x + 6.

- f''(-2) = -18 — שלילי, ולכן מקסימום. f(-2) = -16 + 12 + 24 = 20, כלומר (-2, 20).
- f''(1) = 18 — חיובי, ולכן מינימום. f(1) = 2 + 3 - 12 = -7, כלומר (1, -7).
תרגיל 5: אתגר: שתי נקודות פיתול מאתגר
מצאו את כל נקודות הפיתול של f(x) = x4 - 4x3, וקבעו לגבי הנקודה הקריטית x = 0 אם היא נקודת קיצון.
f'(x) = 4x3 - 12x2 = 4x2(x - 3), ולכן הנקודות הקריטיות הן x = 0 ו-x = 3.

f''(x) = 12x2 - 24x = 12x(x - 2) = 0 ⇒ x = 0 או x = 2.

בדיקת סימן ל-f'': עבור x = (-1) מתקבל 36 (חיובי), עבור x = 1 מתקבל -12 (שלילי), ועבור x = 3 מתקבל 36 (חיובי). בשתי הנקודות יש החלפת סימן, ולכן שתיהן נקודות פיתול: f(0) = 0 ו-f(2) = 16 - 32 = -16, כלומר (0, 0) ו-(2, -16).

לגבי x = 0: כאן f''(0) = 0 והמבחן אינו מכריע. מטבלת הסימנים של f' ראינו שהנגזרת שלילית משני צידי האפס, ולכן אין שם קיצון — זו נקודת פיתול עם משיק אופקי.
תרגיל 6: חישוב נגזרת שנייה קל
מצאו את הנגזרת השנייה של f(x) = x4 - 3x2 + 5x.
הנגזרת הראשונה: f'(x) = 4x3 - 6x + 5.

גוזרים שוב: f''(x) = 12x2 - 6. שימו לב שהאיבר 5x נעלם בגזירה השנייה.
תרגיל 7: נקודת פיתול בלי קיצון בינוני
מצאו את נקודת הפיתול של f(x) = x3 - 6x2 + 12x, וקבעו אם יש לפונקציה נקודות קיצון.
f'(x) = 3x2 - 12x + 12 = 3(x - 2)2, ולכן f''(x) = 6x - 12.

איפוס: 6x - 12 = 0 נותן x = 2. בדיקת סימן: f''(1) = -6 ו-f''(3) = 6 — הסימן התחלף.

הערך: f(2) = 8 - 24 + 24 = 8, ולכן נקודת הפיתול היא (2, 8).

נקודות קיצון: הנגזרת 3(x - 2)2 מתאפסת ב-x = 2 אך אינה מחליפה סימן (היא אי-שלילית תמיד), ולכן אין נקודות קיצון — הפונקציה עולה בכל תחומה, והמשיק ב-x = 2 אופקי.
תרגיל 8: סיווג קיצון בעזרת הנגזרת השנייה בינוני
מצאו את נקודות הקיצון של f(x) = 2x3 + 3x2 - 36x וסווגו אותן בעזרת הנגזרת השנייה.
f'(x) = 6x2 + 6x - 36 = 6(x + 3)(x - 2) = 0, ולכן x = (-3) או x = 2.

f''(x) = 12x + 6.

f''(-3) = -30 — שלילי, ולכן מקסימום. ערכו: f(-3) = -54 + 27 + 108 = 81, כלומר (-3, 81).

f''(2) = 30 — חיובי, ולכן מינימום. ערכו: f(2) = 16 + 12 - 72 = -44, כלומר (2, -44).
תרגיל 9: אתגר: תחומי קמירות ושתי נקודות פיתול מאתגר
מצאו את תחומי הקמירות ואת כל נקודות הפיתול של f(x) = x4 - 4x3 + 2.
f'(x) = 4x3 - 12x2, ולכן f''(x) = 12x2 - 24x = 12x(x - 2).

איפוס: x = 0 או x = 2.

טבלת סימנים ל-f'': עבור x = (-1) מתקבל 36 (חיובי), עבור x = 1 מתקבל (-12) (שלילי), ועבור x = 3 מתקבל 36 (חיובי).

המסקנה: הפונקציה קמורה כלפי מעלה בתחומים x < 0 וגם x > 2, וקמורה כלפי מטה בתחום 0 < x < 2.

בשתי הנקודות יש החלפת סימן. הערכים: f(0) = 2 ו-f(2) = 16 - 32 + 2 = -14, ולכן נקודות הפיתול הן (0, 2) ו-(2, -14).
