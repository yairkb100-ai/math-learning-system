תרגיל 1: תחום הגדרה וחיתוך צירים קל
מצאו את תחום ההגדרה ואת נקודות החיתוך עם הצירים של f(x) = x - 5x + 3.
תחום הגדרה: המכנה מתאפס ב-x = (-3), ולכן התחום הוא כל x ≠ -3.

חיתוך עם ציר ה-x: x - 5 = 0 ⇒ x = 5, כלומר (5, 0).

חיתוך עם ציר ה-y: f(0) = -53, כלומר (0, -53).
תרגיל 2: אסימפטוטות קל
מצאו את האסימפטוטות של f(x) = 5x + 1x - 3.
אנכית: המכנה מתאפס ב-x = 3, והמונה שם שווה 16 ואינו מתאפס — ולכן x = 3 אסימפטוטה אנכית.

אופקית: דרגות המונה והמכנה שוות, ומנת המקדמים המובילים היא 51 — ולכן y = 5.
תרגיל 3: חקירה מלאה של פולינום בינוני
בצעו חקירה מלאה של f(x) = x3 - 12x2 + 36x: תחום הגדרה, נקודות חיתוך עם הצירים, קיצון ונקודת פיתול.
תחום הגדרה: כל x ממשי.

חיתוך עם הצירים: f(x) = x(x - 6)2, ולכן השורשים הם x = 0 ו-x = 6 (כפול). f(0) = 0, כך שהגרף עובר בראשית.

קיצון: f'(x) = 3x2 - 24x + 36 = 3(x - 2)(x - 6) = 0 ⇒ x = 2 או x = 6.

f''(x) = 6x - 24. מתקיים f''(2) = -12 — מקסימום, f(2) = 8 - 48 + 72 = 32, כלומר (2, 32); ומתקיים f''(6) = 12 — מינימום, f(6) = 0, כלומר (6, 0).

פיתול: 6x - 24 = 0 ⇒ x = 4, והסימן מתחלף. f(4) = 64 - 192 + 144 = 16, ולכן הנקודה היא (4, 16).
תרגיל 4: חקירה מלאה של פונקציה רציונלית בינוני
בצעו חקירה מלאה של f(x) = 2x + 4x - 3.
תחום הגדרה: כל x ≠ 3.

חיתוך עם הצירים: המונה מתאפס ב-x = (-2), ולכן (-2, 0); והצבת x = 0 נותנת 4-3, כלומר (0, -43).

אסימפטוטות: אנכית x = 3 (המונה שם שווה 10); אופקית y = 2 (הדרגות שוות ומנת המקדמים היא 21).

קיצון: f'(x) = 2(x - 3) - (2x + 4)(x - 3)2 = -10(x - 3)2. הנגזרת שלילית בכל תחום ההגדרה, ולכן אין נקודות קיצון, והפונקציה יורדת בתחום x < 3 ויורדת בנפרד גם בתחום x > 3.
תרגיל 5: אתגר: פונקציה עם שתי נקודות קיצון מאתגר
בצעו חקירה מלאה של f(x) = x + 4x.
תחום הגדרה: כל x ≠ 0.

חיתוך עם הצירים: איחוד לשבר אחד נותן f(x) = x2 + 4x. המונה x2 + 4 חיובי תמיד ואינו מתאפס לעולם, ולכן אין חיתוך עם ציר ה-x; וגם אין חיתוך עם ציר ה-y, שהרי x = 0 אינו בתחום.

אסימפטוטה אנכית: x = 0.

קיצון: f'(x) = 1 - 4x2 = 0 ⇒ x2 = 4 ⇒ x = 2 או x = (-2).

הנגזרת השנייה: f''(x) = 8x3. מתקיים f''(2) = 1 — חיובי, ולכן מינימום, f(2) = 2 + 2 = 4, כלומר (2, 4). ומתקיים f''(-2) = -1 — שלילי, ולכן מקסימום, f(-2) = -2 - 2 = -4, כלומר (-2, -4).

גם כאן ערך המקסימום (-4) קטן מערך המינימום 4 — שני ענפים נפרדים משני צידי האסימפטוטה.
תרגיל 6: תחום הגדרה ואסימפטוטות קל
מצאו את תחום ההגדרה ואת האסימפטוטות של f(x) = x + 6x - 4.
תחום ההגדרה: כל x ≠ 4.

אסימפטוטה אנכית: המכנה מתאפס ב-x = 4, והמונה שם שווה 10 ואינו מתאפס — ולכן x = 4 אסימפטוטה אנכית.

אסימפטוטה אופקית: הדרגות שוות ומנת המקדמים המובילים היא 11, ולכן y = 1.
תרגיל 7: חקירה מלאה של פולינום בינוני
בצעו חקירה של f(x) = x3 - 3x2 - 9x + 11: מצאו את נקודות הקיצון (וסווגו אותן) ואת נקודת הפיתול.
f'(x) = 3x2 - 6x - 9 = 3(x - 3)(x + 1) = 0, ולכן x = 3 או x = (-1).

f''(x) = 6x - 6.

f''(3) = 12 — חיובי, ולכן מינימום: f(3) = 27 - 27 - 27 + 11 = -16, כלומר (3, -16).

f''(-1) = -12 — שלילי, ולכן מקסימום: f(-1) = -1 - 3 + 9 + 11 = 16, כלומר (-1, 16).

פיתול: 6x - 6 = 0 נותן x = 1, והסימן מתחלף. f(1) = 1 - 3 - 9 + 11 = 0, ולכן נקודת הפיתול היא (1, 0).
תרגיל 8: חקירה מלאה של פונקציה רציונלית בינוני
בצעו חקירה מלאה של f(x) = 4xx - 2.
תחום הגדרה: כל x ≠ 2.

חיתוך עם הצירים: המונה מתאפס ב-x = 0, ו-f(0) = 0 — הגרף עובר בראשית הצירים, וזו נקודת החיתוך היחידה עם שני הצירים.

אסימפטוטות: אנכית x = 2 (המונה שם שווה 8); אופקית y = 4, כי הדרגות שוות ומנת המקדמים המובילים היא 41.

קיצון: לפי כלל המנה,

f'(x) = 4(x - 2) - 4x(x - 2)2 = -8(x - 2)2

הנגזרת שלילית בכל תחום ההגדרה, ולכן אין נקודות קיצון. הניסוח הנכון: הפונקציה יורדת בתחום x < 2 ויורדת בנפרד גם בתחום x > 2 — אין לחבר את שני הענפים.
תרגיל 9: אתגר: חקירה מלאה עם אסימפטוטה אנכית מאתגר
בצעו חקירה מלאה של f(x) = x + 1x, כולל סיווג נקודות הקיצון.
תחום הגדרה: כל x ≠ 0.

חיתוך עם הצירים: איחוד לשבר אחד נותן f(x) = x2 + 1x. המונה x2 + 1 חיובי תמיד ואינו מתאפס, ולכן אין חיתוך עם ציר ה-x; וגם אין חיתוך עם ציר ה-y, שהרי x = 0 אינו בתחום.

אסימפטוטות: אנכית x = 0. אין אסימפטוטה אופקית, כי דרגת המונה גדולה מדרגת המכנה.

קיצון: f'(x) = 1 - 1x2 = 0 נותן x2 = 1, כלומר x = 1 או x = (-1).

הנגזרת השנייה: f''(x) = 2x3. מתקיים f''(1) = 2 — חיובי, ולכן מינימום: f(1) = 2, כלומר (1, 2). ומתקיים f''(-1) = -2 — שלילי, ולכן מקסימום: f(-1) = -2, כלומר (-1, -2).

גם כאן ערך המקסימום (-2) קטן מערך המינימום 2, משום ששתי הנקודות יושבות בענפים נפרדים משני צידי האסימפטוטה x = 0.
