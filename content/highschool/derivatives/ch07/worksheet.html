דף עבודה — פרק 7: חקירת פונקציה מלאה ושרטוט הגרף

חשבון דיפרנציאלי · פרק 7 — תחום הגדרה, חיתוך צירים, אסימפטוטות, קיצון וקמירות
שם: כיתה: תאריך:
סדר החקירה קבוע: (1) תחום הגדרה — בפולינום כל x ממשי, וברציונלית פוסלים את מאפסי המכנה; (2) חיתוך עם ציר ה-y בהצבת x = 0, וחיתוך עם ציר ה-x מפתרון f(x) = 0 (ברציונלית — איפוס המונה); (3) אסימפטוטות: אנכית במאפס המכנה שאינו מאפס את המונה, ואופקית לפי השוואת דרגות; (4) קיצון מ-f'(x) = 0 וסיווג; (5) קמירות ופיתול מ-f''(x) = 0 בתוספת בדיקת החלפת סימן; (6) שרטוט. זהירות: אסימפטוטה אנכית שוברת את התחום לשניים, ואין לחבר בין שני הענפים ואין לתאר אותם כקטע אחד.

שאלה 1 — תחום הגדרה קל

מצאו את תחום ההגדרה:

  1. f(x) = x + 7x - 2 ⟵
  2. f(x) = 5x + 6 ⟵
  3. f(x) = x3 - 4x ⟵

שאלה 2 — חיתוך עם הצירים — פולינום קל

מצאו את נקודות החיתוך של הגרף f(x) = x2 - 9 עם שני הצירים.

שאלה 3 — חיתוך עם הצירים — פונקציה רציונלית קל

נתונה f(x) = x - 4x + 1. מצאו את תחום ההגדרה ואת נקודות החיתוך עם שני הצירים.

שאלה 4 — שתי האסימפטוטות קל

מצאו את האסימפטוטה האנכית ואת האסימפטוטה האופקית של f(x) = 3x + 2x - 5. נמקו כל אחת מהן.

שאלה 5 — אסימפטוטה אופקית לפי השוואת דרגות קל

לכל פונקציה קבעו מהי האסימפטוטה האופקית (או שאין כזאת):

  1. f(x) = x + 1x2 + 3 ⟵
  2. f(x) = x2 + 1x - 2 ⟵
  3. f(x) = 4x - 12x + 3 ⟵

שאלה 6 — קיצון ופיתול של פולינום בינוני

נתונה f(x) = x3 - 3x2 - 9x + 5. מצאו את נקודות הקיצון (וסווגו אותן) ואת נקודת הפיתול.

שאלה 7 — חקירה מלאה של פולינום עם שורש כפול בינוני

בצעו חקירה מלאה של f(x) = x3 - 3x2: תחום הגדרה, חיתוך עם הצירים, קיצון ונקודת פיתול. אחר כך התאימו כל נקודה שמצאתם לנקודה המסומנת בציור.

ארבע נקודות החקירה של הפונקציה על מערכת הצירים

שאלה 8 — חקירה מלאה של פונקציה רציונלית בינוני

בצעו חקירה מלאה של f(x) = 3x - 6x + 2: תחום הגדרה, חיתוך עם הצירים, אסימפטוטות וקיצון.

שאלה 9 — פונקציה מדרגה רביעית בינוני

נתונה f(x) = x4 - 8x2 + 16. מצאו את נקודות החיתוך עם הצירים ואת נקודות הקיצון, וסווגו אותן בעזרת f''.

שאלה 10 — מצאו את הטעות בינוני

עבור f(x) = x + 1x - 2 חישב תלמיד נכון f'(x) = -3(x - 2)2, ומיד כתב: "הנגזרת שלילית תמיד, ולכן הפונקציה יורדת בכל x". הסבירו מה שגוי בניסוח, וכתבו את הניסוח הנכון.

שאלה 11 — אתגר: חקירה מלאה של פולינום מאתגר

בצעו חקירה מלאה של f(x) = x3 - 3x + 2: תחום הגדרה, חיתוך עם הצירים (רמז — נסו להציב x = 1), קיצון, ונקודת פיתול. תארו במילים כיצד נראה הגרף.

שאלה 12 — אתגר: רציונלית עם שתי נקודות קיצון מאתגר

בצעו חקירה מלאה של f(x) = x + 9x: תחום הגדרה, חיתוך עם הצירים, אסימפטוטות וקיצון. הסבירו מדוע ערך המקסימום קטן מערך המינימום.

שאלה 13 — אתגר: שחזור פונקציה מנתוני חקירה מאתגר

נתונה f(x) = x3 + ax2 + bx + c. ידוע שהגרף עובר בנקודה (0, 4), שיש לו נקודה קריטית בנקודה שבה x = 2, ושנקודת הפיתול שלו היא בנקודה שבה x = 1.

  1. מצאו את a, את b ואת c.
  2. מצאו את נקודות הקיצון וסווגו אותן.

שאלה 1. א. כל x ≠ 2   ב. כל x ≠ -6   ג. כל x ממשי — בפולינום אין מכנה ואין שורש, ולכן אין מה לפסול
שאלה 2. חיתוך עם ציר ה-y: f(0) = -9, כלומר (0, -9). חיתוך עם ציר ה-x: x2 - 9 = 0 נותן x = 3 או x = -3, כלומר (3, 0) ו-(-3, 0)
שאלה 3. תחום הגדרה: כל x ≠ -1. חיתוך עם ציר ה-x: מאפסים את המונה, x - 4 = 0, ולכן (4, 0). חיתוך עם ציר ה-y: f(0) = -41 = -4, כלומר (0, -4)
שאלה 4. אנכית: המכנה מתאפס ב-x = 5, והמונה שם שווה 17 ואינו מתאפס — ולכן x = 5 אסימפטוטה אנכית. אופקית: דרגות המונה והמכנה שוות, ומנת המקדמים המובילים היא 31 — ולכן y = 3
שאלה 5. א. דרגת המונה קטנה מדרגת המכנה, ולכן y = 0   ב. דרגת המונה גדולה מדרגת המכנה, ולכן אין אסימפטוטה אופקית   ג. הדרגות שוות, ומנת המקדמים המובילים היא 42 = 2, ולכן y = 2
שאלה 6. f'(x) = 3x2 - 6x - 9 = 3(x - 3)(x + 1) = 0 נותן x = 3 או x = -1. הנגזרת השנייה f''(x) = 6x - 6. מתקיים f''(3) = 12 — מינימום, f(3) = 27 - 27 - 27 + 5 = -22, כלומר (3, -22); ומתקיים f''(-1) = -12 — מקסימום, f(-1) = -1 - 3 + 9 + 5 = 10, כלומר (-1, 10). פיתול: 6x - 6 = 0 נותן x = 1 והסימן מתחלף, f(1) = 1 - 3 - 9 + 5 = -6, כלומר (1, -6)
שאלה 7. תחום הגדרה: כל x ממשי. חיתוך עם הצירים: f(x) = x2(x - 3), ולכן (0, 0) (שורש כפול — הגרף נוגע בציר) ו-(3, 0); זו גם נקודת החיתוך עם ציר ה-y. קיצון: f'(x) = 3x2 - 6x = 3x(x - 2) = 0 נותן x = 0 או x = 2; f''(x) = 6x - 6, ומתקיים f''(0) = -6 — מקסימום (0, 0), ו-f''(2) = 6 — מינימום, f(2) = 8 - 12 = -4, כלומר (2, -4). פיתול: x = 1 והסימן מתחלף, f(1) = 1 - 3 = -2, כלומר (1, -2). בציור: A היא (0, 0), B היא (3, 0), C היא המינימום ו-D היא נקודת הפיתול
שאלה 8. תחום הגדרה: כל x ≠ -2. חיתוך עם ציר ה-x: 3x - 6 = 0 נותן (2, 0). חיתוך עם ציר ה-y: f(0) = -62 = -3, כלומר (0, -3). אסימפטוטות: אנכית x = -2 (המונה שם שווה -12); אופקית y = 3 (הדרגות שוות ומנת המקדמים היא 31). קיצון: f'(x) = 3(x + 2) - (3x - 6)(x + 2)2 = 12(x + 2)2 — חיובית בכל תחום ההגדרה, ולכן אין נקודות קיצון, והפונקציה עולה בתחום x < -2 ועולה בנפרד גם בתחום x > -2
שאלה 9. חיתוך עם ציר ה-x: f(x) = (x2 - 4)2, ולכן (2, 0) ו-(-2, 0) (שני שורשים כפולים). חיתוך עם ציר ה-y: f(0) = 16, כלומר (0, 16). קיצון: f'(x) = 4x3 - 16x = 4x(x - 2)(x + 2) = 0 נותן x = 0, x = 2 או x = -2; f''(x) = 12x2 - 16, ומתקיים f''(0) = -16 — מקסימום (0, 16), f''(2) = 32 — מינימום (2, 0), ו-f''(-2) = 32 — מינימום (-2, 0)
שאלה 10. הנגזרת אכן שלילית בכל נקודה בתחום, אבל תחום ההגדרה עצמו שבור לשניים על ידי האסימפטוטה x = 2. משפט העלייה והירידה תקף רק בתוך קטע רציף, ולא מעבר לחור בתחום. הניסוח הנכון: הפונקציה יורדת בתחום x < 2 ויורדת בנפרד גם בתחום x > 2 — ואסור לחבר את שני הענפים בקו אחד
שאלה 11. תחום הגדרה: כל x ממשי. חיתוך עם ציר ה-y: f(0) = 2. חיתוך עם ציר ה-x: הצבת x = 1 נותנת 0, והפירוק הוא f(x) = (x - 1)2(x + 2) — ולכן (1, 0) (שורש כפול, הגרף נוגע בציר) ו-(-2, 0). קיצון: f'(x) = 3x2 - 3 = 3(x - 1)(x + 1) = 0 נותן x = 1 או x = -1; f''(x) = 6x, ומתקיים f''(1) = 6 — מינימום (1, 0), ו-f''(-1) = -6 — מקסימום, f(-1) = -1 + 3 + 2 = 4, כלומר (-1, 4). פיתול: 6x = 0 נותן x = 0 והסימן מתחלף, ולכן (0, 2). הגרף עולה עד המקסימום (-1, 4), יורד דרך נקודת הפיתול (0, 2) עד המינימום (1, 0) שבו הוא נוגע בציר ה-x, ומשם ממשיך לעלות
שאלה 12. תחום הגדרה: כל x ≠ 0. איחוד לשבר אחד: f(x) = x2 + 9x; המונה חיובי תמיד ואינו מתאפס, ולכן אין חיתוך עם ציר ה-x, וגם אין חיתוך עם ציר ה-y כי x = 0 אינו בתחום. אסימפטוטה אנכית: x = 0; אסימפטוטה אופקית אין, כי דרגת המונה גדולה מדרגת המכנה. קיצון: f'(x) = 1 - 9x2 = 0 נותן x2 = 9, כלומר x = 3 או x = -3; f''(x) = 18x3, ומתקיים f''(3) = 23 — מינימום, f(3) = 3 + 3 = 6, כלומר (3, 6); ומתקיים f''(-3) = -23 — מקסימום, f(-3) = -3 - 3 = -6, כלומר (-3, -6). ערך המקסימום קטן מערך המינימום משום ששתי הנקודות יושבות בשני ענפים נפרדים משני צידי האסימפטוטה, וכל אחת מהן מקומית בענף שלה בלבד
שאלה 13. א. מהנקודה (0, 4): f(0) = c = 4. הנגזרות: f'(x) = 3x2 + 2ax + b ו-f''(x) = 6x + 2a. מנקודת הפיתול: f''(1) = 6 + 2a = 0, ולכן a = -3. מהנקודה הקריטית: f'(2) = 12 - 12 + b = 0, ולכן b = 0. הפונקציה היא f(x) = x3 - 3x2 + 4. ב. f'(x) = 3x2 - 6x = 3x(x - 2) = 0 נותן x = 0 או x = 2; f''(0) = -6 — מקסימום (0, 4), ו-f''(2) = 6 — מינימום, f(2) = 8 - 12 + 4 = 0, כלומר (2, 0)
