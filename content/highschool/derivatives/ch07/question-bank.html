חלק א' — תחום הגדרה 🚧 (שאלות 1–4)

  1. מצאו את תחום ההגדרה של f(x) = xx - 7.
  2. מצאו את תחום ההגדרה של f(x) = 2x + 1x2 - 9.
  3. מצאו את תחום ההגדרה של f(x) = x4 - 5x2.
  4. מצאו את תחום ההגדרה של f(x) = x + 6x.

חלק ב' — חיתוך עם הצירים ✖️ (שאלות 5–8)

  1. מצאו את נקודות החיתוך של f(x) = x2 - 4x עם שני הצירים.
  2. מצאו את נקודות החיתוך של f(x) = x3 - x עם שני הצירים.
  3. מצאו את נקודות החיתוך של f(x) = x + 5x - 1 עם שני הצירים.
  4. מצאו את נקודות החיתוך של f(x) = x2 - 2x - 8 עם שני הצירים.

חלק ג' — אסימפטוטות 📉 (שאלות 9–12)

  1. מצאו את האסימפטוטות של f(x) = 4x - 3.
  2. מצאו את האסימפטוטות של f(x) = 7xx + 2.
  3. מצאו את האסימפטוטות של f(x) = x2 + 1x - 4.
  4. מצאו את האסימפטוטות של f(x) = 2x - 13x + 6.

חלק ד' — קיצון וקמירות 📈 (שאלות 13–16)

  1. מצאו וסווגו את נקודת הקיצון של f(x) = x2 - 10x + 3.
  2. מצאו וסווגו את נקודות הקיצון של f(x) = x3 - 6x2 + 9x.
  3. מצאו את נקודת הפיתול של f(x) = x3 - 6x2 + 9x.
  4. מצאו וסווגו את נקודת הקיצון של f(x) = x4 - 4x.

חלק ה' — חקירה מלאה 🔬 (שאלות 17–20)

  1. בצעו חקירה של f(x) = x2 - 6x + 5: חיתוך עם הצירים וקיצון.
  2. בצעו חקירה של f(x) = x3 + 3x2: חיתוך עם הצירים, קיצון ופיתול.
  3. בצעו חקירה של f(x) = x - 1x + 3: תחום, חיתוך עם הצירים, אסימפטוטות וקיצון.
  4. בצעו חקירה של f(x) = x4 - 2x2 + 1: חיתוך עם הצירים וקיצון.

חלק ו' — אתגרים 🏆 (שאלות 21–24)

  1. מדוע אסור לכתוב ש-f(x) = 1x יורדת בכל תחום הגדרתה כקטע אחד? נסחו נכון.
  2. האם ייתכן שערך המקסימום המקומי של פונקציה קטן מערך המינימום המקומי שלה? הסבירו ותנו דוגמה.
  3. נתונה f(x) = x2 - 1x - 1. המכנה מתאפס ב-x = 1. האם זו אסימפטוטה אנכית?
  4. נתונה f(x) = x3 + ax2 + 12x ונקודת פיתול ב-x = 1. מצאו את a וקבעו אם יש נקודות קיצון.

🔑 פתרונות מלאים — מאגר שאלות פרק 7

למורה / להורה / לבדיקה עצמית
1. כל x ≠ 7
2. המכנה מתאפס ב-x = 3 וב-x = -3, ולכן התחום הוא כל x פרט לשני הערכים האלה
3. כל x ממשי — זהו פולינום
4. כל x ≠ 0
5. f(x) = x(x - 4), ולכן החיתוכים עם ציר ה-x הם (0, 0) ו-(4, 0); החיתוך עם ציר ה-y הוא (0, 0)
6. f(x) = x(x - 1)(x + 1), ולכן (0, 0), (1, 0) ו-(-1, 0); החיתוך עם ציר ה-y הוא (0, 0)
7. המונה מתאפס ב-x = -5, ולכן (-5, 0); והצבת x = 0 נותנת 5-1 = -5, כלומר (0, -5)
8. f(x) = (x - 4)(x + 2), ולכן (4, 0) ו-(-2, 0); והצבת x = 0 נותנת (0, -8)
9. אנכית x = 3 (המונה שם שווה 4); אופקית y = 0, כי דרגת המונה קטנה מדרגת המכנה
10. אנכית x = -2 (המונה שם שווה -14); אופקית y = 7, כי הדרגות שוות ומנת המקדמים היא 71
11. אנכית x = 4 (המונה שם שווה 17); אין אסימפטוטה אופקית, כי דרגת המונה גדולה מדרגת המכנה
12. אנכית x = -2 (המונה שם שווה -5); אופקית y = 23, כי הדרגות שוות ומנת המקדמים המובילים היא 23
13. f'(x) = 2x - 10 = 0 נותן x = 5; f''(x) = 2 חיובי, ולכן מינימום, f(5) = 25 - 50 + 3 = -22, כלומר (5, -22)
14. f'(x) = 3x2 - 12x + 9 = 3(x - 1)(x - 3) = 0 נותן x = 1 או x = 3; f''(x) = 6x - 12, ומתקיים f''(1) = -6 — מקסימום, f(1) = 4, כלומר (1, 4); ו-f''(3) = 6 — מינימום, f(3) = 0, כלומר (3, 0)
15. f''(x) = 6x - 12 = 0 נותן x = 2, והסימן מתחלף; f(2) = 8 - 24 + 18 = 2, ולכן נקודת הפיתול היא (2, 2)
16. f'(x) = 4x3 - 4 = 0 נותן x3 = 1, כלומר x = 1; f''(x) = 12x2 ו-f''(1) = 12 חיובי, ולכן מינימום, f(1) = 1 - 4 = -3, כלומר (1, -3)
17. f(x) = (x - 1)(x - 5), ולכן החיתוכים עם ציר ה-x הם (1, 0) ו-(5, 0), ועם ציר ה-y הנקודה (0, 5). קיצון: f'(x) = 2x - 6 = 0 נותן x = 3, ו-f''(x) = 2 חיובי — מינימום (3, -4)
18. f(x) = x2(x + 3), ולכן (0, 0) (שורש כפול) ו-(-3, 0). קיצון: f'(x) = 3x2 + 6x = 3x(x + 2) = 0 נותן x = 0 או x = -2; f''(x) = 6x + 6, ומתקיים f''(0) = 6 — מינימום (0, 0), ו-f''(-2) = -6 — מקסימום, f(-2) = -8 + 12 = 4, כלומר (-2, 4). פיתול: x = -1, f(-1) = -1 + 3 = 2, כלומר (-1, 2)
19. תחום: כל x ≠ -3. חיתוכים: (1, 0) ו-(0, -13). אסימפטוטות: אנכית x = -3, אופקית y = 1. קיצון: f'(x) = (x + 3) - (x - 1)(x + 3)2 = 4(x + 3)2 — חיובית תמיד, ולכן אין קיצון, והפונקציה עולה בתחום x < -3 ועולה בנפרד גם בתחום x > -3
20. f(x) = (x2 - 1)2, ולכן (1, 0) ו-(-1, 0) (שורשים כפולים), והחיתוך עם ציר ה-y הוא (0, 1). קיצון: f'(x) = 4x3 - 4x = 4x(x - 1)(x + 1) = 0; f''(x) = 12x2 - 4, ומתקיים f''(0) = -4 — מקסימום (0, 1), f''(1) = 8 — מינימום (1, 0), ו-f''(-1) = 8 — מינימום (-1, 0)
21. כי תחום ההגדרה שבור ב-x = 0, ומשפט העלייה והירידה תקף רק בקטע רציף. הניסוח הנכון: הפונקציה יורדת בתחום x < 0 ויורדת בנפרד גם בתחום x > 0
22. כן — כשהן יושבות בשני ענפים נפרדים משני צידי אסימפטוטה אנכית, שהרי כל אחת מהן מקומית בענף שלה בלבד. דוגמה: f(x) = x + 4x, שבה המקסימום הוא (-2, -4) והמינימום הוא (2, 4)
23. לא — גם המונה מתאפס שם, שהרי x2 - 1 = (x - 1)(x + 1). אחרי צמצום מתקבל x + 1 לכל x ≠ 1, ולכן ב-x = 1 יש "חור" בגרף ולא אסימפטוטה אנכית
24. f''(x) = 6x + 2a, ומהתנאי f''(1) = 6 + 2a = 0 מתקבל a = -3. אז f'(x) = 3x2 - 6x + 12, והדיסקרימיננטה שלה היא 36 - 144 = -108 — שלילית, ולכן הנגזרת אינה מתאפסת לעולם ואין נקודות קיצון
