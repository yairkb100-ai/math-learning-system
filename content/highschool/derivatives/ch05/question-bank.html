חלק א' — שיפוע המשיק 📐 (שאלות 1–4)

  1. מהו שיפוע המשיק לגרף f(x) = x2 - 6x בנקודה שבה x = 4?
  2. מהו שיפוע המשיק לגרף f(x) = x3 + x בנקודה שבה x = 1?
  3. מהו שיפוע המשיק לגרף f(x) = 5x2 - 2x בנקודה שבה x = -1?
  4. מהו שיפוע המשיק לגרף f(x) = 1x בנקודה שבה x = 1?

חלק ב' — משוואת המשיק בנקודה ✏️ (שאלות 5–8)

  1. כתבו את משוואת המשיק לגרף f(x) = x2 בנקודה שבה x = 3.
  2. כתבו את משוואת המשיק לגרף f(x) = x2 - 2x + 4 בנקודה שבה x = 0.
  3. כתבו את משוואת המשיק לגרף f(x) = x3 בנקודה שבה x = -1.
  4. כתבו את משוואת המשיק לגרף f(x) = x3 - 6x2 + 5 בנקודה שבה x = 1.

חלק ג' — משיק אופקי 📏 (שאלות 9–12)

  1. היכן המשיק לגרף f(x) = x2 - 10x + 7 אופקי, ומהי משוואתו?
  2. מצאו את כל המשיקים האופקיים לגרף f(x) = x3 - 3x.
  3. מצאו את שיעורי ה-x של כל הנקודות שבהן המשיק לגרף f(x) = x4 - 8x2 אופקי.
  4. היכן המשיק לגרף f(x) = x2 + 4x - 1 אופקי, ומהי משוואתו?

חלק ד' — מקביל ומאונך לישר 🧭 (שאלות 13–16)

  1. מצאו את המשיק לגרף f(x) = x2 + 2x המקביל לישר y = 8x.
  2. מצאו את כל המשיקים לגרף f(x) = x3 המקבילים לישר y = 3x + 4.
  3. מצאו את המשיק לגרף f(x) = x2 - 3x המאונך לישר y = -17x.
  4. מצאו את המשיק לגרף f(x) = 2x2 - x המקביל לישר y = 7x + 1.

חלק ה' — משיק מנקודה חיצונית 🎯 (שאלות 17–20)

  1. מצאו את כל המשיקים לגרף f(x) = x2 העוברים דרך (0, -9).
  2. מצאו את כל המשיקים לגרף f(x) = x2 העוברים דרך (1, -3).
  3. מצאו את כל המשיקים לגרף f(x) = x2 + 1 העוברים דרך ראשית הצירים.
  4. האם (2, 4) נמצאת על הגרף של f(x) = x2? הסיקו מכך אם צריך לסמן נקודת השקה, וכתבו את המשיק.

חלק ו' — אתגרים 🏆 (שאלות 21–24)

  1. מצאו את המשיק לגרף f(x) = x2 המקביל למיתר המחבר את (0, 0) ואת (4, 16).
  2. נתון f(x) = x2 + bx + 1. המשיק בנקודה שבה x = 2 אופקי. מצאו את b ואת משוואת המשיק.
  3. הוכיחו שהישר y = 4x - 4 משיק לגרף f(x) = x2, ומצאו את נקודת ההשקה.
  4. המשיק לגרף f(x) = x3 בנקודה שבה x = 2 — היכן הוא חותך את ציר ה-x?
