תרגול: משוואת המשיק לגרף פונקציה

פרק 5 · חשבון דיפרנציאלי · פרק 5 — נקודת השקה, שיפוע מהנגזרת ומשיקים מנקודה חיצונית

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: משיק לפרבולה קל
מצאו את משוואת המשיק לגרף f(x) = x2 + 3x בנקודה שבה x = 1.
נקודת ההשקה: f(1) = 1 + 3 = 4, כלומר (1, 4).

השיפוע: f'(x) = 2x + 3, ולכן f'(1) = 5.

המשיק: y - 4 = 5(x - 1), כלומר y = 5x - 1.

בדיקה: עבור x = 1 מתקבל y = 4 ✓
תרגיל 2: משיק בנקודה שלילית קל
מצאו את משוואת המשיק לגרף f(x) = x3 - 4x בנקודה שבה x = (-1).
נקודת ההשקה: f(-1) = -1 + 4 = 3, כלומר (-1, 3).

השיפוע: f'(x) = 3x2 - 4, ולכן f'(-1) = 3 - 4 = -1.

המשיק: y - 3 = -1 · (x + 1), כלומר y = -x + 2.
תרגיל 3: משיק מקביל לישר בינוני
באיזו נקודה המשיק לגרף f(x) = x2 - x מקביל לישר y = 3x - 7? כתבו את משוואת המשיק.
מקבילות פירושה f'(x) = 3:

2x - 1 = 3 ⇒ x = 2

נקודת ההשקה: f(2) = 4 - 2 = 2, כלומר (2, 2).

המשיק: y - 2 = 3(x - 2), כלומר y = 3x - 4. שיפועו 3 כשל הישר הנתון, אך חותך את ציר ה-y בנקודה אחרת — ולכן הם מקבילים ואינם מתלכדים.
תרגיל 4: משיק לפונקציה רציונלית בינוני
מצאו את משוואת המשיק לגרף f(x) = xx + 1 בנקודה שבה x = 1.
נקודת ההשקה: f(1) = 12, כלומר (1, 12).

השיפוע בעזרת כלל המנה:

f'(x) = 1 · (x + 1) - x · 1(x + 1)2 = 1(x + 1)2

ולכן f'(1) = 14.

המשיק: y - 12 = 14(x - 1), כלומר y = 14x + 14.
תרגיל 5: אתגר: משיקים מראשית הצירים מאתגר
מצאו את כל המשיקים לגרף f(x) = x2 + 1 העוברים דרך ראשית הצירים (0, 0).
הראשית איננה על הגרף (שהרי f(0) = 1), ולכן נסמן את נקודת ההשקה (a, a2 + 1).

השיפוע: f'(a) = 2a, והמשיק הכללי:

y - (a2 + 1) = 2a(x - a) ⇒ y = 2ax - a2 + 1

נציב x = 0 ו-y = 0:

0 = -a2 + 1 ⇒ a2 = 1 ⇒ a = ± 1

עבור a = 1 מתקבל y = 2x (נקודת השקה (1, 2)), ועבור a = (-1) מתקבל y = -2x (נקודת השקה (-1, 2)).

בדיקה עבור y = 2x: פתרון x2 + 1 = 2x נותן (x - 1)2 = 0 — פתרון כפול יחיד x = 1, בדיוק כמצופה ממשיק.
תרגיל 6: משיק בנקודה נתונה קל
מצאו את משוואת המשיק לגרף f(x) = x2 - 2x בנקודה שבה x = 3.
נקודת ההשקה: f(3) = 9 - 6 = 3, כלומר (3, 3). השיפוע: f'(x) = 2x - 2, ולכן f'(3) = 4. המשיק: y - 3 = 4(x - 3), כלומר y = 4x - 9. בדיקה: הצבת x = 3 נותנת y = 12 - 9 = 3.
תרגיל 7: שני משיקים מקבילים לישר בינוני
מצאו את כל המשיקים לגרף f(x) = x3 + 2x המקבילים לישר y = 5x - 1.
מקבילות פירושה f'(x) = 5. הנגזרת היא f'(x) = 3x2 + 2, ולכן 3x2 + 2 = 5, כלומר x2 = 1 ומכאן x = 1 או x = (-1).

עבור x = 1: f(1) = 1 + 2 = 3, והמשיק y - 3 = 5(x - 1), כלומר y = 5x - 2.

עבור x = (-1): f(-1) = -1 - 2 = -3, והמשיק y + 3 = 5(x + 1), כלומר y = 5x + 2.
תרגיל 8: משיק לפונקציה רציונלית בינוני
מצאו את משוואת המשיק לגרף f(x) = xx - 2 בנקודה שבה x = 3.
נקודת ההשקה: f(3) = 31 = 3, כלומר (3, 3).

לפי כלל המנה: f'(x) = 1 · (x - 2) - x · 1(x - 2)2 = -2(x - 2)2, ולכן f'(3) = -21 = -2.

המשיק: y - 3 = -2(x - 3), כלומר y = -2x + 9.
תרגיל 9: אתגר: משיקים מנקודה חיצונית מאתגר
מצאו את כל המשיקים לגרף f(x) = x2 - 4x העוברים דרך הנקודה (0, -9).
הנקודה אינה על הגרף, שהרי f(0) = 0 ולא (-9). נסמן נקודת השקה (a, a2 - 4a); השיפוע שם הוא f'(a) = 2a - 4, ולכן המשיק הכללי הוא

y - (a2 - 4a) = (2a - 4)(x - a) ⇒ y = (2a - 4)x - a2

מציבים x = 0 ו-y = -9 ומקבלים -9 = -a2, כלומר a2 = 9 ומכאן a = 3 או a = (-3).

עבור a = 3: השיפוע 2 והמשיק y = 2x - 9, בנקודת השקה (3, -3).

עבור a = (-3): השיפוע (-10) והמשיק y = -10x - 9, בנקודת השקה (-3, 21).
