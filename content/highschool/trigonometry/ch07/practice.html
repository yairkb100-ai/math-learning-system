תרגיל 1: חילוץ שתי הפונקציות האחרות קל
נתון sinα = 45, כאשר α זווית חדה. חשבו את cosα ואת tanα.
cos2α = 1 - 1625 = 925, ומכיוון שהזווית חדה cosα = 35.

tanα = 4/53/5 = 43 ≈ 1.33.
תרגיל 2: זוויות משלימות קל
השלימו את השוויונות:

א. sin 25° = cos ?
ב. cos 80° = sin ?
ג. tan 40° · tan 50° = ?
א. sin 25° = cos 65°, כי 90° - 25° = 65°.
ב. cos 80° = sin 10°, כי 90° - 80° = 10°.
ג. הזוויות משלימות, ולכן tan 50° = 1tan 40° והמכפלה היא 1.
תרגיל 3: זווית קהה בינוני
נתון cosα = -1213, כאשר α זווית קהה. חשבו את sinα ואת tanα.
sin2α = 1 - 144169 = 25169, ולכן sinα = ±513.

הזווית קהה — ברבע השני הסינוס חיובי, ולכן sinα = 513.

tanα = 5/13-12/13 = -512 ≈ -0.417.
תרגיל 4: הוכחת זהות בינוני
הוכיחו את הזהות sin2α - cos2α = 1 - 2cos2α.
עובדים על האגף השמאלי.

לפי הזהות הפיתגורית sin2α = 1 - cos2α, ולכן:

sin2α - cos2α = (1 - cos2α) - cos2α = 1 - 2cos2α

זהו בדיוק האגף הימני, והזהות מוכחת.
תרגיל 5: אתגר: זהות עם שברים מאתגר
הוכיחו את הזהות sinα1+cosα + 1+cosαsinα = 2sinα.
עובדים על האגף השמאלי ומאחדים למכנה משותף sinα(1+cosα):

sin2α + (1+cosα)2sinα(1+cosα)

פותחים את המונה: sin2α + 1 + 2cosα + cos2α.

לפי הזהות הפיתגורית sin2α + cos2α = 1, ולכן המונה שווה 1 + 1 + 2cosα = 2 + 2cosα = 2(1+cosα).

מצמצמים את הגורם (1+cosα):

2(1+cosα)sinα(1+cosα) = 2sinα

הגענו לאגף הימני, והזהות מוכחת.
תרגיל 6: שתי הפונקציות האחרות קל
נתון sinα = 725, כאשר α זווית חדה. חשבו את cosα ואת tanα.
cos2α = 1 - 49625 = 576625, ומכיוון שהזווית חדה cosα = 2425.

tanα = 7/2524/25 = 724 ≈ 0.292.
תרגיל 7: הוכחת זהות בינוני
הוכיחו את הזהות 1-sin2αcosα = cosα (עבור cosα ≠ 0).
עובדים על האגף השמאלי בלבד.

לפי הזהות הפיתגורית 1 - sin2α = cos2α, ולכן המונה הוא cos2α.

מצמצמים: cos2αcosα = cosα — זהו האגף הימני, והזהות מוכחת.
תרגיל 8: זווית קהה בינוני
נתון cosα = -817, כאשר α זווית קהה. חשבו את sinα ואת tanα.
sin2α = 1 - 64289 = 225289, ולכן sinα = ±1517.

הזווית קהה — ברבע השני הסינוס חיובי, ולכן sinα = 1517.

tanα = 15/17-8/17 = -158 = -1.875.
תרגיל 9: אתגר: מהפרש אל מכפלה מאתגר
נתון sinα - cosα = 12. חשבו את sinαcosα בלי למצוא את הזווית.
מעלים את הנתון בריבוע:

(sinα - cosα)2 = sin2α - 2sinαcosα + cos2α

לפי הזהות הפיתגורית שני הריבועים יחד שווים 1, ולכן האגף השמאלי הוא 1 - 2sinαcosα.

מצד שני (12)2 = 14, ולכן:

1 - 2sinαcosα = 14

2sinαcosα = 34, ומכאן sinαcosα = 38.
