נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: משוואת סינוס קל
פתרו את המשוואה sin x = √32 בתחום 0° ≤ x ≤ 360°.
פתרון בסיסי: x1 = 60°.

פתרון משלים: x2 = 180° - 60° = 120°.

הפתרונות: x = 60° ו-x = 120°.
תרגיל 2: משוואת קוסינוס קל
פתרו את המשוואה cos x = 0 בתחום 0° ≤ x ≤ 360°, והסבירו מה קורה ל-tan x בפתרונות האלה.
פתרון בסיסי: x1 = cos-1(0) = 90°. פתרון שני: x2 = 360° - 90° = 270°.

הפתרונות: x = 90° ו-x = 270°.

בזוויות האלה tan x = sin xcos x אינו מוגדר, כי המכנה מתאפס.
תרגיל 3: משוואת טנגנס עם ערך שלילי בינוני
פתרו את המשוואה tan x = -1 בתחום 0° ≤ x ≤ 360°.
המחשבון מחזיר tan-1(-1) = -45°, שאינו בתחום. מוסיפים 180° ומקבלים x1 = 135°.

הפתרון הבא: x2 = 135° + 180° = 315°.

הפתרונות: x = 135° ו-x = 315° — שניהם ברבעים שבהם הטנגנס שלילי (השני והרביעי).
תרגיל 4: פירוק לגורמים בינוני
פתרו את המשוואה 2sin2 x - sin x = 0 בתחום 0° ≤ x ≤ 360°.
מוציאים גורם משותף: sin x(2sin x - 1) = 0.

מ-sin x = 0: x = 0°, x = 180°, x = 360°.

מ-sin x = 12: x = 30° ו-x = 150°.

סך הכול חמישה פתרונות: 0°, 30°, 150°, 180°, 360°.

שימו לב: חלוקה ב-sin x הייתה מוחקת שלושה מהם.
תרגיל 5: אתגר: זהות ומשוואה ריבועית מאתגר
פתרו את המשוואה 2cos2 x + 3sin x - 3 = 0 בתחום 0° ≤ x ≤ 360°.
שלב 1 — מציבים cos2 x = 1 - sin2 x כדי להשאיר פונקציה אחת:

2(1 - sin2 x) + 3sin x - 3 = 0

שלב 2 — מסדרים: -2sin2 x + 3sin x - 1 = 0, ואחרי הכפלה ב-(-1): 2sin2 x - 3sin x + 1 = 0.

שלב 3 — מסמנים t = sin x: 2t2 - 3t + 1 = 0, ולכן t = 1 או t = 12.

שלב 4 — מ-sin x = 1 מקבלים x = 90° בלבד. מ-sin x = 12 מקבלים x = 30° ו-x = 150°.

שלב 5 — הפתרונות: x = 30°, x = 90° ו-x = 150°.

בדיקה עבור x = 90°: 2· 0 + 3· 1 - 3 = 0.
תרגיל 6: משוואת סינוס בסיסית קל
פתרו את המשוואה sin x = 12 בתחום 0° ≤ x ≤ 360°.
פתרון בסיסי: x1 = sin-1(12) = 30°.

פתרון משלים: x2 = 180° - 30° = 150°.

הפתרונות: x = 30° ו-x = 150°.
תרגיל 7: משוואת טנגנס בינוני
פתרו את המשוואה tan x = √3 בתחום 0° ≤ x ≤ 360°.
פתרון בסיסי: x1 = tan-1(√3) = 60°.

מחזור הטנגנס הוא 180°, ולכן x2 = 60° + 180° = 240°.

הפתרונות: x = 60° ו-x = 240° — הרבע הראשון והרבע השלישי, שבהם הטנגנס חיובי.
תרגיל 8: משוואה ריבועית בסינוס בינוני
פתרו את המשוואה 2sin2 x - sin x - 1 = 0 בתחום 0° ≤ x ≤ 360°.
שלב 1 — מסמנים t = sin x ומקבלים 2t2 - t - 1 = 0.

שלב 2 — מפרקים: (2t + 1)(t - 1) = 0, ולכן t = -12 או t = 1.

שלב 3 — מ-sin x = 1 מקבלים x = 90° בלבד.

שלב 4 — מ-sin x = -12 מקבלים x = 210° ו-x = 330°.

הפתרונות: x = 90°, x = 210° ו-x = 330°.
תרגיל 9: אתגר: זהות ופתרון שיש לפסול מאתגר
פתרו את המשוואה 2cos2 x - 3sin x = 0 בתחום 0° ≤ x ≤ 360°.
שלב 1 — מציבים cos2 x = 1 - sin2 x כדי להשאיר פונקציה אחת:

2(1 - sin2 x) - 3sin x = 0

שלב 2 — מסדרים: -2sin2 x - 3sin x + 2 = 0, ואחרי הכפלה ב-(-1): 2sin2 x + 3sin x - 2 = 0.

שלב 3 — מסמנים t = sin x ומפרקים: (2t - 1)(t + 2) = 0, ולכן t = 12 או t = -2.

שלב 4 — הפתרון t = -2 נפסל: הסינוס חסום בתחום -1 ≤ sin x ≤ 1, ואין זווית שהסינוס שלה הוא -2.

שלב 5 — נשאר sin x = 12, ומכאן x = 30° ו-x = 150°.

בדיקה עבור x = 30°: 2·(√32)2 - 3·12 = 2·34 - 32 = 0.
