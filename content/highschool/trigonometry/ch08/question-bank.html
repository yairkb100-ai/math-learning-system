חלק א' — משוואות סינוס 🌊 (שאלות 1–4)

  1. פתרו בתחום 0° ≤ x ≤ 360°: sin x = √3/2.
  2. פתרו בתחום 0° ≤ x ≤ 360°: sin x = 0.
  3. פתרו בתחום 0° ≤ x ≤ 360°: sin x = −√2/2.
  4. פתרו בתחום 0° ≤ x ≤ 360°: sin x = 1.

חלק ב' — משוואות קוסינוס 🔵 (שאלות 5–8)

  1. פתרו בתחום 0° ≤ x ≤ 360°: cos x = √2/2.
  2. פתרו בתחום 0° ≤ x ≤ 360°: cos x = −1/2.
  3. פתרו בתחום 0° ≤ x ≤ 360°: cos x = 0.
  4. פתרו בתחום 0° ≤ x ≤ 360°: cos x = 1.

חלק ג' — משוואות טנגנס ↗️ (שאלות 9–12)

  1. פתרו בתחום 0° ≤ x ≤ 360°: tan x = √3/3.
  2. פתרו בתחום 0° ≤ x ≤ 360°: tan x = −1.
  3. פתרו בתחום 0° ≤ x ≤ 360°: tan x = 0.
  4. מדוע ההפרש בין שני פתרונות עוקבים של משוואת טנגנס הוא 180° ולא 360°?

חלק ד' — יש פתרון או אין? 🚫 (שאלות 13–16)

  1. האם למשוואה sin x = 1.2 יש פתרון? נמקו.
  2. האם למשוואה cos x = −1 יש פתרון? אם כן — מהו?
  3. האם למשוואה tan x = 1000 יש פתרון? נמקו.
  4. האם למשוואה sin x = −1.5 יש פתרון? נמקו.

חלק ה' — פירוק לגורמים ✂️ (שאלות 17–20)

  1. פתרו בתחום 0° ≤ x ≤ 360°: sin x · cos x = 0.
  2. פתרו בתחום 0° ≤ x ≤ 360°: 2cos²x − cos x = 0.
  3. פתרו בתחום 0° ≤ x ≤ 360°: 2sin x · cos x + cos x = 0.
  4. בפתרון המשוואה sin x · cos x = sin x — איזו פעולה אסור לבצע, ולמה?

חלק ו' — זהות, ריבועית ואתגרים 🏆 (שאלות 21–24)

  1. פתרו בתחום 0° ≤ x ≤ 360°: 2sin²x + 3sin x + 1 = 0.
  2. פתרו בתחום 0° ≤ x ≤ 360°: 2cos²x + cos x − 1 = 0.
  3. פתרו בתחום 0° ≤ x ≤ 360°: 2sin²x + cos x = 1.
  4. פתרו בתחום 0° ≤ x ≤ 360°: cos 2x = 1/2.

13. אין פתרון — הסינוס חסום בתחום −1 ≤ sin x ≤ 1, ואין על מעגל היחידה נקודה בגובה 1.2.

15. יש פתרון — לטנגנס אין חסם עליון או תחתון. הפתרונות הם x ≈ 89.94° ו-x ≈ 269.94°.
16. אין פתרון — הערך −1.5 נמצא מחוץ לתחום −1 ≤ sin x ≤ 1.
17. מ-sin x = 0: 0°, 180°, 360°; מ-cos x = 0: 90°, 270°. סך הכול: 0°, 90°, 180°, 270°, 360°.
18. מוציאים גורם משותף: cos x · (2cos x − 1) = 0. מ-cos x = 0: 90° ו-270°; מ-cos x = 1/2: 60° ו-300°. סך הכול ארבעה פתרונות.
19. מוציאים גורם משותף: cos x · (2sin x + 1) = 0. מ-cos x = 0: 90° ו-270°; מ-sin x = −1/2: 210° ו-330°. סך הכול: 90°, 210°, 270°, 330°.
20. אסור לחלק את שני האגפים ב-sin x — זה מוחק את הפתרונות שבהם sin x = 0, שהם פתרונות חוקיים של המשוואה. מעבירים לאגף אחד ומפרקים לגורמים.
21. (2t + 1)(t + 1) = 0 עם t = sin x, ולכן sin x = −1/2 או sin x = −1. הפתרונות: 210°, 270°, 330°.
22. (2t − 1)(t + 1) = 0 עם t = cos x, ולכן cos x = 1/2 או cos x = −1. הפתרונות: 60°, 180°, 300°.
23. מציבים sin²x = 1 − cos²x ומקבלים 2 − 2cos²x + cos x − 1 = 0, כלומר 2cos²x − cos x − 1 = 0 ומכאן cos x = −1/2 או cos x = 1. הפתרונות: 0°, 120°, 240°, 360°.
24. הזווית 2x נעה בתחום 0° ≤ 2x ≤ 720°, ולכן 2x = 60°, 300°, 420° ו-660°. מחלקים בשתיים: x = 30°, 150°, 210°, 330°.
