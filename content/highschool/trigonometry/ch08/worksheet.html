טריגונומטריה · פרק 8 — כל הפתרונות בתחום, זהויות ופירוק לגורמים
שם: כיתה: תאריך:
בכל התרגילים התחום הוא 0° ≤ x ≤ 360°, אלא אם נכתב אחרת. המחשבון מחזיר פתרון אחד — את השאר משלימים לפי הסימטריה של מעגל היחידה. סינוס: x₂ = 180° − x₁. קוסינוס: x₂ = 360° − x₁. טנגנס: x₂ = x₁ + 180°. פתרון שיצא שלילי מוסיפים לו 360°. לסינוס ולקוסינוס יש חסם −1 ≤ y ≤ 1, ומחוצה לו אין פתרון כלל; לטנגנס אין חסם. כששתי פונקציות מופיעות יחד — מאחדים אותן בעזרת sin²x + cos²x = 1. וכשיש גורם משותף — מפרקים ולעולם לא מחלקים בביטוי שמכיל את הנעלם.

שאלה 1 — משוואות סינוס בסיסיות קל

פתרו בתחום 0° ≤ x ≤ 360°:

  1. sin x = 1/2
  2. sin x = √2/2

שאלה 2 — משוואות קוסינוס בסיסיות קל

פתרו בתחום 0° ≤ x ≤ 360°:

  1. cos x = √3/2
  2. cos x = 1/2

שאלה 3 — משוואות טנגנס בסיסיות קל

פתרו בתחום 0° ≤ x ≤ 360°:

  1. tan x = 1
  2. tan x = √3

שאלה 4 — ערכי קצה קל

פתרו בתחום 0° ≤ x ≤ 360°, ושימו לב למספר הפתרונות:

  1. sin x = 1
  2. cos x = −1
  3. sin x = 0

שאלה 5 — יש פתרון או אין? קל

לכל משוואה כתבו אם יש לה פתרון, ונמקו במילה אחת או שתיים:

  1. sin x = 1.3
  2. cos x = −0.9
  3. tan x = 50
  4. cos x = 1.01

שאלה 6 — סינוס שלילי בינוני

פתרו בתחום 0° ≤ x ≤ 360° את המשוואה sin x = −1/2.

שימו לב: המחשבון יחזיר זווית שלילית — הסבירו מה עושים איתה.

שאלה 7 — קוסינוס שלילי בינוני

פתרו בתחום 0° ≤ x ≤ 360° את המשוואה cos x = −√2/2, וכתבו באילו רבעים נמצאים הפתרונות.

שאלה 8 — טנגנס שלילי בינוני

פתרו בתחום 0° ≤ x ≤ 360° את המשוואה tan x = −√3.

שאלה 9 — פירוק לגורמים בינוני

פתרו בתחום 0° ≤ x ≤ 360° את המשוואה 2sin x · cos x = cos x.

העבירו הכול לאגף אחד, הוציאו גורם משותף, ואפסו כל גורם בנפרד.

שאלה 10 — משוואה ריבועית בסינוס בינוני

פתרו בתחום 0° ≤ x ≤ 360° את המשוואה 2sin²x + sin x − 1 = 0.

רמז: סמנו t = sin x.

שאלה 11 — אתגר: זהות ואז ריבועית מאתגר

פתרו בתחום 0° ≤ x ≤ 360° את המשוואה 2cos²x + sin x − 1 = 0.

התחילו מהצבת cos²x = 1 − sin²x.

שאלה 12 — אתגר: הזווית אינה x עצמה מאתגר

פתרו בתחום 0° ≤ x ≤ 360° את המשוואה sin 2x = √3/2.

שימו לב לתחום שבו נעה הזווית 2x.

שאלה 13 — מצאו את הטעות מאתגר

תלמיד פתר את 2sin x · cos x = sin x כך: חילק את שני האגפים ב-sin x, קיבל 2cos x = 1, ורשם שני פתרונות בלבד.

מצאו את כל הפתרונות בתחום 0° ≤ x ≤ 360°, כתבו כמה פתרונות הוא איבד, והסבירו מדוע החלוקה אסורה.

שאלה 1. א. x₁ = 30° ו-x₂ = 180° − 30° = 150°.   ב. x₁ = 45° ו-x₂ = 180° − 45° = 135°.
שאלה 2. א. x₁ = 30° ו-x₂ = 360° − 30° = 330°.   ב. x₁ = 60° ו-x₂ = 360° − 60° = 300°.
שאלה 3. א. x₁ = 45° ו-x₂ = 45° + 180° = 225°.   ב. x₁ = 60° ו-x₂ = 60° + 180° = 240°.
שאלה 4. א. x = 90° בלבד — זו הנקודה הגבוהה ביותר במעגל, ויש לה זווית אחת.   ב. x = 180° בלבד.   ג. x = 0°, x = 180° ו-x = 360° — שלושה פתרונות.
שאלה 5. א. אין פתרון — הסינוס חסום ב-1.   ב. יש פתרון — −0.9 בתוך התחום המותר.   ג. יש פתרון — לטנגנס אין חסם.   ד. אין פתרון — הקוסינוס חסום ב-1.
שאלה 6. המחשבון מחזיר −30°, שאינו בתחום; מוסיפים לו סיבוב שלם: −30° + 360° = 330°. הפתרון השני: 180° − (−30°) = 210°. הפתרונות: x = 210° ו-x = 330° — שניהם ברבעים שבהם הסינוס שלילי (השלישי והרביעי).
שאלה 7. x₁ = 135° ו-x₂ = 360° − 135° = 225°. הפתרון הראשון ברבע השני והשני ברבע השלישי — בדיוק הרבעים שבהם הקוסינוס שלילי.
שאלה 8. המחשבון מחזיר −60°; מוסיפים 180° ומקבלים x₁ = 120°. הפתרון הבא: x₂ = 120° + 180° = 300°. הפתרונות: x = 120° ו-x = 300°.
שאלה 9. 2sin x · cos x − cos x = 0, כלומר cos x · (2sin x − 1) = 0. מ-cos x = 0 מקבלים x = 90° ו-x = 270°. מ-sin x = 1/2 מקבלים x = 30° ו-x = 150°. סך הכול ארבעה פתרונות: 30°, 90°, 150°, 270°.
שאלה 10. מציבים t = sin x ומקבלים 2t² + t − 1 = 0, שמתפרק ל-(2t − 1)(t + 1) = 0 ולכן t = 1/2 או t = −1. מ-sin x = 1/2 מקבלים x = 30° ו-x = 150°; מ-sin x = −1 מקבלים x = 270° בלבד. הפתרונות: 30°, 150°, 270°.
שאלה 11. מציבים ומסדרים: 2(1 − sin²x) + sin x − 1 = 0, כלומר −2sin²x + sin x + 1 = 0, ואחרי הכפלה במינוס אחד 2sin²x − sin x − 1 = 0. מתפרק ל-(2t + 1)(t − 1) = 0, ולכן sin x = −1/2 או sin x = 1. הפתרונות: x = 90°, x = 210° ו-x = 330°.
שאלה 12. כאשר x נע בתחום 0° ≤ x ≤ 360°, הזווית 2x נעה בתחום הכפול 0° ≤ 2x ≤ 720°. הפתרונות עבור 2x הם 60°, 120°, ואחרי סיבוב שלם גם 420° ו-480°. מחלקים בשתיים: x = 30°, x = 60°, x = 210°, x = 240°.
שאלה 13. הפתרון הנכון: sin x · (2cos x − 1) = 0. מ-sin x = 0 מקבלים x = 0°, x = 180° ו-x = 360°; מ-cos x = 1/2 מקבלים x = 60° ו-x = 300° — סך הכול חמישה פתרונות. התלמיד קיבל רק שניים, כלומר איבד שלושה. החלוקה אסורה כי חלוקה בביטוי חוקית רק כשידוע שהוא שונה מאפס, וכאן דווקא המקרים שבהם sin x = 0 הם פתרונות של המשוואה המקורית.
