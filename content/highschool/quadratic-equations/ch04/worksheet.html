דף עבודה — פרק 4: השלמה לריבוע

משוואות ריבועיות · פרק 4 — האיבר המשלים, צורת הקדקוד וגזירת נוסחת השורשים
שם: כיתה: תאריך:
הכלל המרכזי: כדי להשלים את x² + bx לריבוע מושלם מוסיפים את הריבוע של חצי מהמקדם של x, כלומר (b/2)², ומתקבל x² + bx + (b/2)² = (x + b/2)². במשוואה מוסיפים את המספר הזה לשני האגפים — לא לאגף אחד בלבד. אם המקדם המוביל אינו 1, מחלקים תחילה את כל המשוואה בו; בפונקציה מוציאים אותו כגורם משותף מהאיברים שמכילים את x. בהוצאת שורש אל תשכחו את ± — אחרת נעלם פתרון שלם. צורת הקדקוד היא y = a(x − h)² + k, והקדקוד הוא (h, k) — שימו לב שהסימן בסוגריים הפוך לשיעור הקדקוד.

שאלה 1 — האיבר המשלים — מקדמים זוגיים קל

איזה מספר יש להוסיף לכל ביטוי כדי להפוך אותו לריבוע מושלם, וכיצד ייראה הריבוע?

  1. x² + 6x ⟵
  2. x² − 10x ⟵
  3. x² + 14x ⟵

שאלה 2 — האיבר המשלים — גם כשהמקדם אינו זוגי קל

השלימו לריבוע מושלם וכתבו את הריבוע:

  1. x² + 20x ⟵
  2. x² + 3x ⟵
  3. x² − x ⟵

שאלה 3 — מריבוע מוכן אל הפתרון קל

פתרו בעזרת הוצאת שורש לשני הכיוונים. אל תשכחו את שני הסימנים.

  1. (x − 4)² = 25
  2. (x + 2)² = 9
  3. (x − 1)² = 0

שאלה 4 — השלמה לריבוע — משוואה ראשונה קל

פתרו בהשלמה לריבוע ובדקו את שני הפתרונות בהצבה:

x² + 6x − 7 = 0

שאלה 5 — השלמה לריבוע — משוואה שנייה קל

פתרו בהשלמה לריבוע:

x² − 8x + 12 = 0

שאלה 6 — שתי משוואות בהשלמה לריבוע בינוני

פתרו בהשלמה לריבוע:

  1. x² + 10x + 9 = 0
  2. x² − 2x − 15 = 0

שאלה 7 — מקדם מוביל שאינו 1 בינוני

חלקו תחילה במקדם המוביל, ורק אז השלימו לריבוע:

  1. 2x² + 8x − 10 = 0
  2. 3x² − 12x + 9 = 0

שאלה 8 — צורת הקדקוד כשהמקדם המוביל הוא 1 בינוני

כתבו כל פונקציה בצורת הקדקוד, וכתבו מהו הקדקוד:

  1. y = x² + 6x + 11
  2. y = x² − 10x + 18

שאלה 9 — צורת הקדקוד — מוציאים גורם משותף בינוני

כתבו בצורת הקדקוד, וקבעו אם הקדקוד הוא נקודת מינימום או נקודת מקסימום:

  1. y = 3x² − 12x + 5
  2. y = −2x² + 8x − 1

שאלה 10 — המחיר שממקסם את הרווח בינוני

הרווח החודשי של דוכן, באלפי שקלים, מתואר על ידי y = −x² + 12x − 20, כאשר x הוא מחיר המוצר בשקלים. כתבו את הפונקציה בצורת הקדקוד, ומצאו באיזה מחיר הרווח מרבי ומהו הרווח הזה.

שאלה 11 — תשובה מדויקת עם שורש מאתגר

פתרו בהשלמה לריבוע והשאירו תשובה מדויקת (עם סימן שורש):

x² + 6x + 4 = 0

שאלה 12 — מהקדקוד אל המשוואה מאתגר

פרבולה שקדקודה (2, −3) עוברת בנקודה (0, 5). מצאו את המקדם המוביל a, וכתבו את הפונקציה גם בצורת הקדקוד וגם בצורה הכללית.

שאלה 13 — אתגר: כמה פתרונות, ולמה מאתגר

נתונה המשוואה x² − 6x + k = 0 עם פרמטר k. השלימו לריבוע, ואז קבעו:

  1. עבור אילו ערכי k יש שני פתרונות שונים?
  2. עבור איזה ערך יש פתרון יחיד, ומהו?
  3. עבור אילו ערכים אין פתרון ממשי?

שאלה 1. א. מוסיפים 9: x² + 6x + 9 = (x + 3)²   ב. מוסיפים 25: x² − 10x + 25 = (x − 5)²   ג. מוסיפים 49: x² + 14x + 49 = (x + 7)²
שאלה 2. א. מוסיפים 100: x² + 20x + 100 = (x + 10)²   ב. מוסיפים 9/4: x² + 3x + 9/4 = (x + 3/2)²   ג. מוסיפים 1/4: x² − x + 1/4 = (x − 1/2)²
שאלה 3. א. x − 4 = ±5, ולכן x = 9 או x = −1   ב. x + 2 = ±3, ולכן x = 1 או x = −5   ג. פתרון יחיד x = 1
שאלה 4. מעבירים: x² + 6x = 7. חצי מ-6 הוא 3 וריבועו 9, ומוסיפים לשני האגפים: (x + 3)² = 16. מכאן x + 3 = ±4, כלומר x = 1 או x = −7. בדיקה: 1 + 6 − 7 = 0 ✓ וגם 49 − 42 − 7 = 0 ✓
שאלה 5. מעבירים: x² − 8x = −12. חצי מ-−8 הוא −4 וריבועו 16: (x − 4)² = 4. מכאן x − 4 = ±2, כלומר x = 6 או x = 2. בדיקה: 36 − 48 + 12 = 0 ✓ וגם 4 − 16 + 12 = 0 ✓
שאלה 6. א. x² + 10x = −9 → (x + 5)² = 16 → x + 5 = ±4, ולכן x = −1 או x = −9   ב. x² − 2x = 15 → (x − 1)² = 16 → x − 1 = ±4, ולכן x = 5 או x = −3
שאלה 7. א. מחלקים ב-2 ומקבלים x² + 4x − 5 = 0 → (x + 2)² = 9 → x = 1 או x = −5   ב. מחלקים ב-3 ומקבלים x² − 4x + 3 = 0 → (x − 2)² = 1 → x = 3 או x = 1
שאלה 8. א. y = (x² + 6x + 9) − 9 + 11 = (x + 3)² + 2, הקדקוד (−3, 2)   ב. y = (x² − 10x + 25) − 25 + 18 = (x − 5)² − 7, הקדקוד (5, −7)
שאלה 9. א. y = 3(x² − 4x) + 5 = 3(x − 2)² − 12 + 5 = 3(x − 2)² − 7, הקדקוד (2, −7) והוא מינימום כי a = 3 > 0   ב. y = −2(x² − 4x) − 1 = −2(x − 2)² + 8 − 1 = −2(x − 2)² + 7, הקדקוד (2, 7) והוא מקסימום כי a = −2 < 0
שאלה 10. מוציאים −1 כגורם ומשלימים: y = −(x² − 12x) − 20 = −(x − 6)² + 36 − 20 = −(x − 6)² + 16. הקדקוד הוא (6, 16), ולכן במחיר 6 שקלים הרווח מרבי ושווה 16 אלף שקלים. בדיקה: −36 + 72 − 20 = 16 ✓
שאלה 11. מעבירים: x² + 6x = −4. מוסיפים 9 לשני האגפים: (x + 3)² = 5. מוציאים שורש: x + 3 = ±√5, ולכן x = −3 + √5 או x = −3 − √5
שאלה 12. מציבים בצורת הקדקוד y = a(x − 2)² − 3. עבור x = 0 מקבלים 4a − 3 = 5, ולכן a = 2. צורת הקדקוד: y = 2(x − 2)² − 3; ובפתיחת הסוגריים y = 2x² − 8x + 5. בדיקה: עבור x = 0 מתקבל y = 5 ✓
שאלה 13. משלימים: x² − 6x = −k → (x − 3)² = 9 − k. א. שני פתרונות שונים כאשר 9 − k > 0, כלומר k < 9   ב. פתרון יחיד x = 3 כאשר k = 9   ג. אין פתרון ממשי כאשר 9 − k < 0, כלומר k > 9
