  4. מהו הערך המזערי של y = x² − 14x + 50, ובאיזה x הוא מתקבל?

1. מוסיפים 16: x² + 8x + 16 = (x + 4)²
2. מוסיפים 36: x² − 12x + 36 = (x − 6)²
3. מוסיפים 25/4: x² + 5x + 25/4 = (x + 5/2)²
4. מוסיפים 81: x² − 18x + 81 = (x − 9)²
5. x − 2 = ±7, ולכן x = 9 או x = −5
6. x + 5 = ±4, ולכן x = −1 או x = −9
7. פתרון יחיד: x = 3
8. x + 1 = ±√12 = ±2√3, ולכן x = −1 + 2√3 או x = −1 − 2√3
9. x² + 4x = 12 → (x + 2)² = 16 → x = 2 או x = −6
10. x² − 6x = −5 → (x − 3)² = 4 → x = 5 או x = 1
11. x² + 12x = −20 → (x + 6)² = 16 → x = −2 או x = −10
12. x² − 10x = −16 → (x − 5)² = 9 → x = 8 או x = 2
13. מחלקים ב-2: x² − 2x − 3 = 0 → (x − 1)² = 4 → x = 3 או x = −1
14. מחלקים ב-3: x² + 6x + 5 = 0 → (x + 3)² = 4 → x = −1 או x = −5
15. מחלקים ב-5: x² − 4x + 3 = 0 → (x − 2)² = 1 → x = 3 או x = 1
16. מחלקים ב-4: x² + 2x − 8 = 0 → (x + 1)² = 9 → x = 2 או x = −4
17. y = (x + 1)² + 4, הקדקוד (−1, 4)
18. y = (x − 4)² − 3, הקדקוד (4, −3)
19. y = 2(x + 3)² + 2, הקדקוד (−3, 2)
20. y = −(x − 2)² + 5, הקדקוד (2, 5) והוא נקודת מקסימום
21. x² + 3x = −1 → (x + 3/2)² = 5/4 → x + 3/2 = ±√5/2, ולכן x = (−3 + √5)/2 או x = (−3 − √5)/2
22. y = a(x + 1)² + 4; מציבים x = 1 ומקבלים 4a + 4 = 12, ולכן a = 2 והצורה היא y = 2(x + 1)² + 4
23. (x + 4)² = 16 − k. שני פתרונות שונים כאשר 16 − k > 0, כלומר k < 16
24. y = (x − 7)² + 1, ולכן הערך המזערי הוא 1 והוא מתקבל ב-x = 7
