תרגיל 1: השלמת האיבר החסר קל
איזה מספר יש להוסיף כדי להפוך כל ביטוי לריבוע מושלם, וכיצד ייראה הריבוע?

א. x2 + 12x
ב. x2 - 14x
א. חצי מ-12 הוא 6, וריבועו 36. מוסיפים 36: x2 + 12x + 36 = (x + 6)2.
ב. חצי מ-(-14) הוא (-7), וריבועו 49. מוסיפים 49: x2 - 14x + 49 = (x - 7)2.
תרגיל 2: פתרון בהשלמה לריבוע קל
פתרו בהשלמה לריבוע: x2 + 10x + 21 = 0.
מעבירים: x2 + 10x = -21.
חצי מ-10 הוא 5, וריבועו 25. מוסיפים לשני האגפים: (x + 5)2 = -21 + 25 = 4.
מוציאים שורש: x + 5 = ± 2, ולכן x = -3 או x = -7.
בדיקה: 9 - 30 + 21 = 0 ✓, וגם 49 - 70 + 21 = 0 ✓.
תרגיל 3: מקדם מוביל 3 בינוני
פתרו בהשלמה לריבוע: 3x2 - 6x - 24 = 0.
מחלקים ב-3: x2 - 2x - 8 = 0.
מעבירים: x2 - 2x = 8. חצי מ-(-2) הוא (-1), וריבועו 1: (x - 1)2 = 8 + 1 = 9.
מוציאים שורש: x - 1 = ± 3, ולכן x = 4 או x = -2.
בדיקה במשוואה המקורית: 3 · 16 - 24 - 24 = 0 ✓.
תרגיל 4: צורת הקדקוד וערך מזערי בינוני
כתבו את y = x2 + 4x + 7 בצורת הקדקוד, ומצאו את הקדקוד ואת הערך המזערי של הפונקציה.
חצי מ-4 הוא 2, וריבועו 4. מוסיפים ומחסרים 4:
y = (x2 + 4x + 4) - 4 + 7 = (x + 2)2 + 3.
כותבים בצורה (x - h)2: מכיוון ש-(x + 2)2 = (x - (-2))2, מתקבל h = -2 ו-k = 3.
הקדקוד הוא (-2, 3), והערך המזערי הוא 3 — כי (x + 2)2 לעולם אינו שלילי, ולכן y לעולם אינו קטן מ-3.
תרגיל 5: אתגר: תשובה עם שורש מאתגר
פתרו בהשלמה לריבוע: 2x2 - 4x - 3 = 0. השאירו את התשובה בצורה מדויקת (עם סימן שורש).
מחלקים ב-2: x2 - 2x - 32 = 0, כלומר x2 - 2x = 32.
חצי מ-(-2) הוא (-1), וריבועו 1. מוסיפים לשני האגפים:
(x - 1)2 = 32 + 1 = 52.
מוציאים שורש: x - 1 = ± √52 = ± √102, ולכן x = 1 ± √102.
בדיקה מול נוסחת השורשים: Δ = 16 + 24 = 40, ואז x = 4 ± √404 = 4 ± 2√104 = 1 ± √102 ✓.
תרגיל 6: האיבר המשלים קל
איזה מספר יש להוסיף ל-x2 + 16x כדי לקבל ריבוע מושלם, ומהו הריבוע?
חצי מהמקדם של x הוא 162 = 8, וריבועו 64. מוסיפים 64 ומקבלים x2 + 16x + 64 = (x + 8)2.
תרגיל 7: פתרון בהשלמה לריבוע בינוני
פתרו בהשלמה לריבוע: x2 - 4x - 21 = 0.
מעבירים את האיבר החופשי: x2 - 4x = 21. חצי מ-(-4) הוא (-2) וריבועו 4, ומוסיפים אותו לשני האגפים: (x - 2)2 = 25. מוציאים שורש: x - 2 = ± 5, ולכן x = 7 או x = -3. בדיקה: 49 - 28 - 21 = 0 וגם 9 + 12 - 21 = 0.
תרגיל 8: צורת הקדקוד עם מקדם מוביל בינוני
כתבו את y = 3x2 - 6x + 8 בצורת הקדקוד, ומצאו את הקדקוד ואת הערך המזערי.
מוציאים 3 כגורם מהאיברים שמכילים את x: y = 3(x2 - 2x) + 8. משלימים בתוך הסוגריים: x2 - 2x = (x-1)2 - 1, ולכן y = 3(x-1)2 - 3 + 8 = 3(x-1)2 + 5. הקדקוד הוא (1, 5), והערך המזערי הוא 5 כי a = 3 > 0. בדיקה: עבור x = 0 מתקבל 3 + 5 = 8.
תרגיל 9: אתגר: תשובה מדויקת עם מקדם מוביל מאתגר
פתרו בהשלמה לריבוע והשאירו תשובה מדויקת: 2x2 + 6x - 1 = 0.
מחלקים ב-2: x2 + 3x - 12 = 0, כלומר x2 + 3x = 12. חצי מ-3 הוא 32 וריבועו 94, ומוסיפים לשני האגפים: (x + 32)2 = 12 + 94 = 114. מוציאים שורש: x + 32 = ± √112, ולכן x = -3 ± √112. בדיקה מול נוסחת השורשים: Δ = 36 + 8 = 44, ואז x = -6 ± √444 = -6 ± 2√114 = -3 ± √112.
