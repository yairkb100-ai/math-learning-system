דף עבודה — פרק 6: אי-שוויונות ריבועיים

משוואות ריבועיות · פרק 6 — תחום הפתרון לפי הפרבולה ולפי טבלת סימנים
שם: כיתה: תאריך:
שלושת הצעדים: מסדרים הכול מול 0, מוצאים את שורשי המשוואה המתאימה, ובוחרים את התחום. כאשר a > 0 הביטוי חיובי מחוץ לשורשים ושלילי ביניהם; כאשר a < 0 התמונה מתהפכת — ולכן הדרך הבטוחה היא להכפיל ב-−1 ולהפוך את סימן האי-שוויון. סימן חלש (≤ או ≥) כולל את השורשים עצמם, סימן חזק אינו כולל אותם. כשאין שורשים (Δ < 0) הביטוי שומר על סימן קבוע בכל מקום. שני תחומים זרים מחוברים תמיד במילה "או" ולעולם לא בשרשרת אחת.

שאלה 1 — הפרש ריבועים קל

פתרו את האי-שוויונות. רמז: מפרקים להפרש ריבועים.

  1. x² − 16 > 0
  2. x² − 25 < 0

שאלה 2 — השורשים כבר ידועים — בחרו את התחום קל

נתון שהשורשים של x² − 3x − 10 הם −2 ו-5, והמקדם המוביל חיובי. כתבו את הפתרון של:

  1. x² − 3x − 10 > 0 ⟵
  2. x² − 3x − 10 < 0 ⟵

שאלה 3 — בין השורשים קל

פתרו: x² − 6x + 8 < 0

שאלה 4 — מחוץ לשורשים קל

פתרו: x² − x − 6 > 0

שאלה 5 — סימן חלש — כוללים את השורשים קל

פתרו: x² − 8x + 15 ≤ 0

שאלה 6 — גורם משותף בינוני

פתרו בעזרת הוצאת גורם משותף:

  1. x² − 5x > 0
  2. x² + 4x ≤ 0

שאלה 7 — מקדם מוביל שלילי בינוני

הכפילו ב-−1, הפכו את סימן האי-שוויון ופתרו:

  1. −x² + 6x − 8 > 0
  2. −x² − 2x + 15 ≥ 0

שאלה 8 — מסדרים לפני שפותרים בינוני

העבירו הכול לאגף אחד ופתרו:

  1. x² > 4x + 5
  2. x² + 12 ≤ 7x

שאלה 9 — טבלת סימנים בינוני

בנו טבלת סימנים לשני הגורמים של (x + 1)(x − 4) בשלושת התחומים, ובעזרתה פתרו את (x + 1)(x − 4) < 0. בדקו שורה אחת בהצבת מספר נציג.

שאלה 10 — כשאין שורשים כלל בינוני

חשבו דיסקרימיננט וקבעו את הפתרון:

  1. x² + 2x + 6 > 0
  2. x² + 2x + 6 < 0
  3. −x² + x − 3 < 0

שאלה 11 — כשהדיסקרימיננט מתאפס מאתגר

כתבו כל ביטוי כריבוע וקבעו את הפתרון המדויק:

  1. x² − 10x + 25 > 0
  2. x² − 10x + 25 ≤ 0
  3. x² + 6x + 9 ≥ 0

שאלה 12 — מתי הרווח חיובי מאתגר

הרווח של חברה, באלפי שקלים, מתואר על ידי P = −x² + 10x − 16, כאשר x הוא מספר המוצרים באלפים. עבור אילו ערכי x הרווח חיובי? כתבו את התשובה כתחום.

שאלה 13 — אתגר: פרמטר וסימן קבוע מאתגר

עבור אילו ערכי k מתקיים x² + kx + 4 > 0 עבור כל x ממשי? הסבירו במה תלוי הדבר.

שאלה 1. א. (x − 4)(x + 4) = 0 נותן שורשים ±4; המקדם המוביל חיובי ומחפשים חיובי — מחוץ לשורשים: x < −4 או x > 4   ב. שורשים ±5, ומחפשים שלילי — בין השורשים: −5 < x < 5
שאלה 2. א. מחוץ לשורשים: x < −2 או x > 5   ב. בין השורשים: −2 < x < 5
שאלה 3. פירוק: (x − 2)(x − 4) = 0, השורשים 2 ו-4. המקדם המוביל חיובי ומחפשים היכן הביטוי שלילי — בין השורשים, בלי לכלול אותם: 2 < x < 4
שאלה 4. פירוק: (x − 3)(x + 2) = 0, השורשים −2 ו-3. מחפשים היכן הביטוי חיובי — מחוץ לשורשים: x < −2 או x > 3. בדיקה: עבור x = 0 מתקבל −6, שלילי — ואכן 0 אינו בתחום ✓
שאלה 5. פירוק: (x − 3)(x − 5) = 0, השורשים 3 ו-5. הסימן חלש, ולכן התחום הוא בין השורשים כולל אותם: 3 ≤ x ≤ 5
שאלה 6. א. x(x − 5) > 0, השורשים 0 ו-5; מחוץ לשורשים: x < 0 או x > 5   ב. x(x + 4) ≤ 0, השורשים −4 ו-0; בין השורשים כולל אותם: −4 ≤ x ≤ 0
שאלה 7. א. מכפילים ב-−1 והופכים: x² − 6x + 8 < 0; השורשים 2 ו-4, והפתרון 2 < x < 4   ב. מכפילים ב-−1 והופכים: x² + 2x − 15 ≤ 0; (x + 5)(x − 3) = 0 נותן שורשים −5 ו-3, והפתרון −5 ≤ x ≤ 3
שאלה 8. א. x² − 4x − 5 > 0; (x − 5)(x + 1) = 0 נותן שורשים −1 ו-5, והפתרון x < −1 או x > 5   ב. x² − 7x + 12 ≤ 0; השורשים 3 ו-4, והפתרון 3 ≤ x ≤ 4
שאלה 9. השורשים הם −1 ו-4. בתחום x < −1 שני הגורמים שליליים והמכפלה חיובית; בתחום −1 < x < 4 הגורם הראשון חיובי והשני שלילי, ולכן המכפלה שלילית; בתחום x > 4 שניהם חיוביים והמכפלה חיובית. הפתרון: −1 < x < 4. בדיקה עם נציג x = 0: 1 · (−4) = −4, שלילי ✓
שאלה 10. א. Δ = 4 − 24 = −20, שלילי, והמקדם המוביל חיובי — הביטוי חיובי תמיד, ולכן הפתרון הוא כל x ממשי   ב. לאותו ביטוי אין ערכים שליליים — אין פתרון כלל   ג. מכפילים ב-−1 והופכים: x² − x + 3 > 0; Δ = 1 − 12 = −11, שלילי, והמקדם המוביל חיובי — מתקיים לכל x ממשי
שאלה 11. א. (x − 5)² > 0 — ריבוע חיובי בכל מקום פרט לנקודה שבה הוא מתאפס, ולכן הפתרון הוא כל x פרט ל-x = 5   ב. (x − 5)² ≤ 0 מתקיים רק כאשר הריבוע מתאפס, כלומר רק x = 5   ג. (x + 3)² ≥ 0 נכון תמיד — כל x ממשי
שאלה 12. מחפשים −x² + 10x − 16 > 0. מכפילים ב-−1 והופכים: x² − 10x + 16 < 0. Δ = 100 − 64 = 36, ולכן x = (10 ± 6)/2 והשורשים הם 2 ו-8. המקדם המוביל חיובי ומחפשים שלילי — בין השורשים: 2 < x < 8, כלומר בין 2000 ל-8000 מוצרים
שאלה 13. המקדם המוביל 1 חיובי, ולכן הפרבולה פתוחה כלפי מעלה; היא נשארת כולה מעל הציר בדיוק כאשר אין לה שורשים ממשיים, כלומר כאשר Δ < 0. מחשבים Δ = k² − 16, ודורשים k² − 16 < 0, כלומר k² < 16. התשובה: −4 < k < 4
