תרגול: מערכת עם משוואה ריבועית

פרק 7 · משוואות ריבועיות · פרק 7 — הצבה, מפגש בין ישר לפרבולה ונקודת השקה

✏️ תרגילים

נסו לפתור לבד, ורק אחר כך גלו את הפתרון.

תרגיל 1: חיתוך ישר ופרבולה קל
מצאו את נקודות החיתוך של הישר והפרבולה:

{y = x2y = x + 6
משווים: x2 = x + 6, ולאחר סידור x2 - x - 6 = 0.

פירוק: (x-3)(x+2) = 0, ולכן x1 = 3 ו-x2 = -2.

מציבים בישר: עבור x = 3 מקבלים y = 9, ועבור x = -2 מקבלים y = 4.

תשובה: (3, 9) ו-(-2, 4).
תרגיל 2: השקה בינוני
פתרו את המערכת וקבעו כמה נקודות מפגש יש:

{y = x2 - 2x + 3y = 2x - 1
משווים: x2 - 2x + 3 = 2x - 1, ולאחר סידור x2 - 4x + 4 = 0.

Δ = 16 - 16 = 0 — שורש כפול, ולכן נקודת מפגש אחת בלבד.

(x-2)2 = 0, ולכן x = 2 ומכאן y = 2 · 2 - 1 = 3.

תשובה: נקודת השקה יחידה, (2, 3). בדיקה בפרבולה: 4 - 4 + 3 = 3 ✓.
תרגיל 3: בלי מפגש בינוני
בדקו האם לישר ולפרבולה יש נקודות מפגש:

{y = x2 - 2x + 5y = x + 1
משווים: x2 - 2x + 5 = x + 1, ולאחר סידור x2 - 3x + 4 = 0.

Δ = (-3)2 - 4 · 1 · 4 = 9 - 16 = -7, שלילי.

תשובה: אין שורשים ממשיים ולכן אין נקודות מפגש — הישר אינו נוגע בפרבולה.
תרגיל 4: סכום ומכפלה נתונים בינוני
פתרו את המערכת:

{x + y = 7xy = 12
מבודדים: y = 7 - x, ומציבים: x(7 - x) = 12.

פותחים ומסדרים: 7x - x2 = 12, ומכאן x2 - 7x + 12 = 0.

פירוק: (x-3)(x-4) = 0, ולכן x1 = 3 ו-x2 = 4.

תשובה: (3, 4) ו-(4, 3). בדיקה: 3 + 4 = 7 ✓ וגם 3 · 4 = 12 ✓.
תרגיל 5: אתגר: מציאת פרמטר מאתגר
נתונה הפרבולה y = x2 - 3x + 5 ומשפחת הישרים y = x + k.

א. עבור איזה ערך של k הישר משיק לפרבולה?
ב. עבור אילו ערכי k יהיו שתי נקודות חיתוך, ועבור אילו לא יהיה מפגש כלל?
משווים: x2 - 3x + 5 = x + k, ולאחר סידור x2 - 4x + (5 - k) = 0.

מחשבים את הדיסקרימיננט: Δ = (-4)2 - 4 · 1 · (5-k) = 16 - 20 + 4k = 4k - 4.

א. השקה כאשר Δ = 0, כלומר 4k - 4 = 0 ומכאן k = 1. אז x2 - 4x + 4 = 0 נותן x = 2 ו-y = 2 + 1 = 3, כלומר נקודת ההשקה היא (2, 3). בדיקה בפרבולה: 4 - 6 + 5 = 3 ✓.

ב. שתי נקודות חיתוך כאשר Δ > 0, כלומר k > 1; אין מפגש כאשר Δ < 0, כלומר k < 1.
תרגיל 6: חיתוך ישר ופרבולה קל
מצאו את נקודות החיתוך של הפרבולה y = x2 והישר y = 5x - 6.
משווים: x2 = 5x - 6, ולאחר סידור x2 - 5x + 6 = 0. פירוק: (x-2)(x-3) = 0, ולכן x1 = 2 ו-x2 = 3. מציבים בישר: עבור x = 2 מתקבל y = 4, ועבור x = 3 מתקבל y = 9. התשובה: (2, 4) ו-(3, 9). בדיקה בפרבולה: 22 = 4 וגם 32 = 9.
תרגיל 7: ישר דרך הראשית בינוני
פתרו את המערכת שבה y = x2 - 6x + 10 ו-y = x.
משווים: x2 - 6x + 10 = x, ולאחר סידור x2 - 7x + 10 = 0. פירוק: (x-2)(x-5) = 0, ולכן x1 = 2 ו-x2 = 5. מהישר y = x, ולכן y1 = 2 ו-y2 = 5. התשובה: (2, 2) ו-(5, 5). בדיקה בפרבולה: 4 - 12 + 10 = 2 וגם 25 - 30 + 10 = 5.
תרגיל 8: סכום ומכפלה בינוני
פתרו את המערכת שבה x + y = 11 ו-xy = 30.
מבודדים מהמשוואה הקווית: y = 11 - x, ומציבים בשנייה: x(11 - x) = 30. פותחים ומסדרים: 11x - x2 = 30, ומכאן x2 - 11x + 30 = 0. פירוק: (x-5)(x-6) = 0, ולכן x1 = 5 ו-x2 = 6. מחזירים ל-y = 11 - x ומקבלים שני פתרונות: (5, 6) ו-(6, 5). בדיקה: 5 + 6 = 11 וגם 5 · 6 = 30.
תרגיל 9: אתגר: פרמטר ונקודת השקה מאתגר
נתונה הפרבולה y = x2 - 2x + 6 ומשפחת הישרים y = 2x + k. עבור איזה k הישר משיק לפרבולה, ומהי נקודת ההשקה? עבור אילו ערכי k יש שתי נקודות חיתוך ועבור אילו אין מפגש?
משווים: x2 - 2x + 6 = 2x + k, ולאחר סידור x2 - 4x + (6 - k) = 0. מחשבים את הדיסקרימיננט: Δ = 16 - 4(6-k) = 4k - 8. השקה כאשר Δ = 0, כלומר k = 2; אז x2 - 4x + 4 = 0 נותן x = 2, ומהישר y = 4 + 2 = 6 — נקודת ההשקה היא (2, 6). בדיקה בפרבולה: 4 - 4 + 6 = 6. שתי נקודות חיתוך כאשר Δ > 0, כלומר k > 2; ואין מפגש כאשר k < 2.
