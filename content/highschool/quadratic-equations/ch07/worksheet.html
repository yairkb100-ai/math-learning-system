משוואות ריבועיות · פרק 7 — הצבה, מפגש בין ישר לפרבולה ונקודת השקה
שם: כיתה: תאריך:
שיטת ההצבה: מבודדים משתנה מהמשוואה הקווית ומציבים אותו במשוואה הריבועית, וכך מתקבלת משוואה אחת ב-x בלבד. כששתי המשוואות כבר נתונות בצורה y = ... פשוט משווים ביניהן. הדיסקרימיננט של המשוואה שהתקבלה מספר את הסיפור הגרפי: Δ > 0 — שתי נקודות חיתוך, Δ = 0 — נקודת השקה יחידה, Δ < 0 — אין מפגש כלל. אזהרה: פתרון של מערכת הוא זוג סדור, ולכן אין לעצור אחרי מציאת ערכי x — מחזירים כל שורש למשוואה ומחשבים את ה-y שנולד ממנו בדיוק. לבסוף בודקים כל זוג בשתי המשוואות.

שאלה 1 — הצבה ראשונה קל

מצאו את נקודות המפגש:

{y = x²y = x + 2

שאלה 2 — כששני האגפים שווים ל-y קל

פתרו את המערכת וכתבו את הפתרונות כזוגות סדורים:

{y = x² + 1y = 2x + 1

שאלה 3 — ישר דרך הראשית קל

מצאו את נקודות החיתוך של הישר והפרבולה:

{y = x² − 3y = 2x

שאלה 4 — מפגש עם ישר אופקי קל

מצאו את נקודות המפגש:

{y = x² − 5y = 4

שאלה 5 — כמה מפגשים — לפי הדיסקרימיננט בלבד קל

אחרי ההצבה התקבלה בכל סעיף המשוואה הבאה. קבעו כמה נקודות מפגש יש, בלי לפתור:

  1. x² − 6x + 9 = 0 ⟵
  2. x² + 2x + 5 = 0 ⟵
  3. x² − x − 6 = 0 ⟵

שאלה 6 — שתי נקודות חיתוך בינוני

פתרו ובדקו את שני הפתרונות בשתי המשוואות:

{y = x² − 4x + 6y = x + 2

שאלה 7 — נקודת השקה בינוני

פתרו את המערכת, חשבו את הדיסקרימיננט והסבירו את המשמעות הגרפית:

{y = x² + 2x + 3y = 4x + 2

שאלה 8 — בלי מפגש כלל בינוני

בדקו אם לישר ולפרבולה יש נקודות מפגש, ונמקו:

{y = x² + 3y = x + 1

שאלה 9 — סכום ומכפלה בינוני

פתרו את המערכת בשיטת ההצבה:

{x + y = 9xy = 20

שאלה 10 — כשהמשוואה הקווית אינה מפורשת בינוני

בודדו משתנה מהמשוואה הקווית ואז הציבו:

{y = x²x + y = 12

שאלה 11 — ממדי מלבן מאתגר

היקף מלבן הוא 26 ס"מ ושטחו 40 סמ"ר. סמנו את הצלעות ב-a וב-b, כתבו מערכת משוואות, ומצאו את הממדים.

שאלה 12 — אתגר: מציאת פרמטר להשקה מאתגר

נתונה הפרבולה y = x² + 2x + 7 ומשפחת הישרים y = 4x + k.

  1. עבור איזה k הישר משיק לפרבולה, ומהי נקודת ההשקה?
  2. עבור אילו ערכי k יש שתי נקודות חיתוך, ועבור אילו אין מפגש כלל?

שאלה 13 — אתגר: הפרש ומכפלה מאתגר

מצאו שני מספרים שהפרשם 3 ומכפלתם 54. כתבו מערכת משוואות, פתרו בהצבה, וכתבו את כל הפתרונות.

שאלה 1. משווים: x² = x + 2 → x² − x − 2 = 0 → (x − 2)(x + 1) = 0, ולכן x = 2 או x = −1. מציבים בישר: עבור x = 2 מתקבל y = 4, ועבור x = −1 מתקבל y = 1. הפתרונות: (2, 4) ו-(−1, 1)
שאלה 2. משווים: x² + 1 = 2x + 1 → x² − 2x = 0 → x(x − 2) = 0, ולכן x = 0 או x = 2. הערכים המתאימים: y = 1 ו-y = 5. הפתרונות: (0, 1) ו-(2, 5)
שאלה 3. משווים: x² − 3 = 2x → x² − 2x − 3 = 0 → (x − 3)(x + 1) = 0, ולכן x = 3 או x = −1. מציבים בישר: y = 6 ו-y = −2. הפתרונות: (3, 6) ו-(−1, −2)
שאלה 4. משווים: x² − 5 = 4 → x² = 9 → x = ±3. בשני המקרים y = 4. הפתרונות: (3, 4) ו-(−3, 4)
שאלה 5. א. Δ = 36 − 36 = 0 — נקודת השקה אחת   ב. Δ = 4 − 20 = −16 — אין מפגש   ג. Δ = 1 + 24 = 25 — שתי נקודות חיתוך
שאלה 6. משווים: x² − 4x + 6 = x + 2 → x² − 5x + 4 = 0 → (x − 1)(x − 4) = 0, ולכן x = 1 או x = 4. מציבים בישר: y = 3 ו-y = 6. הפתרונות: (1, 3) ו-(4, 6). בדיקה בפרבולה: 1 − 4 + 6 = 3 ✓ וגם 16 − 16 + 6 = 6 ✓
שאלה 7. משווים: x² + 2x + 3 = 4x + 2 → x² − 2x + 1 = 0. Δ = 4 − 4 = 0 — שורש כפול, ולכן נקודת מפגש אחת. (x − 1)² = 0 נותן x = 1, ומהישר y = 6. הפתרון היחיד: (1, 6). מבחינה גרפית הישר משיק לפרבולה ואינו חוצה אותה. בדיקה בפרבולה: 1 + 2 + 3 = 6 ✓
שאלה 8. משווים: x² + 3 = x + 1 → x² − x + 2 = 0. Δ = 1 − 8 = −7, שלילי — אין שורשים ממשיים, ולכן אין נקודות מפגש. הישר עובר כולו מתחת לפרבולה
שאלה 9. מבודדים: y = 9 − x, ומציבים: x(9 − x) = 20 → 9x − x² = 20 → x² − 9x + 20 = 0 → (x − 4)(x − 5) = 0, ולכן x = 4 או x = 5. הפתרונות: (4, 5) ו-(5, 4). בדיקה: 4 + 5 = 9 ✓ וגם 4 · 5 = 20 ✓
שאלה 10. מבודדים: y = 12 − x, ומציבים בפרבולה: x² = 12 − x → x² + x − 12 = 0 → (x + 4)(x − 3) = 0, ולכן x = 3 או x = −4. הערכים המתאימים: y = 9 ו-y = 16. הפתרונות: (3, 9) ו-(−4, 16). בדיקה: 3 + 9 = 12 ✓ וגם −4 + 16 = 12 ✓
שאלה 11. מההיקף 2(a + b) = 26 ולכן a + b = 13, ומהשטח ab = 40. מבודדים b = 13 − a ומציבים: a(13 − a) = 40 → a² − 13a + 40 = 0 → (a − 5)(a − 8) = 0, ולכן a = 5 או a = 8. שתי האפשרויות מתארות את אותו מלבן: הצלעות הן 8 ס"מ ו-5 ס"מ. בדיקה: 2 · 13 = 26 ✓ וגם 8 · 5 = 40 ✓
שאלה 12. משווים: x² + 2x + 7 = 4x + k → x² − 2x + (7 − k) = 0, ולכן Δ = 4 − 4(7 − k) = 4k − 24. א. השקה כאשר Δ = 0, כלומר k = 6; אז x² − 2x + 1 = 0 נותן x = 1 ו-y = 10, ונקודת ההשקה היא (1, 10) (בדיקה בפרבולה: 1 + 2 + 7 = 10 ✓)   ב. שתי נקודות חיתוך כאשר k > 6, ואין מפגש כאשר k < 6
שאלה 13. המערכת היא {x − y = 3xy = 54. מבודדים x = y + 3 ומציבים: y(y + 3) = 54 → y² + 3y − 54 = 0 → (y + 9)(y − 6) = 0, ולכן y = 6 או y = −9. הפתרונות: (9, 6) ו-(−6, −9) — כלומר המספרים 9 ו-6, או −6 ו-−9. בדיקה: 9 · 6 = 54 ✓ וגם (−6) · (−9) = 54 ✓
