תרגיל 1: כיוון פתיחה וקדקוד קל
נתונה הפונקציה y = x2 - 8x + 12.

א. לאיזה כיוון פתוחה הפרבולה?
ב. מצאו את הקדקוד ואת משוואת ציר הסימטריה.
א. a = 1 > 0, ולכן הפרבולה פתוחה כלפי מעלה.
ב. xv = --82 · 1 = 4, ומהצבה yv = 16 - 32 + 12 = -4. הקדקוד הוא (4, -4), וציר הסימטריה הוא x = 4.
תרגיל 2: חיתוך עם הצירים בינוני
מצאו את נקודות החיתוך של הפרבולה y = x2 - 2x - 8 עם שני הצירים.
עם ציר ה-y: מציבים x = 0 ומקבלים y = -8, כלומר הנקודה (0, -8).
עם ציר ה-x: פותרים x2 - 2x - 8 = 0. בפירוק לגורמים (x - 4)(x + 2) = 0, ולכן x = 4 או x = -2 — הנקודות (4, 0) ו-(-2, 0).
תרגיל 3: ערך מרבי בינוני
נתונה הפונקציה y = -x2 + 6x - 5. מצאו את הערך המרבי שלה ואת נקודות החיתוך עם ציר ה-x.
a = -1 < 0, ולכן לפונקציה יש ערך מרבי בקדקוד.
xv = -62 · (-1) = 3, ומהצבה yv = -9 + 18 - 5 = 4. הערך המרבי הוא 4, בנקודה (3, 4).
חיתוך עם ציר ה-x: -x2 + 6x - 5 = 0, כלומר x2 - 6x + 5 = 0, ולכן x = 1 או x = 5.
בדיקת סימטריה: האמצע בין 1 ל-5 הוא 3 ✓.
תרגיל 4: כמה חיתוכים עם ציר ה-x? בינוני
בלי לפתור אף משוואה, קבעו לכל פונקציה כמה נקודות חיתוך יש לה עם ציר ה-x.

א. y = x2 - 6x + 9
ב. y = x2 + 2x + 5
ג. y = 2x2 - 3x - 2
מחשבים את הדיסקרימיננט Δ = b2 - 4ac בכל סעיף:
א. Δ = 36 - 36 = 0 — נקודת חיתוך אחת (הקדקוד נוגע בציר).
ב. Δ = 4 - 20 = -16, וזהו מספר שלילי — אין נקודות חיתוך.
ג. Δ = 9 + 16 = 25, וזהו מספר חיובי — שתי נקודות חיתוך.
תרגיל 5: אתגר: סרטוט מלא מאתגר
נתונה הפונקציה y = 2x2 - 8x + 6. מצאו את כיוון הפתיחה, הקדקוד, ציר הסימטריה, נקודות החיתוך עם שני הצירים, וכתבו אותה גם בצורת הקדקוד.
כיוון: a = 2 > 0 — פתוחה כלפי מעלה.
קדקוד: xv = --82 · 2 = 2, ומהצבה yv = 8 - 16 + 6 = -2. הקדקוד (2, -2).
ציר סימטריה: x = 2.
חיתוך עם ציר ה-y: (0, 6).
חיתוך עם ציר ה-x: 2x2 - 8x + 6 = 0; מחלקים ב-2 ומקבלים x2 - 4x + 3 = 0, ולכן x = 1 ו-x = 3 — הנקודות (1, 0) ו-(3, 0).
צורת הקדקוד: y = 2(x2 - 4x) + 6 = 2[(x - 2)2 - 4] + 6 = 2(x - 2)2 - 2 — ואכן הקדקוד הוא (2, -2) ✓.
תרגיל 6: מציאת הקדקוד קל
מצאו את קדקוד הפרבולה y = x2 - 2x - 8 ואת משוואת ציר הסימטריה שלה.
xv = --22 · 1 = 1, ובהצבה yv = 1 - 2 - 8 = -9. הקדקוד הוא (1, -9) וציר הסימטריה הוא x = 1. מכיוון ש-a = 1 > 0 זו נקודת מינימום.
תרגיל 7: כל הנתונים לסרטוט בינוני
נתונה הפונקציה y = -x2 + 2x + 3. מצאו את כיוון הפתיחה, הקדקוד, ונקודות החיתוך עם שני הצירים.
a = -1 < 0, ולכן הפרבולה פתוחה כלפי מטה. xv = -22 · (-1) = 1, ובהצבה yv = -1 + 2 + 3 = 4 — הקדקוד (1, 4) הוא נקודת מקסימום. חיתוך עם ציר ה-y: (0, 3). חיתוך עם ציר ה-x: פותרים -x2 + 2x + 3 = 0, כלומר x2 - 2x - 3 = 0, ובפירוק (x-3)(x+1) = 0 — הנקודות (3, 0) ו-(-1, 0). בדיקת סימטריה: האמצע בין -1 ל-3 הוא 1.
תרגיל 8: הדיסקרימיננט כמנבא בינוני
כמה נקודות חיתוך עם ציר ה-x יש לפרבולה y = 2x2 - 3x + 5? הסבירו מה זה אומר על מיקום הגרף.
Δ = (-3)2 - 4 · 2 · 5 = 9 - 40 = -31, שלילי — אין נקודות חיתוך. מכיוון ש-a = 2 > 0 הפרבולה פתוחה כלפי מעלה, ולכן היא כולה מעל ציר ה-x ואינה נוגעת בו באף נקודה. חשוב: לפונקציה יש גרף מצוין, היא פשוט אינה פוגשת את הציר.
תרגיל 9: אתגר: פרמטר ומספר החיתוכים מאתגר
עבור אילו ערכי m יש לפרבולה y = x2 - 4x + m שתי נקודות חיתוך עם ציר ה-x? ועבור איזה ערך היא משיקה לציר?
מחשבים Δ = (-4)2 - 4 · 1 · m = 16 - 4m. שתי נקודות חיתוך כאשר Δ > 0, כלומר 16 - 4m > 0 ומכאן m < 4. השקה כאשר Δ = 0, כלומר m = 4; אז y = x2 - 4x + 4 = (x-2)2 ונקודת ההשקה היא (2, 0). עבור m > 4 אין חיתוך כלל.
